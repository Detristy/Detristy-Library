## 核心公式速查表

> 💡 **小贴士**：光学公式多但规律强，记住"光程差 → 干涉/衍射条件"这条主线！

### 1. 光程与相位差
- 光程：$L = nr$（介质折射率 × 几何路程）
- 相位差与光程差：$\Delta\phi = \dfrac{2\pi}{\lambda}\delta$（$\lambda$ 为**真空**波长）
- 干涉加强：$\delta = k\lambda$（明纹）
- 干涉减弱：$\delta = (2k+1)\dfrac{\lambda}{2}$（暗纹）

### 2. 杨氏双缝干涉
- 波程差：$\delta \approx d\sin\theta \approx d\dfrac{x}{D}$
- 明纹位置：$x = k\dfrac{D\lambda}{d}$
- 暗纹位置：$x = (2k-1)\dfrac{D\lambda}{2d}$
- 条纹间距：$\Delta x = \dfrac{D\lambda}{d}$
- 光源偏移 $L$：总光程差 $\delta = L + \dfrac{xd}{D}$，中央明纹移到 $x_0 = -\dfrac{LD}{d}$
- 缝贴膜（厚度 $h$，折射率 $n$）：附加光程差 $(n-1)h$，条纹移动 $N = \dfrac{(n-1)h}{\lambda}$ 条

### 3. 薄膜干涉
- 劈尖光程差：$\delta = 2ne + \dfrac{\lambda}{2}$（注意半波损有无要看上下界面反射情况）
- 相邻明/暗纹高度差：$\Delta e = \dfrac{\lambda}{2n}$
- 相邻条纹间距：$l = \dfrac{\lambda}{2n\theta}$
- 条纹弯曲：凹槽 → 弯向棱边；凸起 → 弯离棱边；弯曲量 $a/b$ 对应深度 $h = \dfrac{a}{b}·\dfrac{\lambda}{2}$
- 牛顿环明环半径：$r = \sqrt{\dfrac{(2k-1)R\lambda}{2}}$；暗环半径：$r = \sqrt{kR\lambda}$
- 增透膜最小厚度：$e = \dfrac{\lambda}{4n_c}$（反射光相消）
- 增反膜最小厚度：$e = \dfrac{\lambda}{2n_c}$（反射光加强）

### 4. 单缝夫琅禾费衍射
- 暗纹条件：$a\sin\theta = k\lambda$（$k = \pm1, \pm2, \dots$）
- 明纹条件：$a\sin\theta = (2k+1)\dfrac{\lambda}{2}$（$k = \pm1, \pm2, \dots$）
- 中央明纹半角宽度：$\theta_0 \approx \dfrac{\lambda}{a}$
- 中央明纹线宽度：$\Delta x_0 = \dfrac{2f\lambda}{a}$
- 其他明纹线宽度：$\Delta x = \dfrac{f\lambda}{a}$（中央明纹的一半）
- 各级暗纹坐标：$x = k\dfrac{f\lambda}{a}$
- 不同介质中波长变化：$\lambda' = \lambda / n$
- 半波带数：$N = \dfrac{2a\sin\theta}{\lambda}$

### 5. 光栅衍射
- 光栅常数：$d = a + b$
- 光栅方程（主极大）：$d\sin\theta = k\lambda$（$k = 0, \pm1, \pm2, \dots$）
- 缺级条件：$k = \dfrac{d}{a}k'$（$k' = \pm1, \pm2, \dots$，$k$ 为整数时该级缺级）
- 最大级次：$k_{\max} < \dfrac{d}{\lambda}$（$|\sin\theta| < 1$）
- 主极大坐标：$x = k\dfrac{f\lambda}{d}$
- 两波长重合条件：$k_1\lambda_1 = k_2\lambda_2$

### 6. 偏振
- 自然光过偏振片：$I = \dfrac{1}{2}I_0$
- 马吕斯定律（线偏振光入射）：$I = I_0\cos^2\theta$
- 布儒斯特定律：$\tan i_0 = \dfrac{n_2}{n_1}$，$i_0 + r = 90^\circ$
- 三片偏振片（$P_1 \perp P_3$，中间 $P_2$ 夹角 $\theta$）：$I = \dfrac{I_0}{2}\cos^2\theta\cos^2(90^\circ-\theta)$
- 光学仪器最小分辨角：$\delta\theta = 1.22\dfrac{\lambda}{D}$；分辨本领 $R = \dfrac{1}{\delta\theta}$

## 📝 模块一：杨氏双缝干涉

### 📌 考点 1：条纹位置与间距

#### 题1【单选】
**题目**：在杨氏双缝干涉实验中，双缝间距为 $d$，双缝到屏幕的距离为 $D$（$D \gg d$），用波长为 $\lambda$ 的单色光垂直照射。则相邻明条纹之间的距离为____。
*   (A) $\dfrac{d}{D}\lambda$
*   (B) $\dfrac{D}{d}\lambda$
*   (C) $\dfrac{d}{D\lambda}$
*   (D) $\dfrac{D\lambda}{d^2}$

**解析**：
相邻明纹间距公式直接套：$\Delta x = \dfrac{D\lambda}{d}$。故选 **(B)**。

*   **🔑 老师划重点**：
    *   条纹间距与 $D$ 和 $\lambda$ 成正比，与 $d$ 成反比。
    *   增大双缝间距 → 条纹变密；增大波长 → 条纹变疏。

---

#### 题2【填空】
**题目**：在杨氏双缝干涉实验中，用波长 $\lambda = 600\ \text{nm}$ 的单色光垂直照射双缝，双缝间距 $d = 0.3\ \text{mm}$，双缝到屏幕距离 $D = 1.5\ \text{m}$。则屏幕上相邻明条纹之间的距离为____ mm。

**解析**：
$$\Delta x = \frac{D\lambda}{d} = \frac{1.5 \times 600 \times 10^{-9}}{0.3 \times 10^{-3}} = \frac{9 \times 10^{-7}}{3 \times 10^{-4}} = 3 \times 10^{-3}\ \text{m} = 3\ \text{mm}$$
**答案**：3

---

### 📌 考点 2：光源偏移

#### 题3【单选】
**题目**：在杨氏双缝干涉实验中，点光源 $S$ 位于双缝 $S_1$ 和 $S_2$ 的中垂线上。现将光源 $S$ 沿竖直方向**向上**平移一小段距离，其他条件不变，则屏幕上的干涉条纹将____。
*   (A) 向上平移
*   (B) 向下平移
*   (C) 间距变大
*   (D) 间距变小

**解析**：
由 303A 笔记结论：**光源上移，条纹下移；光源下移，条纹上移**。光源向上移动，相当于 $S_1$ 支路的光程比 $S_2$ 多（或反之），导致中央零级条纹向下移动以补偿光程差。
条纹间距 $\Delta x = \dfrac{D\lambda}{d}$ 与光源位置无关，保持不变。
故选 **(B)**。

---

### 📌 考点 3：缝处贴膜

#### 题4【填空】
**题目**：在杨氏双缝干涉实验中，用波长 $\lambda = 500\ \text{nm}$ 的单色光照射。现将一厚度 $h = 2\ \mu\text{m}$、折射率 $n = 1.5$ 的透明薄膜覆盖在**上**缝 $S_1$ 的后面。原来中央零级明纹处现在变成了第____ 级明纹。（填整数）

**解析**：
1. **附加光程差**：薄膜使上缝支路增加光程 $(n-1)h = 0.5 \times 2 \times 10^{-6} = 1 \times 10^{-6}\ \text{m} = 1000\ \text{nm}$。
2. **条纹移动数**：
   $$N = \frac{(n-1)h}{\lambda} = \frac{1000}{500} = 2$$
3. 上缝贴膜 → 上缝光程增大 → 中央零级上移。原中央点 $O$ 处，上缝光程多出 $2\lambda$，对应第 2 级明纹（或第 -2 级，取决于正方向规定，取绝对值即可）。
**答案**：2

*   **🔑 老师划重点**：
    *   贴膜不改变条纹间距，只平移整个条纹分布。
    *   移动的条纹数 $N = (n-1)h / \lambda$ 必须是整数时原位置才恰好是明纹。

## 📝 模块二：薄膜干涉

### 📌 考点 4：劈尖条纹

#### 题5【单选】
**题目**：在空气劈尖干涉实验中，用波长 $\lambda$ 的单色平行光垂直照射。保持其他条件不变，将劈尖夹角 $\theta$ 增大，则相邻明条纹之间的间距将____。
*   (A) 变大
*   (B) 变小
*   (C) 不变
*   (D) 不能确定

**解析**：
相邻条纹间距公式：$l = \dfrac{\lambda}{2n\theta}$。空气 $n=1$，$\theta$ 增大 → 分母增大 → $l$ 变小。
故选 **(B)**。

---

#### 题6【填空】
**题目**：一空气劈尖由两块平板玻璃构成，用波长 $\lambda = 600\ \text{nm}$ 的单色光垂直照射。在劈尖表面上观察到相邻暗纹的间距为 $l = 0.5\ \text{mm}$，则劈尖的夹角 $\theta$ 为____ rad。

**解析**：
$$l = \frac{\lambda}{2n\theta} = \frac{\lambda}{2\theta}\quad (n=1)$$
$$\theta = \frac{\lambda}{2l} = \frac{600 \times 10^{-9}}{2 \times 0.5 \times 10^{-3}} = \frac{6 \times 10^{-7}}{10^{-3}} = 6 \times 10^{-4}\ \text{rad}$$
**答案**：$6 \times 10^{-4}$

---

### 📌 考点 5：牛顿环与增透膜

#### 题7【填空】
**题目**：在牛顿环实验中，用波长 $\lambda = 589\ \text{nm}$ 的钠黄光垂直照射，测得第 $k$ 级暗环的半径为 $r_k = 4.0\ \text{mm}$，第 $k+5$ 级暗环的半径为 $r_{k+5} = 6.0\ \text{mm}$。则平凸透镜的曲率半径 $R =$ ____ m。

**解析**：
1. **牛顿环暗环半径公式**：$r_m = \sqrt{mR\lambda}$
2. **列出两个方程**：
   $r_k^2 = kR\lambda$，$r_{k+5}^2 = (k+5)R\lambda$
3. **两式相减消去 $k$**：
   $$r_{k+5}^2 - r_k^2 = 5R\lambda$$
   $$R = \frac{r_{k+5}^2 - r_k^2}{5\lambda} = \frac{(36 - 16) \times 10^{-6}}{5 \times 589 \times 10^{-9}} = \frac{20 \times 10^{-6}}{2945 \times 10^{-9}}$$
   $$= \frac{20 \times 10^3}{2945} \approx 6.79\ \text{m}$$
**答案**：6.79

> [!corollary] 小结
> 测 $R$ 的标准套路：用两个不同级次暗环半径平方差消去级次 $k$，$R = \dfrac{r_{m}^2 - r_{n}^2}{(m-n)\lambda}$。不需要知道 $k$ 是多少！

---

#### 题8【填空】
**题目**：在折射率 $n = 1.5$ 的玻璃表面镀一层折射率 $n_c = 1.38$ 的 MgF₂ 薄膜作为增透膜。若光在真空中的波长 $\lambda = 550\ \text{nm}$，为使反射光相消，薄膜的最小厚度为____ nm。

**解析**：
1. **判断半波损**：$n_{\text{空气}}=1 < n_c=1.38 < n_{\text{玻璃}}=1.5$。上下表面反射都是从光疏到光密，**都有半波损** → 两次半波损互相抵消 → 光程差中**不加** $\lambda/2$。
2. **反射光相消条件**：
   $$\delta = 2n_c e = (2k+1)\frac{\lambda}{2}$$
3. **最小厚度**（$k=0$）：
   $$2n_c e = \frac{\lambda}{2} \implies e = \frac{\lambda}{4n_c} = \frac{550}{4 \times 1.38} \approx 99.6\ \text{nm}$$
**答案**：99.6

> [!warning] 易错
> $n_{\text{空气}} < n_c < n_{\text{玻璃}}$ 时上下表面都有半波损，抵消！光程差直接 $2n_c e$，不加 $\lambda/2$。如果 $n_c > n_{\text{玻璃}}$，则只有上表面有半波损。

## 📝 模块三：单缝夫琅禾费衍射

### 📌 考点 6：中央明纹宽度与半波带

#### 题9【单选】
**题目**：在单缝夫琅禾费衍射实验中，波长为 $\lambda$ 的单色平行光垂直照射缝宽为 $a$ 的单缝。缝宽 $a$ 减小为原来的一半，其他条件不变，则中央明纹的线宽度将变为原来的____。
*   (A) $\dfrac{1}{2}$ 倍
*   (B) 1 倍
*   (C) 2 倍
*   (D) 4 倍

**解析**：
中央明纹线宽度 $\Delta x_0 = \dfrac{2f\lambda}{a}$。$a \to a/2$ → $\Delta x_0 \to 2\Delta x_0$。
故选 **(C)**。

*   **🔑 老师划重点**：
    *   缝越窄 → 衍射越明显 → 中央明纹越宽。这和直觉"缝窄了图案也窄"是反的！

---

#### 题10【填空】
**题目**：在单缝夫琅禾费衍射实验中，用波长 $\lambda = 500\ \text{nm}$ 的光垂直照射。对应第二级暗纹的衍射角方向，单缝处的波面被分成____ 个半波带。

**解析**：
1. 第二级暗纹：$k = 2$，$a\sin\theta = 2\lambda$。
2. 半波带数：
   $$N = \frac{2a\sin\theta}{\lambda} = \frac{2 \times 2\lambda}{\lambda} = 4$$
**答案**：4

> 规律：第 $k$ 级暗纹 → $2k$ 个半波带；第 $k$ 级明纹 → $2k+1$ 个半波带。

### 📌 考点 7：暗纹间距反推参数

#### 题11【填空】
**题目**：单缝夫琅禾费衍射实验中，波长 $\lambda = 600\ \text{nm}$ 的单色光垂直照射缝宽 $a = 0.2\ \text{mm}$ 的单缝，缝后透镜将衍射光会聚在焦平面上。测得第一级暗纹与第三级暗纹之间的距离为 $3\ \text{mm}$，则透镜的焦距为____ m。

**解析**：
1. 第 $k$ 级暗纹坐标：$x_k = k\dfrac{f\lambda}{a}$
2. 第一级与第三级暗纹间距：
   $$\Delta x = x_3 - x_1 = \frac{2f\lambda}{a}$$
3. 求解 $f$：
   $$f = \frac{a \cdot \Delta x}{2\lambda} = \frac{0.2 \times 10^{-3} \times 3 \times 10^{-3}}{2 \times 600 \times 10^{-9}} = \frac{6 \times 10^{-7}}{1.2 \times 10^{-6}} = 0.5\ \text{m}$$
**答案**：0.5

## 📝 模块四：光栅衍射

### 📌 考点 8：光栅方程与缺级

#### 题12【单选】
**题目**：一光栅的光栅常数 $d = 2\ \mu\text{m}$，缝宽 $a = 0.5\ \mu\text{m}$。用波长 $\lambda = 500\ \text{nm}$ 的单色平行光垂直照射。下列哪个级次的明纹会出现缺级？
*   (A) $k = 2$
*   (B) $k = 4$
*   (C) $k = 5$
*   (D) $k = 7$

**解析**：
1. $\dfrac{d}{a} = \dfrac{2}{0.5} = 4$
2. 缺级级次：$k = 4k'$，即 $k = \pm4, \pm8, \pm12, \dots$
3. 故选 **(B)**。

---

#### 题13【填空】
**题目**：用一束含有 $\lambda_1 = 400\ \text{nm}$ 和 $\lambda_2 = 600\ \text{nm}$ 两种波长的平行光垂直照射一光栅。在衍射光谱中，这两种波长的谱线**第一次重合**（不计中央零级）时，$\lambda_1$ 对应的级次 $k_1$ 和 $\lambda_2$ 对应的级次 $k_2$ 分别为____。

**解析**：
1. **重合条件**：$k_1\lambda_1 = k_2\lambda_2$
2. **求最简整数比**：
   $$\frac{k_1}{k_2} = \frac{\lambda_2}{\lambda_1} = \frac{600}{400} = \frac{3}{2}$$
3. 第一次重合：$k_1 = 3$，$k_2 = 2$。
**答案**：$k_1 = 3$，$k_2 = 2$

---

#### 题14【单选】
**题目**：一光栅的光栅常数 $d = 3\lambda$（$\lambda$ 为入射光波长），用该波长的单色光垂直照射。不计缺级时，在 $90^\circ > \theta > -90^\circ$ 范围内，最多能观察到的明纹总条数为____。
*   (A) 3
*   (B) 5
*   (C) 7
*   (D) 9

**解析**：
1. **最大级次**：$k < \dfrac{d}{\lambda} = 3$，所以 $k = 0, \pm1, \pm2$。
2. **总条数**：$2 \times 2 + 1 = 5$ 条。
   注意 $k=3$ 时 $\sin\theta = 1$（$\theta = 90^\circ$，刚好在边界），严格说不算"观察到的"（只有半条），不计入。
故选 **(B)**。

*   **🔑 老师划重点**：
    *   $k_{\max} < d/\lambda$（严格小于！$=$ 时在 $90^\circ$ 边界不算）。
    *   总条数 = $2k_{\max} + 1$（算上零级）。

### 📌 考点 9：光栅缺级 + 总条数综合

#### 题15【填空】
**题目**：一光栅的光栅常数 $d = 6\ \mu\text{m}$，缝宽 $a = 2\ \mu\text{m}$。用波长 $\lambda = 500\ \text{nm}$ 的单色平行光垂直照射。在 $90^\circ > \theta > -90^\circ$ 范围内，实际呈现的明纹总条数为____。

**解析**：
1. **最大理论级次**：
   $$k < \frac{d}{\lambda} = \frac{6 \times 10^{-6}}{5 \times 10^{-7}} = 12 \implies k = 0, \pm1, \pm2, \dots, \pm11$$
   理论共 $2 \times 11 + 1 = 23$ 条。

2. **缺级分析**：
   $$\frac{d}{a} = \frac{6}{2} = 3$$
   缺级级次：$k = 3k'$，即 $k = \pm3, \pm6, \pm9$。缺 6 条。

3. **实际条数**：$23 - 6 = 17$ 条。
**答案**：17

## 📝 模块五：偏振

### 📌 考点 10：马吕斯定律

#### 题16【单选】
**题目**：一束自然光垂直通过两片叠在一起的偏振片。两偏振片的透振方向夹角为 $60^\circ$。设入射自然光强为 $I_0$，则透射光强为____。
*   (A) $\dfrac{1}{2}I_0$
*   (B) $\dfrac{1}{4}I_0$
*   (C) $\dfrac{1}{8}I_0$
*   (D) $\dfrac{3}{8}I_0$

**解析**：
1. 过第一片（自然光 → 线偏振光）：$I_1 = \dfrac{1}{2}I_0$
2. 过第二片（马吕斯定律）：$I_2 = I_1\cos^2 60^\circ = \dfrac{1}{2}I_0 \times \dfrac{1}{4} = \dfrac{1}{8}I_0$
故选 **(C)**。

#### 题17【填空】
**题目**：三片偏振片 $P_1$、$P_2$、$P_3$ 依次叠放。$P_1$ 与 $P_3$ 的透振方向**相互垂直**，$P_2$ 的透振方向与 $P_1$ 的夹角为 $30^\circ$。一束自然光强度为 $I_0$，垂直入射 $P_1$，依次通过三个偏振片。则最终的透射光强为____。

**解析**：
1. $P_1$ 后：$I_1 = \dfrac{1}{2}I_0$
2. $P_2$ 后（与 $P_1$ 夹角 $30^\circ$）：$I_2 = I_1\cos^2 30^\circ = \dfrac{1}{2}I_0 \times \dfrac{3}{4} = \dfrac{3}{8}I_0$
3. $P_3$ 后（$P_1 \perp P_3$，$P_2$ 与 $P_1$ 夹角 $30^\circ$ → $P_2$ 与 $P_3$ 夹角 $60^\circ$）：
   $$I_3 = I_2\cos^2 60^\circ = \dfrac{3}{8}I_0 \times \dfrac{1}{4} = \dfrac{3}{32}I_0$$
**答案**：$\dfrac{3}{32}I_0$

> [!warning] 如果只有 $P_1$ 和 $P_3$ 两片正交 → 透射光强为 0（消光）！中间插入 $P_2$ 打破了正交 → 有光透过。这就是"三片偏振片反而有光"的反直觉结论。

### 📌 考点 11：布儒斯特定律

#### 题18【填空】
**题目**：一束自然光从空气（$n_1 = 1$）射向一块玻璃（$n_2 = 1.5$）表面。要使反射光成为完全线偏振光，入射角应为____ 度。（结果保留一位小数）

**解析**：
布儒斯特定律：$\tan i_0 = \dfrac{n_2}{n_1} = 1.5$
$$i_0 = \arctan 1.5 \approx 56.3^\circ$$
此时折射角 $r = 90^\circ - i_0 = 33.7^\circ$。
**答案**：56.3

*   **🔑 老师划重点**：
    *   以布儒斯特角入射 → 反射光完全线偏振（振动方向 $\perp$ 入射面），折射光部分偏振。
    *   $n$ 大的介质中角度更小：$n_2 > n_1$ 时 $i_0 > 45^\circ$。

## 📝 模块六：综合计算

### 📌 考点 12：双缝 + 贴膜零级位移

#### 题19【计算】
**题目**：杨氏双缝干涉实验中，双缝间距 $d = 0.2\ \text{mm}$，双缝到屏幕距离 $D = 2\ \text{m}$。用波长 $\lambda = 500\ \text{nm}$ 的单色光垂直照射。
(1) 求相邻明纹间距；
(2) 现将一厚度 $h = 5\ \mu\text{m}$、折射率 $n = 1.4$ 的透明薄膜覆盖在**下**缝 $S_2$ 的后面。求零级明纹移动的距离和方向。

**解析**：
**(1)** 相邻明纹间距：
$$\Delta x = \frac{D\lambda}{d} = \frac{2 \times 500 \times 10^{-9}}{0.2 \times 10^{-3}} = 5 \times 10^{-3}\ \text{m} = 5\ \text{mm}$$

**(2)** 贴膜产生的附加光程差（下缝支路增加）：
$$\Delta\delta = (n-1)h = 0.4 \times 5 \times 10^{-6} = 2 \times 10^{-6}\ \text{m} = 2000\ \text{nm} = 4\lambda$$

下缝贴膜 → 下缝光程增大 → 为补偿，零级条纹必须**向下移动**（缩短上缝的几何路程）。

移动的条纹数：$N = \dfrac{(n-1)h}{\lambda} = \dfrac{2000}{500} = 4$ 条。

零级明纹移动距离：
$$\Delta x_0 = N \cdot \Delta x = 4 \times 5 = 20\ \text{mm}$$

> **答案**：(1) $5\ \text{mm}$；(2) 向下移动 $20\ \text{mm}$

### 📌 考点 13：劈尖缺陷深度

#### 题20【填空】
**题目**：在空气劈尖干涉实验中，用波长 $\lambda = 600\ \text{nm}$ 的单色光垂直照射。观察到的等厚条纹如图所示，某处条纹向劈尖棱边方向弯曲，弯曲的最大偏移量占条纹间距的 $\dfrac{2}{3}$。则该处平板玻璃表面存在的缺陷是____（填"凹槽"或"凸起"），缺陷深度为____ nm。

**解析**：
1. **判断缺陷类型**：条纹弯向棱边 → **凹槽**（条纹弯向棱边说明该处空气膜厚度偏大，对应凹槽）。
2. **计算深度**：
   $$h = \frac{a}{b} \cdot \frac{\lambda}{2} = \frac{2}{3} \times \frac{600}{2} = \frac{2}{3} \times 300 = 200\ \text{nm}$$
**答案**：凹槽，200

> [!corollary] 条纹弯曲口诀
> - 弯向棱边 → 凹槽（空气膜变厚）
> - 弯离棱边 → 凸起（空气膜变薄）
> - 深度 = $\dfrac{\text{弯曲量}}{\text{条纹间距}} \times \dfrac{\lambda}{2}$

### 📌 考点 14：光栅最大级次与缺级

#### 题21【计算】
**题目**：一光栅每毫米有 500 条刻痕，光栅的总宽度为 $20\ \text{mm}$。用波长 $\lambda = 600\ \text{nm}$ 的单色平行光垂直照射。
(1) 光栅常数 $d$ 是多少？
(2) 理论上最多能看到几级明纹？
(3) 若缝宽 $a = 0.5\ \mu\text{m}$，哪些级次会出现缺级？实际能看到多少条明纹？

**解析**：
**(1)** 光栅常数：
$$d = \frac{1\ \text{mm}}{500} = 2 \times 10^{-6}\ \text{m} = 2\ \mu\text{m}$$

**(2)** 最大级次：
$$k < \frac{d}{\lambda} = \frac{2 \times 10^{-6}}{6 \times 10^{-7}} = \frac{10}{3} \approx 3.33$$
最大整数 $k_{\max} = 3$。理论最多 $2 \times 3 + 1 = 7$ 条。

**(3)** 缺级：
$$\frac{d}{a} = \frac{2}{0.5} = 4$$
缺级级次：$k = 4k' = \pm4, \pm8, \dots$
由于 $k_{\max}=3$，$k=4$ 已超出可见范围，**不存在缺级**！
实际看到 7 条明纹。

> **答案**：(1) $2\ \mu\text{m}$；(2) 7 条；(3) 无缺级，7 条

> [!warning] 注意
> 缺级级次可能超出 $k_{\max}$ 范围！此时虽然 $d/a$ 存在，但实际观察不到缺级。先算 $k_{\max}$，再判断缺级是否落在范围内。
