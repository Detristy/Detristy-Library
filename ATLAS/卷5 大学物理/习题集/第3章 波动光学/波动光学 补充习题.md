# 波动光学 补充习题精讲

> 本笔记补充 300A 中未覆盖的波动光学经典题型：牛顿环定量计算、增透膜/增反膜、迈克尔逊干涉仪、布儒斯特定律、双缝覆盖介质。

## 📌 补1：牛顿环定量计算

### 题1-1
**题目**：在牛顿环实验中，平凸透镜的曲率半径为 $R=1.5\text{ m}$，用波长 $\lambda=589\text{ nm}$ 的钠黄光垂直照射。求从中心向外数第 5 级暗环的半径。

**解析**：
1. **牛顿环暗环公式**（空气薄膜，有半波损失）：
   $$r_k = \sqrt{kR\lambda} \quad (k=0,1,2,\dots)$$
2. 第 5 级暗环对应 $k=5$（注意：中心为零级暗斑，$k$ 从 0 开始数）：
   $$r_5 = \sqrt{5 \times 1.5 \times 589 \times 10^{-9}}$$
   $$= \sqrt{4.4175 \times 10^{-6}} \approx 2.10 \times 10^{-3}\text{ m} = 2.10\text{ mm}$$

**答案**：约 $2.10\text{ mm}$

> 🔑 **老师划重点**：牛顿环暗环 $r_k = \sqrt{kR\lambda}$，明环 $r_k = \sqrt{(k-\frac{1}{2})R\lambda}$。中心是暗斑！注意 $k$ 从 0 还是从 1 开始数——暗环：中心 $k=0$，第一条暗环 $k=1$。

---

### 题1-2
**题目**：牛顿环实验中，测得第 $m$ 级暗环半径 $r_m = 2.0\text{ mm}$，第 $m+5$ 级暗环半径 $r_{m+5} = 3.5\text{ mm}$，所用光的波长 $\lambda = 589\text{ nm}$。求平凸透镜的曲率半径 $R$。

**解析**：
1. 暗环公式：$r_k^2 = kR\lambda$
2. 两式相减消去未知的 $m$：
   $$r_{m+5}^2 - r_m^2 = (m+5)R\lambda - mR\lambda = 5R\lambda$$
3. 代入求解：
   $$R = \frac{r_{m+5}^2 - r_m^2}{5\lambda} = \frac{(3.5^2 - 2.0^2) \times 10^{-6}}{5 \times 589 \times 10^{-9}}$$
   $$= \frac{(12.25 - 4.0) \times 10^{-6}}{2945 \times 10^{-9}} = \frac{8.25 \times 10^{-6}}{2.945 \times 10^{-6}} \approx 2.80\text{ m}$$

**答案**：约 $2.80\text{ m}$

> ⚠️ **易错提醒**：直接代 $r_k = \sqrt{kR\lambda}$ 解不出（不知道 $k$），必须用**差值法**消去 $k$！

## 📌 补2：增透膜与增反膜

### 题2-1（增透膜）
**题目**：在玻璃（$n_3=1.5$）表面镀一层 MgF₂ 薄膜（$n_2=1.38$）作为增透膜。用波长 $\lambda=550\text{ nm}$ 的光垂直照射，为使反射光最弱（透射光最强），薄膜的最小厚度为多少？

**解析**：
1. **分析半波损失**：
   - 上表面：空气 $n_1=1$ → MgF₂ $n_2=1.38$，$n_1 < n_2$，有半波损失 ✓
   - 下表面：MgF₂ $n_2=1.38$ → 玻璃 $n_3=1.5$，$n_2 < n_3$，有半波损失 ✓
   - **两表面都有半波损失** → 互相抵消，光程差无需加 $\lambda/2$
2. **反射光最弱（干涉相消）条件**：
   $$\delta = 2n_2 d = (2k+1)\frac{\lambda}{2}$$
   即：$2n_2 d = \frac{\lambda}{2}, \frac{3\lambda}{2}, \dots$
3. **最小厚度**（$k=0$）：
   $$d_{\min} = \frac{\lambda}{4n_2} = \frac{550}{4 \times 1.38} \approx 99.6\text{ nm}$$

**答案**：约 $100\text{ nm}$

> 🔑 **老师划重点**：增透膜的关键是**两表面都有（或都没有）半波损失**，光程差就是 $2nd$，反射相消条件 $2nd = (2k+1)\lambda/2$，最小厚度 $d = \lambda/(4n)$。

---

### 题2-2（增反膜）
**题目**：在玻璃（$n_3=1.5$）表面镀一层 ZnS 薄膜（$n_2=2.35$）作为增反膜。用波长 $\lambda=550\text{ nm}$ 的光垂直照射，为使反射光最强，薄膜的最小厚度为多少？

**解析**：
1. **分析半波损失**：
   - 上表面：空气 $n_1=1$ → ZnS $n_2=2.35$，$n_1 < n_2$，有半波损失 ✓
   - 下表面：ZnS $n_2=2.35$ → 玻璃 $n_3=1.5$，$n_2 > n_3$，无半波损失 ✗
   - **仅上表面有半波损失** → 光程差需加 $\lambda/2$
2. **反射光最强（干涉加强）条件**：
   $$\delta = 2n_2 d + \frac{\lambda}{2} = k\lambda \quad (k=1,2,\dots)$$
   即：$2n_2 d = \left(k - \frac{1}{2}\right)\lambda$
3. **最小厚度**（$k=1$）：
   $$d_{\min} = \frac{\lambda}{4n_2} = \frac{550}{4 \times 2.35} \approx 58.5\text{ nm}$$

**答案**：约 $58.5\text{ nm}$

> ⚠️ **易错提醒**：增反膜（高反膜）本质和 300A 题29 一样，反射增强 → $2nd + \lambda/2 = k\lambda$ → $d_{\min} = \lambda/(4n)$。但**增透膜**是反射相消，公式不同！区分口诀：**增透 = 消除反射 = 相消；增反 = 增强反射 = 加强**。

## 📌 补3：迈克尔逊干涉仪

### 题3-1
**题目**：在迈克尔逊干涉仪中，用波长 $\lambda=632.8\text{ nm}$ 的 He-Ne 激光作为光源。移动可动反射镜，观察到视场中有 $N=100$ 条干涉条纹移过某参考线。求可动反射镜移动的距离 $\Delta d$。

**解析**：
1. **迈克尔逊干涉仪公式**：
   可动反射镜移动 $\Delta d$，光程差改变 $2\Delta d$（光两次经过该距离）。
   $$2\Delta d = N\lambda$$
2. 代入：
   $$\Delta d = \frac{N\lambda}{2} = \frac{100 \times 632.8 \times 10^{-9}}{2} = 3.164 \times 10^{-5}\text{ m} = 31.64\ \mu\text{m}$$

**答案**：约 $31.6\ \mu\text{m}$

> 🔑 **老师划重点**：迈克尔逊干涉仪核心关系——**镜移动 $\lambda/2$，条纹移动 1 条**。反过来，数条纹数可测微小位移或波长。公式：$2\Delta d = N\lambda$。

---

### 题3-2
**题目**：迈克尔逊干涉仪的一臂中插入一折射率 $n=1.5$、厚度 $h=0.01\text{ mm}$ 的透明薄片后，视场中移动了若干条干涉条纹。用波长 $\lambda=589\text{ nm}$ 的光源，求移过的条纹数目 $N$。

**解析**：
1. 插入薄片前后，该支路的光程变化：
   - 插入前：光在空气中走过 $h$，光程 $= 1 \cdot h$
   - 插入后：光在介质中走过 $h$，光程 $= n \cdot h$
   - 光程变化 $\Delta L = nh - h = (n-1)h$
2. 光两次经过薄片，总光程差变化：$2(n-1)h$
3. 条纹移动数：
   $$N = \frac{2(n-1)h}{\lambda} = \frac{2 \times 0.5 \times 0.01 \times 10^{-3}}{589 \times 10^{-9}} \approx 17.0$$

**答案**：约 $17$ 条

> 🔑 **老师划重点**：插入介质 → 光程变化 $(n-1)h$，迈克尔逊中是两倍（光来回），条纹数 $N = 2(n-1)h/\lambda$。这种题本质是「光程差变化 ÷ 波长 = 条纹移动数」。

## 📌 补4：布儒斯特定律

### 题4-1
**题目**：一束自然光从空气（$n_1=1$）射向某种玻璃（$n_2=1.5$）。求：(1) 布儒斯特角 $i_B$；(2) 此时折射角 $r$ 为多少？

**解析**：
1. **布儒斯特定律**：
   $$\tan i_B = \frac{n_2}{n_1} = 1.5$$
   $$i_B = \arctan 1.5 \approx 56.3^\circ$$
2. **布儒斯特角与折射角的关系**：
   当入射角为布儒斯特角时，反射光与折射光**垂直**：
   $$i_B + r = 90^\circ$$
   $$r = 90^\circ - 56.3^\circ = 33.7^\circ$$

**答案**：(1) $i_B \approx 56.3^\circ$；(2) $r \approx 33.7^\circ$

> 🔑 **老师划重点**：$\tan i_B = n_2/n_1$，且 $i_B + r = 90^\circ$（反射光⊥折射光）。布儒斯特角也叫**起偏角**——以该角入射时，反射光是**完全线偏振光**（振动方向垂直于入射面）。

---

### 题4-2
**题目**：一束自然光以布儒斯特角从某介质射向空气（$n_2=1$），测得布儒斯特角为 $33.7^\circ$。求该介质的折射率。

**解析**：
1. 光从介质射向空气，$n_1$ 为介质折射率，$n_2=1$：
   $$\tan i_B = \frac{n_2}{n_1} = \frac{1}{n_1}$$
2. 代入：
   $$\tan 33.7^\circ = \frac{1}{n_1} \implies n_1 = \frac{1}{\tan 33.7^\circ} \approx \frac{1}{0.667} \approx 1.5$$

**答案**：$n_1 \approx 1.5$

> ⚠️ **易错提醒**：布儒斯特定理中 $\tan i_B = n_2/n_1$，分子是**折射介质**的折射率，分母是**入射介质**的折射率。光从玻璃射向空气时，$n_2=1$，$n_1=1.5$。

## 📌 补5：双缝干涉 + 介质覆盖（条纹移动）

### 题5-1
**题目**：在杨氏双缝干涉实验中，双缝间距 $d=0.5\text{ mm}$，缝到屏距离 $D=1\text{ m}$，入射光波长 $\lambda=500\text{ nm}$。现将一厚度 $h=0.01\text{ mm}$、折射率 $n=1.5$ 的透明薄片覆盖在**上缝**后面。求：(1) 零级明纹向哪个方向移动？(2) 移动了多少条条纹的距离？

**解析**：
1. **覆盖薄片后上缝支路增加的光程**：
   光在薄片中多走的路程变化：$\Delta_{\text{上}} = (n-1)h$
2. **零级明纹条件**（总光程差 = 0）：
   原来零级明纹在 O 点（$d\sin\theta = 0$）。覆盖后，上缝光程增大，为让两束光光程重新相等，需让上缝到屏的几何路程 **减少**。
   所以零级明纹向**上方（上缝方向）**移动。
3. **条纹移动条数**：
   零级明纹移动的距离对应的条纹级次变化：
   $$N = \frac{(n-1)h}{\lambda} = \frac{0.5 \times 0.01 \times 10^{-3}}{500 \times 10^{-9}} = \frac{5 \times 10^{-6}}{5 \times 10^{-7}} = 10$$

**答案**：(1) 向上缝方向移动；(2) 移动了 $10$ 条条纹的距离

> 🔑 **老师划重点**：覆盖介质 → 该缝支路光程增加 $(n-1)h$ → 零级明纹向该缝方向移动 $N = (n-1)h/\lambda$ 条。条纹间距不变，整组平移！

## 总结：波动光学公式速查补

| 题型 | 核心公式 | 易错点 |
|:---|:---|:---|
| 牛顿环暗环 | $r_k = \sqrt{kR\lambda}$ | $k$ 从 0 开始（中心暗斑 $k=0$）|
| 牛顿环明环 | $r_k = \sqrt{(k-\frac{1}{2})R\lambda}$ | $k$ 从 1 开始 |
| 增透膜（反射最弱） | $2nd = (2k+1)\lambda/2$ | 两表面半波损失都有的情况 |
| 增反膜（反射最强） | $2nd + \lambda/2 = k\lambda$ | 仅一表面有半波损失 |
| 迈克尔逊：镜移动 | $2\Delta d = N\lambda$ | 镜移 $\lambda/2$ → 条纹移 1 条 |
| 迈克尔逊：插介质 | $2(n-1)h = N\lambda$ | 光两次经过，乘 2 |
| 布儒斯特角 | $\tan i_B = n_2/n_1$ | 反射光 ⊥ 折射光 |
| 双缝覆盖介质 | $N = (n-1)h/\lambda$ | 条纹向覆盖缝方向移 |
