## 核心公式速查表

> 💡 **小贴士**：考试前把这几张表在草稿纸上默写一遍，考试直接开挂！

### 1. 运动学与动力学
- 微积分关系：$v = \frac{dx}{dt}$， $a = \frac{dv}{dt} = \frac{d^2x}{dt^2} = v\frac{dv}{dx}$。
- 圆周运动：切向加速度 $a_t = \frac{dv}{dt} = R\alpha$（改变速度大小）；法向（向心）加速度 $a_n = \frac{v^2}{R} = R\omega^2$（改变速度方向）。总加速度 $a = \sqrt{a_t^2 + a_n^2}$。
- 变力做功：$W = \int_{x_1}^{x_2} F(x) dx$。
- 动量定理：$\int \vec{F} dt = \Delta \vec{p}$。

### 2. 刚体定轴转动（与质点运动一一对应）
| 物理量 | 质点直线运动 | 刚体定轴转动 | 对应关系 |
| :--- | :--- | :--- | :--- |
| **位置** | 位移 $x$ | 角位移 $\theta$ | $\theta = x/R$ |
| **速度** | 速度 $v = \frac{dx}{dt}$ | 角速度 $\omega = \frac{d\theta}{dt}$ | $v = R\omega$ |
| **加速度** | 加速度 $a = \frac{dv}{dt}$ | 角加速度 $\alpha = \frac{d\omega}{dt}$ | $a_t = R\alpha$ |
| **惯性度量** | 质量 $m$ | 转动惯量 $J = \int r^2 dm$ | - |
| **受力/矩** | 力 $F$ | 力矩 $M = F \cdot d$ | $M = J\alpha$ (转动定律) |
| **动能** | $E_k = \frac{1}{2}mv^2$ | $E_k = \frac{1}{2}J\omega^2$ | - |
| **动量/角动量** | $p = mv$ | $L = J\omega$ | $M = \frac{dL}{dt}$ |

### 📌 考点 1：一维/二维运动学（微积分与圆周运动）

#### 题1【试卷一·单选1】
**题目**：一质点沿着x轴做直线运动，运动学方程为 $x = 3 + 5t + 6t^2 - t^3$ (其中t表示时间)，当该质点的加速度大小为0时，对应的速度大小为____。
*   (A) 17
*   (B) 51
*   (C) 68
*   (D) 10

**解析**：
1. **求速度**：对位移 $x$ 关于时间 $t$ 求一阶导数：
   $$v(t) = \frac{dx}{dt} = 5 + 12t - 3t^2$$
2. **求加速度**：对速度 $v$ 关于时间 $t$ 求一阶导数：
   $$a(t) = \frac{dv}{dt} = 12 - 6t$$
3. **令加速度为 0**：由 $a(t) = 12 - 6t = 0$ 解得 $t = 2\text{ s}$。
4. **代入求速度**：将 $t = 2\text{ s}$ 代入速度公式中：
   $$v(2) = 5 + 12(2) - 3(2^2) = 5 + 24 - 12 = 17$$
   故选 **(A)**。

*   **🔑 老师划重点（微积分求导套路）**：
    *   已知位移 $x(t) \xrightarrow{\text{求导}} v(t) \xrightarrow{\text{求导}} a(t)$。
    *   已知加速度 $a(t) \xrightarrow{\text{积分}} v(t) \xrightarrow{\text{积分}} x(t)$，积分时别忘了初始条件（常数 $C$）。

#### 题2【试卷一·单选2】
**题目**：一质点沿半径为R的圆周运动，角位移$\theta$与时间$t$的关系为$\theta = 2 + 4t^2$，则$t$时刻切向加速度的大小为____。
*   (A) $64Rt^2$
*   (B) $64t^2/R$
*   (C) $8R$
*   (D) $8/R$

**解析**：
1. **求角速度 $\omega$**：对角位移 $\theta$ 求导：
   $$\omega = \frac{d\theta}{dt} = 8t$$
2. **求角加速度 $\alpha$**：对角速度 $\omega$ 求导：
   $$\alpha = \frac{d\omega}{dt} = 8$$
3. **求切向加速度 $a_t$**：利用角量与线量的转换关系：
   $$a_t = R\alpha = 8R$$
   故选 **(C)**。

*   **🔑 老师划重点（圆周运动“角与线”转换）**：
    *   路程与角位移：$S = R\theta$
    *   切向速度与角速度：$v = R\omega$
    *   切向加速度与角加速度：$a_t = R\alpha = R\frac{d\omega}{dt}$
    *   法向（向心）加速度与角速度：$a_n = \frac{v^2}{R} = R\omega^2$

#### 题1【试卷二·单选1】
**题目**：一质点做二维平面运动，位置矢量的表达式为 $\vec{r} = 3t^2\vec{i} + 6t^2\vec{j}$（其中 t 表示时间），则该质点做____ 运动。
*   (A) 变速直线
*   (B) 匀速直线
*   (C) 抛物线
*   (D) 一般曲线

**解析**：
1. **分析轨迹方向**：位置矢量可以写为：
   $$\vec{r}(t) = (3\vec{i} + 6\vec{j})t^2$$
   由于 $(3\vec{i} + 6\vec{j})$ 是一个方向恒定的常数矢量，因此质点始终在一条通过原点的直线上运动。
2. **求速度**：对 $\vec{r}$ 求导：
   $$\vec{v}(t) = \frac{d\vec{r}}{dt} = (6\vec{i} + 12\vec{j})t$$
   速度大小 $v(t) = \sqrt{6^2 + 12^2}t = 6\sqrt{5}t$，随时间 $t$ 变化，所以是**变速**运动。
3. **结论**：质点做变速直线运动，故选 **(A)**。

#### 题2【试卷二·单选2】
**题目**：一质点沿半径为 R 的圆周运动，质点所经过的路程 S 与时间 t 的关系为 $S = 2t + 3t^2$，则切向与向心（法向）加速度的大小表达式分别为____。
*   (A) $6$ 和 $(2+6t)^2/R$
*   (B) $6R$ 和 $(2+6t)^2/R$
*   (C) $6$ 和 $6R$
*   (D) $2+6t$ 和 $(2+6t)^2/R$

**解析**：
1. **求切向速度（速率） $v$**：
   $$v = \frac{dS}{dt} = 2 + 6t$$
2. **求切向加速度 $a_t$**：
   $$a_t = \frac{dv}{dt} = 6$$
3. **求法向（向心）加速度 $a_n$**：
   $$a_n = \frac{v^2}{R} = \frac{(2+6t)^2}{R}$$
   故选 **(A)**。

#### 题21【试卷一·填空21】
**题目**：一质量为 m 的质点沿半径为 R 的圆周按规律 $S = t + t^2$ 运动，其中 S 是路程，t 是时间；则t时刻，质点的总加速度的大小为____。

**解析**：
1. **求速率 $v$**：对路程 $S$ 求导：
   $$v = \frac{dS}{dt} = 1 + 2t$$
2. **求切向加速度 $a_t$**：
   $$a_t = \frac{dv}{dt} = 2$$
3. **求法向加速度 $a_n$**：
   $$a_n = \frac{v^2}{R} = \frac{(1+2t)^2}{R}$$
4. **求总加速度 $a$**：切向与法向互相垂直，故总加速度大小为：
   $$a = \sqrt{a_t^2 + a_n^2} = \sqrt{4 + \frac{(1+2t)^4}{R^2}}$$
**答案**：$\sqrt{4 + \frac{(1+2t)^4}{R^2}}$

#### 题21【试卷二·填空21】
**题目**：一个质点沿 x 轴运动，加速度 a 与位置坐标 x 的关系为 $a = 2 + 4x^3$。如果质点在原点处的速度为 0，则质点在任意位置处的速率为____。

**解析**：
这是典型的**变加速度求速度**问题。因为加速度 $a = a(x)$ 是关于位置的函数，不能直接对时间 $t$ 积分。
1. **恒等变形**：利用链式法则：
   $$a = \frac{dv}{dt} = \frac{dv}{dx} \cdot \frac{dx}{dt} = v\frac{dv}{dx}$$
2. **分离变量并积分**：
   $$v dv = a(x) dx \implies v dv = (2 + 4x^3) dx$$
3. **两边积分**（代入初始条件：$x=0$ 时 $v=0$）：
   $$\int_0^v v' dv' = \int_0^x (2 + 4x'^3) dx' \implies \frac{1}{2}v^2 = \left[ 2x' + x'^4 \right]_0^x = 2x + x^4$$
4. **解出 $v$**：
   $$v = \sqrt{4x + 2x^4}$$
**答案**：$\sqrt{4x + 2x^4}$ （注：【试卷一】的计算题36题也是同类型题目，解析一致）

### 📌 考点 2：牛顿定律与变力动力学

#### 题3【试卷一·单选3】
**题目**：一质量为m的物体，沿x轴做直线运动，初速度大小为$v_0$；现有力$F = F_0 \cos t$ ($F_0$为常数，$t$代表时间) 沿初速度方向作用在该物体上，则$t = \pi/2$ 秒时物体运动速度的大小为____。
*   (A) $v_0 - F_0/m$
*   (B) $v_0 + F_0/m$
*   (C) $v_0$
*   (D) 0

**解析**：
1. **根据牛顿第二定律**：
   $$a = \frac{F}{m} = \frac{F_0}{m} \cos t$$
2. **积分求速度**：因为 $a = \frac{dv}{dt}$，所以：
   $$dv = \frac{F_0}{m} \cos t dt$$
   两边从 $t=0$ 到 $t=\pi/2$ 积分（对应速度由 $v_0$ 变为 $v$）：
   $$\int_{v_0}^v dv' = \int_0^{\pi/2} \frac{F_0}{m} \cos t dt \implies v - v_0 = \frac{F_0}{m} [\sin t]_0^{\pi/2} = \frac{F_0}{m} (1 - 0) = \frac{F_0}{m}$$
3. **求得速度**：
   $$v = v_0 + \frac{F_0}{m}$$
   故选 **(B)**。

#### 题3【试卷二·单选3】
**题目**：一质量为 1 kg 的物体，初速度大小为 2，力 $F = 2 + 3t^2$ 沿速度方向作用在该物体上，则 2 秒后该物体的运动速度的大小为____。
*   (A) 0
*   (B) $2\sqrt{6}$
*   (C) 12
*   (D) 14

**解析**：
1. 根据牛顿第二定律：
   $$a = \frac{F}{m} = \frac{2 + 3t^2}{1} = 2 + 3t^2$$
2. 对时间 $t$ 积分求速度（由 $t=0$ 到 $t=2$，速度由 $v_0=2$ 到 $v$）：
   $$v - 2 = \int_0^2 (2 + 3t^2) dt = \left[ 2t + t^3 \right]_0^2 = (4 + 8) - 0 = 12$$
   $$v = 12 + 2 = 14$$
   故选 **(D)**。

#### 题4【试卷二·单选4】
**题目**：质量为 1 kg 的质点，无初速度、自原点出发沿 x 轴做直线运动，若质点受到的作用力 F 与时间 t 满足 $F = \cos t$，则质点的位移随时间变化的关系为____。
*   (A) $x = \cos t$
*   (B) $x = 1 - \cos t$
*   (C) $x = t - \sin t$
*   (D) $x = t - \sin t$？（注：原题选项可能有误，但解析唯一）

**解析**：
1. $m = 1\text{ kg}$，根据牛顿第二定律，$a = \frac{F}{m} = \cos t$。
2. 积分求速度（初速度为 0，即 $t=0$ 时 $v=0$）：
   $$v(t) = \int_0^t \cos t' dt' = \sin t$$
3. 积分求位移（出发点在原点，即 $t=0$ 时 $x=0$）：
   $$x(t) = \int_0^t \sin t' dt' = [-\cos t']_0^t = 1 - \cos t$$
   故选 **(B)**。

#### 题4【试卷一·单选4】
**题目**：一驾驶员正在直道高速公路上驾车行驶，此时前方有突发状况，需要踩刹车进行减速。关于刹车过程中驾驶员受到的惯性力方向，下列说法正确的是____。
*   (A) 与汽车行驶方向一致
*   (B) 与汽车行驶方向相反
*   (C) 惯性力为0，不存在方向问题
*   (D) 条件不足，无法判断

**解析**：
1. **非惯性系分析**：以正在刹车减速的汽车为参考系，汽车具有向后的减速加速度 $\vec{a}$（与行驶方向相反）。
2. **惯性力公式**：在加速度为 $\vec{a}$ 的非惯性系中，质量为 $m$ 的物体受到的惯性力为：
   $$\vec{F}_{\text{inertial}} = -m\vec{a}$$
3. **方向判断**：因为汽车的加速度 $\vec{a}$ 方向向后，所以惯性力 $\vec{F}_{\text{inertial}}$ 的方向向前，即与汽车的行驶方向**一致**（这也是急刹车时人会向前倾的原因）。
   故选 **(A)**。

#### 题22【试卷一·填空22】
**题目**：高空中有一质量为m的物体，以初速度$v_0$竖直下落，空气阻力大小与速度成正比，即$f = -kv$ (k为常数)，则物体终极速度大小为____。

**解析**：
1. **终极速度（收尾速度）**：当重物下落足够长时间后，重力与空气阻力平衡，加速度降为 0，此时的速度即为终极速度 $v_t$。
2. **受力平衡方程**：
   $$mg - kv_t = 0 \implies v_t = \frac{mg}{k}$$
**答案**：$\frac{mg}{k}$

#### 题22【试卷二·填空22】
**题目**：如图所示，以加速度 a 上升的升降机内，有一质量均为 m 的物体 A 和 B。A 所在的桌面是水平的，绳子和定滑轮质量均不计，忽略一切摩擦，则绳中张力为____。

**解析**：
这道题需要使用**非惯性参考系**或**相对运动**来解。我们以加速度为 $a$ 向上运动的升降机为参考系：
1. **引入惯性力**：由于升降机以 $\vec{a}$ 向上加速，处于其中的物体都受到一个向下的惯性力 $\vec{F}_i = -m\vec{a}$，大小为 $ma$。
2. **有效重力加速度**：物体在升降机中所受的重力和惯性力都是向下的，所以可以等效为受到了一个有效重力加速度 $g' = g + a$。
3. **列出运动方程**：
   * 对于物体 B（悬挂在滑轮下方）：在升降机参考系中，它受等效重力 $m(g+a)$ 向下，绳子张力 $T$ 向上。设其向下加速度为 $a_{\text{rel}}$：
     $$m(g+a) - T = m a_{\text{rel}}$$
   * 对于物体 A（在光滑水平桌面上）：在升降机参考系中，水平方向只受绳子张力 $T$（垂直方向的重力、支持力和竖直方向的惯性力平衡）。其向右的加速度也为 $a_{\text{rel}}$：
     $$T = m a_{\text{rel}}$$
4. **求解张力 $T$**：将两式相加：
     $$m(g+a) = 2m a_{\text{rel}} \implies a_{\text{rel}} = \frac{g+a}{2}$$
     代回得：
     $$T = \frac{m(g+a)}{2}$$
**答案**：$\frac{m(g+a)}{2}$

### 📌 考点 3：功与动量定理

#### 题5【试卷一·单选5】
**题目**：一个质点在力$\vec{F} = -3\vec{i} - 5\vec{j} + 9\vec{k}$ 作用下的位移为$\Delta \vec{r} = 4\vec{i} - 5\vec{j} + 6\vec{k}$，则力在此位移过程中所做的功为____ J。
*   (A) 91
*   (B) 51
*   (C) 17
*   (D) 67

**解析**：
1. **恒力做功公式**：由于力 $\vec{F}$ 是恒力，功等于力与位移的点积：
   $$W = \vec{F} \cdot \Delta \vec{r} = F_x \Delta x + F_y \Delta y + F_z \Delta z$$
2. **代入计算**：
   $$W = (-3)(4) + (-5)(-5) + (9)(6) = -12 + 25 + 54 = 67\text{ J}$$
   故选 **(D)**。

#### 题5【试卷二·单选5】
**题目**：一物体在力 $F = 3x^2$ 作用下沿 x 轴做直线运动，在 $x = 1$ 到 $x = 2$ 过程中力 F 所做的功为____ J。
*   (A) 7
*   (B) 3
*   (C) 21
*   (D) 42

**解析**：
1. **变力做功公式**：
   $$W = \int_{x_1}^{x_2} F(x) dx$$
2. **计算定积分**：
   $$W = \int_1^2 3x^2 dx = \left[ x^3 \right]_1^2 = 2^3 - 1^3 = 8 - 1 = 7\text{ J}$$
   故选 **(A)**。

#### 题24【试卷二·填空24】
**题目**：一质量为 1 kg 的质点受到 $\vec{F} = 2y\vec{i} + 4\vec{j}$ 的外力作用，沿抛物线 $x^2 = y$ 运动，则质点从 $x_1 = 0$ 到 $x_2 = 3$ 处过程中，外力做功为____ J。

**解析**：
1. **变力做功的一般公式**：
   $$W = \int \vec{F} \cdot d\vec{r} = \int (F_x dx + F_y dy) = \int (2y dx + 4 dy)$$
2. **统一变量**：利用轨迹方程 $y = x^2 \implies dy = 2x dx$。
3. **代入积分**（积分区间 $x \in [0, 3]$）：
   $$W = \int_0^3 \left[ 2(x^2) dx + 4(2x dx) \right] = \int_0^3 (2x^2 + 8x) dx$$
4. **计算定积分**：
   $$W = \left[ \frac{2}{3}x^3 + 4x^2 \right]_0^3 = \left( \frac{2}{3} \cdot 27 + 4 \cdot 9 \right) - 0 = 18 + 36 = 54\text{ J}$$
**答案**：54

**解析**：

1. **力的随时间变化关系**：力在 4 秒内从 0 线性增加到 50 N，故 $F(t)$ 的表达式为：
   $$F(t) = \frac{50}{4}t = 12.5t \quad (0 \le t \le 4)$$
2. **动量定理公式**：
   $$\int_0^t F(t') dt' = \Delta p = m v - m v_0$$
3. **代入数据**：已知 $m = 10\text{ kg}$， $v_0 = 0$。
   * **冲量 $I$** 也可以直接通过 $F-t$ 图象围成的三角形面积计算：

   * 动量变化：
     $$\Delta p = m v = 10 v$$
4. **求解末速度**：
     $$100 = 10 v \implies v = 10\text{ m/s}$$
**答案**：10

#### 题7【试卷二·单选7】
**题目**：一转动惯量为 J 的圆盘绕固定轴以 $\omega_0$ 的角速度开始旋转，圆盘受阻力矩与转动角速度成正比，即 $M = -k\omega$（k为常数），则圆盘的角速度大小变为 $0.5\omega_0$ 时所需的时间为____。

#### 题25【试卷二·填空25】
**题目**：如图，一轻绳绕于半径为 R 的飞轮边缘，且质量为 m 的物体挂在绳端，飞轮对过轮心且与轮面垂直的水平固定轴的转动惯量为 $mR^2$。初始时，飞轮以角速度 $\omega$ 逆时针旋转（向下放绳），则飞轮的角加速度大小为____。

   $$mg - ma = ma \implies 2ma = mg \implies a = \frac{g}{2}$$

   $$\alpha = \frac{g}{2R}$$

### 📌 考点 1：简谐振动的基本特征与方程确定

#### 题10【试卷二·单选10】
**题目**：一质点做简谐运动，下列描述正确的是____。
*   (A) 质点处在端点时，速度和加速度的大小都达到了最大值
*   (B) 质点处于平衡位置且向正方向运动时，速度和加速度都为零
*   (C) 质点从最大位移处向平衡位置运动时，速度和加速度都变大
*   (D) 质点处于平衡位置向负方向运动时，速度的大小最大，加速度为零

**解析**：
1. **简谐运动位移、速度、加速度的关系**：
   $$x = A\cos(\omega t + \phi)$$
   $$v = \frac{dx}{dt} = -\omega A\sin(\omega t + \phi)$$
   $$a = \frac{dv}{dt} = -\omega^2 A\cos(\omega t + \phi) = -\omega^2 x$$
2. **端点处（$x = \pm A$）**：
   * 速度 $v = 0$（最小）；
   * 加速度 $a = \mp \omega^2 A$，大小 $|a| = \omega^2 A$ 最大。
3. **平衡位置处（$x = 0$）**：
   * 速度大小 $|v| = \omega A$ 最大；
   * 加速度 $a = 0$。
4. **从最大位移处向平衡位置运动时**：
   * 位移变小，故加速度大小 $|a| = \omega^2 |x|$ 变小；
   * 质点向平衡位置靠拢，速度大小 $|v|$ 变大。
5. **分析选项**：
   (D) 质点处于平衡位置向负方向运动时，位移 $x = 0$ ，故加速度 $a = 0$ ；速度方向向负，大小为最大值 $\omega A$。此描述完全正确。
   故选 **(D)**。

#### 题8【试卷一·单选8】
**题目**：两个质点各自在x轴做简谐振动，它们的振幅和周期都相同。第一个质点的振动方程为$x_1 = A\cos(\omega t + \pi/3)$。当第一个质点从正向最大位移处回到平衡位置时，第二个质点正从最大负位移回到 $-A/2$ 处。则第二个质点的振动方程 $x_2 =$ ____。
*   (A) $A\cos(\omega t - \pi/3)$
*   (B) $A\cos(\omega t + \pi/6)$
*   (C) $A\cos(\omega t - 2\pi/3)$
*   (D) $A\cos(\omega t - 5\pi/6)$ （注：原题选项 D 印刷可能有偏差，标准解析如下）

**解析（旋转矢量法）**：
1. **分析第一个质点 $x_1$ 运动过程**：
   $x_1$ 的振动方程为 $x_1 = A\cos(\omega t + \pi/3)$。
   * **起点（正向最大位移处）**：其相位为 $2k\pi$，我们取最简相位 $\Phi_1(t_0) = 0$。
   * **终点（回到平衡位置处）**：其相位为 $\pi/2 + k\pi$。因为是从正最大**回到**平衡位置（向负方向运动），所以对应相位为 $\Phi_1(t_1) = \pi/2$。
   * **经历的相位变化**：
     $$\Delta \Phi = \Phi_1(t_1) - \Phi_1(t_0) = \frac{\pi}{2} - 0 = \frac{\pi}{2}$$
     因此，这段运动经历的时间间隔满足 $\omega(t_1 - t_0) = \frac{\pi}{2}$，即经过了 $\frac{1}{4}$ 个周期。

2. **分析第二个质点 $x_2$ 在这一过程中的状态**：
   在相同时间段内，第二个质点也转过了 $\frac{\pi}{2}$ 的相位。
   题目指出：在第一个质点到达平衡位置的时刻 $t_1$，第二个质点“正从最大负位移回到 $-A/2$ 处”。
   * **“从最大负位移处（$x=-A$）回到平衡位置方向”**：说明质点位移为 $-A/2$，且速度为正（$v > 0$），旋转矢量处于第三象限。
   * **确定时刻 $t_1$ 的相位**：
     在第三象限中，满足 $\cos\Phi_2(t_1) = -1/2$ 且 $\sin\Phi_2(t_1) < 0$ 的相位为：
     $$\Phi_2(t_1) = -\frac{2\pi}{3}$$
   * **倒推第二个质点的初相位 $\phi_2$**：
     因为时间过了 $\Delta t = t_1 - t_0$，且 $\omega \Delta t = \frac{\pi}{2}$，所以第二个质点在起点 $t_0$ 时的相位（即初相 $\phi_2$）为：
     $$\phi_2 = \Phi_2(t_1) - \omega \Delta t = -\frac{2\pi}{3} - \frac{\pi}{2} = -\frac{7\pi}{6} \equiv \frac{5\pi}{6}$$
     或者如果题目中起点时间定为 $t_0 = 0$，则 $\omega t_1 = \pi/6$（由 $\omega t_1 + \pi/3 = \pi/2$ 解得）：
     $$\phi_2 = \Phi_2(t_1) - \omega t_1 = -\frac{2\pi}{3} - \frac{\pi}{6} = -\frac{5\pi}{6}$$
     故若选项 (D) 为 $A\cos(\omega t - 5\pi/6)$，则选 **(D)**。

*   **🔑 老师给你的大白话解题口诀**：
    *   “**回到某处**”：如果从负最大往回走，说明速度为正，矢量在下半圆（第三象限）；如果从正最大往回走，说明速度为负，矢量在上半圆（第二象限）。
    *   **算初相**：先确定某特殊时刻的相位 $\Phi(t)$，再减去 $\omega t$ 即可得到初相 $\phi$。

### 📌 考点 2：弹簧分割与劲度系数变化

#### 题9【试卷二·单选9】
**题目**：将弹性系数为 k 的均匀轻弹簧分割成长度分别为 $L_1$ 和 $L_2$ 的两段，且 $L_1 = 3L_2$，则相对应的弹性系数 $k_1$ 和 $k_2$ 分别为____。
*   (A) $3k/4, 4k$
*   (B) $4k/3, 4k$
*   (C) $3k/4, k/4$
*   (D) $4k/3, 3/4k$

**解析**：
1. **弹簧劲度系数与长度规律**：对于同一根均匀弹簧，其劲度系数与长度的乘积为常数：
   $$k \cdot L = \text{常数}$$
2. **计算两段长度**：
   已知总长度为 $L = L_1 + L_2$。
   因为 $L_1 = 3L_2$，所以：
   $$L_1 = \frac{3}{4}L, \quad L_2 = \frac{1}{4}L$$
3. **计算各自的劲度系数**：
   * 对第一段：
     $$k_1 \cdot L_1 = k \cdot L \implies k_1 \cdot \left(\frac{3}{4}L\right) = k L \implies k_1 = \frac{4}{3}k$$
   * 对第二段：
     $$k_2 \cdot L_2 = k \cdot L \implies k_2 \cdot \left(\frac{1}{4}L\right) = k L \implies k_2 = 4k$$
   故选 **(B)**。

### 📌 考点 3：平面简谐波与波动方程

#### 题11【试卷一·单选11】与【试卷二·单选11】

>简谐振动（单个质点，系统封闭）**：动能和势能相互转化，在平衡位置时动能最大，势能为零；在端点时动能为零，势能最大。系统的**总机械能守恒。

 >当质元经过**最大位移（端点）**时，速度为零（**动能为零**），形变为零（**弹性势能为零**）。此时质元总能量为零。

**题目**：如图，一平面简谐波在介质中以波速 $u = 4\text{ m/s}$ 沿 x 轴的负方向传播，已知距离原点 10 m 处的 P 点处的质元的振动方程为 $y = 5\cos(4\pi t)$，则波的表达式为____。

   对于任意位置 $x$：
   * 如果 $x > x_P$（$x > 10$），该点比 P 点更早振动，相位超前。相位差为 $\Delta \phi = +\frac{\omega}{u}(x - x_P)$。
   * 如果 $x < x_P$（$x < 10$），该点比 P 点更晚振动，相位滞后。
   因此，任意点 $x$ 处的波动方程为：
   $$y(x, t) = 5\cos\left[ 4\pi t + \frac{\omega}{u}(x - x_P) \right]$$

   $$y(x, t) = 5\cos\left[ 4\pi t + \pi(x - 10) \right] = 5\cos\left( 4\pi t + \pi x - 10\pi \right)$$

   $$y(x, t) = 5\cos\left( 4\pi t + \pi x \right)$$

   $$y_r(0, t) = A\cos(\omega t + \pi)$$
4. **写出完整的反射波方程**：
   $$y_r(x, t) = A\cos\left(\omega t - \frac{2\pi}{\lambda}x + \pi\right) \quad \text{或} \quad -A\cos\left(\omega t - \frac{2\pi}{\lambda}x\right)$$

*   (D) 雷达站接收器接收到从飞机反射回来的电磁波频率等于飞机接收到的频率

**解析**：
这与声波类似，但这里是电磁波：
1. 雷达发射频率为 $f_0$，飞机向雷达飞来（朝向波源运动），飞机接收到的频率 $f_{plane} > f_0$。
2. 飞机将此频率反射，相当于一个运动的波源向雷达发射，雷达接收器接收到的频率 $f_{radar} > f_{plane}$。
3. 因此：雷达站接收器接收到的频率大于飞机接收到的频率。
   故选 **(C)**。

### 📌 考点 1：相干光、光程与相位差

#### 题13【试卷一·单选13】
**题目**：真空中波长为$\lambda$的单色光，在折射率为 n 的均匀介质中从 A 点沿直线传播到 B 点，若 A、B 两点之间的相位差为 $3\pi$，则此路径 AB 的光程为____。
*   (A) $1.5\lambda/n$
*   (B) $1.5\lambda$
*   (C) $1.5n\lambda$
*   (D) $3\lambda$

**解析**：
1. **相位差与光程差的关系**：
   $$\Delta \phi = \frac{2\pi}{\lambda_0} \cdot \Delta L$$
   其中 $\lambda_0$ 为真空中的波长，$\Delta L$ 为两点之间的**光程**。
2. **计算光程**：
   已知相位差 $\Delta \phi = 3\pi$，代入公式：
   $$3\pi = \frac{2\pi}{\lambda} \cdot \Delta L \implies \Delta L = 1.5\lambda$$
   故选 **(B)**。（注：若是问几何路程，则是 $d = \Delta L / n = 1.5\lambda/n$）。

#### 题13【试卷二·单选13】
**题目**：在相同的时间段内，一束波长为 $\lambda$ 的单色光在真空和在水中传播，则____。
*   (A) 传播的相位差相等，走过的光程相等
*   (B) 传播的路径（路程）相等，走过的光程不相等
*   (C) 传播的路径（路程）不相等，走过的光程相等
*   (D) 传播的路径（路程）不相等，走过的光程不相等

**解析**：
1. **分析传播时间与光速**：
   设时间为 $t$。在真空中光速为 $c$，在水中光速为 $v = c/n$。
2. **计算路程**：
   * 真空中走过的几何路程 $d_1 = c \cdot t$；
   * 水中走过的几何路程 $d_2 = v \cdot t = \frac{c}{n} t$。
   因为 $n > 1$，所以几何路程不相等（$d_1 \ne d_2$）。
3. **计算光程**：
   * 真空中的光程 $L_1 = 1 \cdot d_1 = ct$；
   * 水中的光程 $L_2 = n \cdot d_2 = n \cdot \left(\frac{c}{n} t\right) = ct$。
   所以走过的光程完全相等（$L_1 = L_2$）。
4. **计算相位差**：
   根据相位变化量 $\Delta \phi = \omega \cdot t$。由于是一束单色光，其角频率 $\omega$ 在不同介质中保持不变，因此在相同时间 $t$ 内其相位变化完全相等。
   故选 **(A)** 或 **(C)**（取决于选项描述，A和C都提到了“光程相等”，而路程不相等且相位差相等。从选项看，(C) 明确指出“路径不相等，走过的光程相等”，故选 **(C)** 最为严谨）。

#### 题36【试卷二·计算36】
**题目**：如图，在双缝干涉实验中，单色光源 $S_0$ 到两缝 $S_1$ 和 $S_2$ 的距离分别为 $l_1$ 和 $l_2$，并且 $l_1 - l_2 = \delta_0$。入射光的波长为 $\lambda$，双缝之间的距离为 $d$，双缝到屏幕的距离为 $D (D \gg d)$。
求：
(1) 零级明纹到屏幕中心点 O 的距离；
(2) 如果打算让零级明纹回到屏幕中央 O 点，可采用一折射率 $n=1.5$ 的透明薄膜覆盖在双缝后。试问该薄膜应该覆盖在 $S_1$ 还是 $S_2$ 缝后面？薄膜的厚度 h 应该是多少？

**解析**：
(1) **求零级明纹位置**：
*   光线从光源 $S_0$ 发出，通过双缝 $S_1$ 和 $S_2$ 传播到屏幕上的某点 $P$（设距中心 $O$ 为 $x$）。
*   两束相干光在 $P$ 点的总光程差包括两部分：两缝前的路程差 $\delta_0 = l_1 - l_2$，以及双缝到屏幕的路程差 $\Delta r = r_1 - r_2 \approx \frac{d \cdot x}{D}$。
    $$\delta = (l_1 + r_1) - (l_2 + r_2) = (l_1 - l_2) + (r_1 - r_2) = \delta_0 + \frac{dx}{D}$$
*   零级明纹的要求是总光程差 $\delta = 0$：
    $$\delta_0 + \frac{dx_0}{D} = 0 \implies x_0 = -\frac{\delta_0 D}{d}$$
    所以零级明纹到中心点 O 的距离为 $\frac{\delta_0 D}{d}$。

(2) **覆盖薄膜使零级明纹回到 O 点**：
*   若不覆盖薄膜，当光到达 $O$ 点（即 $x=0$）时，两光束的光程差为：
    $$\delta_O = l_1 - l_2 = \delta_0$$
    由于 $\delta_0 > 0$，说明经 $S_1$ 的光程大于经 $S_2$ 的光程。
*   为了让 $O$ 点的总光程差变为 0，我们需要**增加 $S_2$ 支路的光程**，使其与 $S_1$ 支路平衡。因此，薄膜应该覆盖在 **$S_2$** 缝的后面。
*   在 $S_2$ 后覆盖厚度为 $h$、折射率为 $n$ 的薄膜后， $S_2$ 支路增加的光程为 $(n-1)h$。
*   使 $O$ 点光程差为 0 的条件：
    $$(l_1 + r_1) - [l_2 + r_2 + (n-1)h] = 0$$
    在 $O$ 点，$r_1 = r_2$。所以：
    $$l_1 - l_2 - (n-1)h = 0 \implies \delta_0 = (n-1)h$$
    解得薄膜厚度：
    $$h = \frac{\delta_0}{n-1} = \frac{\delta_0}{1.5-1} = 2\delta_0$$

**答案**：
(1) 零级明纹到屏幕中心点 O 的距离为 $\frac{\delta_0 D}{d}$。
(2) 薄膜应覆盖在 **$S_2$** 缝后，厚度 $h = 2\delta_0$。

### 📌 考点 1：时间膨胀与长度收缩

#### 题20【试卷一·单选20】
**题目**：一艘飞船以 0.8c 的速度远离地球。地球上一个人携带一个质量为 m 的立方体，且立方体的一边与飞行方向平行，地球上人测得此立方体的密度为 $\rho_1$；飞船上的人测得此立方体的密度为 $\rho_2$，关于 $\rho_1$ 和 $\rho_2$ 正确的是____。
*   (A) $\rho_1 < \rho_2$
*   (B) $\rho_1 = \rho_2$
*   (C) $\rho_1 > \rho_2$
*   (D) 不能确定

**解析**：
1. **地球人测得的物理量（固有系）**：
   立方体相对于地球人静止。地球人测得的质量为静止质量 $m_0$，体积为固有体积 $V_0$。
   $$\rho_1 = \frac{m_0}{V_0}$$
2. **飞船上的人测得的物理量（运动系）**：
   飞船相对于立方体以 $v = 0.8c$ 运动。根据相对论效应：
   * **质量增加**：飞船上测得的质量为：
     $$m = \frac{m_0}{\sqrt{1-(v/c)^2}} = \frac{m_0}{\sqrt{1-0.64}} = \frac{m_0}{0.6}$$
   * **长度收缩**：只有平行于运动方向的边长会收缩，垂直于运动方向的边长保持不变。所以体积变为：
     $$V = V_0 \sqrt{1-(v/c)^2} = 0.6 V_0$$
3. **计算飞船上测得的密度 $\rho_2$**：
   $$\rho_2 = \frac{m}{V} = \frac{m_0/0.6}{0.6 V_0} = \frac{m_0}{0.36 V_0} = 2.78 \rho_1$$
   因此有 $\rho_1 < \rho_2$。
   故选 **(A)**。

#### 题34【试卷二·填空34】
**题目**：在 S 系中观察，A 和 B 两地相距 $3c$（$c$ 为光速），且间隔 5 秒发生了两件事情，而在相对于 S 系沿 x 方向匀速运动的 S' 系中观察，这两件事恰好发生在同一点。在 S' 系中观察这两件事的时间间隔为____ 秒。

**解析**：
1. **利用洛伦兹坐标变换公式**：
   在 S 系中： $\Delta x = 3c$， $\Delta t = 5$。
   在 S' 系中：由于两事件发生在同一点，有 $\Delta x' = 0$。
   根据变换公式：
   $$\Delta x' = \gamma (\Delta x - v \Delta t) = 0 \implies \Delta x - v \Delta t = 0$$
   解得 S' 系相对于 S 系的速度为：
   $$v = \frac{\Delta x}{\Delta t} = \frac{3c}{5} = 0.6c$$
2. **利用洛伦兹时间变换公式**：
   $$\Delta t' = \gamma \left( \Delta t - \frac{v}{c^2} \Delta x \right)$$
   代入 $v = 0.6c$，$ \gamma = \frac{1}{\sqrt{1-0.36}} = 1.25$：
   $$\Delta t' = 1.25 \times \left( 5 - \frac{0.6c}{c^2} \times 3c \right) = 1.25 \times (5 - 1.8) = 1.25 \times 3.2 = 4\text{ 秒}$$
**答案**：4

#### 题38(2)【试卷一·大题38(2)】
**题目**：汽车的安全气囊是保障乘驾人员安全的重要装置。当汽车发生碰撞时，安全气囊会迅速弹出弹出保护驾驶员。请用本学期学过的大学物理（1）中的相关知识，解释安全气囊能够减少乘员受到伤害的物理原理。（建议字数 50-200；可使用图、公式辅助说明）

**解析**：
这道题需要使用 **质点的动量定理** 进行定性与定量分析。
1. **动量定理基本公式**：
   $$\vec{F}_{\text{avg}} \cdot \Delta t = \Delta \vec{p} = m\vec{v}_t - m\vec{v}_0$$
   其中 $\vec{F}_{\text{avg}}$ 是碰撞过程中乘驾人员受到的平均冲力， $\Delta t$ 是碰撞接触作用的时间， $\Delta \vec{p}$ 是乘员动量的变化量。
2. **分析过程**：
   * 在发生车祸碰撞的过程中，乘员从原行驶速度 $v_0$ 骤降到 0，其动量变化量 $\Delta \vec{p} = -mv_0$ 是一定的。
   * 如果没有安全气囊，乘员会直接撞击方向盘等硬物，接触时间 $\Delta t$ 极短，导致受到的瞬间冲击力 $\vec{F}_{\text{avg}} = \frac{\Delta \vec{p}}{\Delta t}$ 极大，从而造成严重伤害。
   * 弹出安全气囊后，人体撞击在柔软且有一定排气缓冲的安全气囊上，大大延长了碰撞接触作用的时间 $\Delta t$。
   * 由于 $\Delta \vec{p}$ 保持不变， $\Delta t$ 的增加必然使乘员受到的平均冲击力 $\vec{F}_{\text{avg}}$ 显著减小，从而起到了保护作用。

#### 题37【试卷二·大题37】
**题目**：耳机是同学们拥有的数码产品之一。除了听音乐，部分耳机还拥有降噪功能。降噪技术，可分为被动降噪和主动降噪。被动降噪，是通过遮挡噪声材料，如硅胶等多孔材料，将外界的噪音降低或绝缘，其本质是减弱或阻绝空气的振动；主动降噪技术，也叫消声降噪，一般是利用麦克风收集外界环境噪声，经数据处理器发出与噪声相位相反的声波来抵消噪声。请用本学期学过的大学物理（1）中的相关知识，对主动降噪物理原理作解释。（建议字数 50-200；可以使用图、公式进行辅助）

**解析**：
这道题应当使用 **波的相干叠加与相消干涉** 原理进行解释。
1. **波的相干叠加原理**：
   两列频率相同、振动方向相同、相位差恒定的相干波在空间相遇时，某些点的振动会始终加强，某些点的振动会始终减弱（即波的干涉现象）。
2. **消声（相消干涉）条件**：
   设噪声的声波为 $y_1 = A_1\cos(\omega t + \phi_1)$，主动降噪耳机发出的抵消声波为 $y_2 = A_2\cos(\omega t + \phi_2)$。
   为了达到消声效果，需要使两列波的相位相反（即相位差为 $\pi$ 奇数倍）：
   $$\Delta \phi = \phi_2 - \phi_1 = (2k+1)\pi \quad (k=0, 1, \dots)$$
   并且调节耳机发出的声波振幅使其接近噪声振幅：
   $$A_2 \approx A_1$$
3. **分析过程**：
   * 耳机外侧的麦克风实时收集环境噪声 $y_1$ 的波形和相位信息。
   * 降噪芯片快速计算出该噪声的特征，并通过耳机内的扬声器产生一列频率相同、振幅相同但**相位相反**（相位差为 $\pi$）的“补偿声波” $y_2$。
   * 这两列声波在耳道内发生相消干涉，合振幅几乎为零，从而使用户听不到环境噪声。
   $$y_{\text{total}} = y_1 + y_2 = A\cos(\omega t) + A\cos(\omega t + \pi) = 0$$

---
