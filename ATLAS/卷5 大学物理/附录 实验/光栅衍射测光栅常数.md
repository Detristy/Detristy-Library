# 光栅衍射实验报告

> 本实验利用衍射光栅的分光特性，通过测量钠光经光栅衍射后各级谱线的衍射角 $\varphi_k$，由光栅方程 $d\sin\varphi_k = k\lambda$ 测定光栅常数 $d$。本实验测得光栅常数平均值 $\bar d = 3.320\times10^{3}\ \text{nm}$，A 类不确定度 $u_A = 15\ \text{nm}$，即 $d = (3.320 \pm 0.015)\ \mu\text{m}$，对应刻线密度 $N = 301.2\ \text{条/mm}$，与标称值（300 条/mm）相对误差 $-0.39\%$。

## 1. 实验目的

1. 观察光栅衍射光谱，了解衍射光栅的分光原理与分光计的结构和使用方法。
2. 用分光计测定衍射光栅的光栅常数 $d$，加深对光栅方程的理解。
3. 掌握用分光计测量衍射角、用双游标读数消除偏心误差、用对称法消除零位误差等基本测量方法。

## 2. 实验原理

>[!definition] 光栅方程
> 当一束平行单色光垂直入射到光栅平面上时，光栅各狭缝发出的子波在衍射角 $\varphi_k$ 方向上相干叠加，形成各级衍射主极大，其满足光栅方程
>
> $$d\sin\varphi_k = k\lambda, \qquad k = 0, \pm 1, \pm 2, \cdots$$
>
> 其中 $d$ 为光栅常数（相邻两刻痕间的距离），$\lambda$ 为入射光波长，$\varphi_k$ 为第 $k$ 级衍射角（$k$ 级明纹与中央明纹之间的夹角），$k$ 为衍射级数。

由光栅方程可知，只要测得第 $k$ 级明纹对应的衍射角 $\varphi_k$，在入射光波长 $\lambda$ 已知时，即可求出光栅常数

$$d = \frac{k\lambda}{\sin\varphi_k}$$

本实验采用钠光灯作光源，取其双黄线（589.0 nm 与 589.6 nm）的平均波长 $\lambda = 589.3\ \text{nm} = 5.893\times10^{-4}\ \text{mm}$。

>[!important] 以 0 级为基准的衍射角测量
> 1. **以 0 级（中央明纹）为基准，双游标读数消除偏心差**：先测出中央明纹（$k=0$）在两个游标上的读数 $\theta_2$、$\theta_2'$ 作为基准；再分别测出 $+k$、$-k$ 级谱线在两个游标上的读数 $\theta_1$、$\theta_1'$。第 $k$ 级谱线相对中央明纹的单侧衍射角按教材式 $(25.3)$ 计算：
>
> $$\varphi_k = \frac{|\theta_1 - \theta_2| + |\theta_1' - \theta_2'|}{2}$$
>
> 式中 $\theta_1$、$\theta_1'$ 为第 $k$ 级谱线在两个游标上的读数，$\theta_2$、$\theta_2'$ 为 0 级（中央明纹）在两个游标上的读数。两个游标读数取平均可消除分光计刻度盘的偏心误差。
>
> 2. **对称测量消除零位误差**：由于衍射光谱关于中央明纹左右对称，实际测量时分别测出 $+k$、$-k$ 级相对 0 级的衍射角 $\varphi_{+k}$、$\varphi_{-k}$，第 $k$ 级衍射角取两侧平均：
>
> $$\varphi_k = \frac{\varphi_{+k} + \varphi_{-k}}{2}$$
>
> 两侧平均可消除中央明纹零位定位不准带来的系统误差。
>
> 3. **分光计最小分度**：游标读数分度值为 $1'$。

## 3. 实验仪器

- 分光计（附两个游标，最小分度 1′）
- 衍射光栅（300 线/mm，标称光栅常数 $d_0 = 1/300\ \text{mm} = 3333.3\ \text{nm}$）
- 钠光灯（$\lambda = 589.3\ \text{nm}$）
- 平行光管（狭缝）

## 4. 实验步骤

### 4.1 分光计与光路的调节

1. 按分光计使用规范调好分光计：使平行光管发出平行光，望远镜聚焦于无穷远并适合接收平行光，平行光管光轴与望远镜光轴均垂直于分光计中心转轴。
2. 将光栅放在载物台上，使光栅平面与平行光管轴线大致垂直；转动望远镜观察中央明纹，微调光栅，使衍射光谱与中央明纹基本处于同一水平面内（即狭缝与光栅刻痕平行）。

### 4.2 测量各级衍射谱线位置

1. 将望远镜由左向右（$-3, -2, -1, 0, +1, +2, +3$ 级）依次移动，用分划板十字竖线精确对准每条光谱线，并在两个游标上分别读数（记为 $\theta_k$、$\theta_k'$），记录于数据表。
2. 每条谱线均采用双游标读数，以消除刻度盘偏心误差。

### 4.3 数据处理

1. 度、分换算为十进制度。
2. 由教材式 $(25.3)$ 计算各级衍射角 $\varphi_k$。
3. 由 $d_k = k\lambda/\sin\varphi_k$ 逐级求光栅常数，取平均得 $\bar d$ 与刻线密度 $N$。
4. 计算 A 类不确定度，给出最终结果。

## 5. 实验数据

钠光经光栅衍射后，各级谱线在两个游标上的读数记录如下（0 级即中央明纹）：

| 衍射级数 $k$ | $-3$ | $-2$ | $-1$ | $0$ | $+1$ | $+2$ | $+3$ |
|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|

| 游标 2 读数 $\theta_k'$ | $125^\circ25'$ | $114^\circ03'$ | $103^\circ24'$ | $93^\circ14'$ | $83^\circ05'$ | $72^\circ30'$ | $60^\circ22'$ |

## 6. 数据处理与计算

### 6.1 角度单位换算

将原始读数的度、分换算为十进制度：

$$\theta(\text{小数度}) = \text{度} + \frac{\text{分}}{60}$$

| 衍射级数 $k$ | $-3$ | $-2$ | $-1$ | $0$ | $+1$ | $+2$ | $+3$ |
|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| $\theta_k$ / ° | 125.350 | 113.967 | 103.333 | 93.167 | 83.000 | 72.583 | 60.450 |
| $\theta_k'$ / ° | 125.417 | 114.050 | 103.400 | 93.233 | 83.083 | 72.500 | 60.367 |

### 6.2 以 0 级为基准求衍射角

先取中央明纹（0 级）在两个游标上的读数作为基准：

$$\theta_2 = 93^\circ10' = 93.167^\circ,\qquad \theta_2' = 93^\circ14' = 93.233^\circ$$

再按教材式 $(25.3)$ 计算各级谱线相对 0 级的单侧衍射角 $\varphi_k = \dfrac{|\theta_1 - \theta_2| + |\theta_1' - \theta_2'|}{2}$，$+k$、$-k$ 两侧各算一次后取平均。

以 $k = \pm 1$ 级为例：

$$\varphi_{+1} = \frac{|83.000 - 93.167| + |83.083 - 93.233|}{2} = \frac{10.167 + 10.150}{2} = 10.158^\circ$$

$$\varphi_{-1} = \frac{|103.333 - 93.167| + |103.400 - 93.233|}{2} = \frac{10.167 + 10.167}{2} = 10.167^\circ$$

$$\varphi_1 = \frac{\varphi_{+1} + \varphi_{-1}}{2} = \frac{10.158 + 10.167}{2} = 10.1625^\circ$$

各级结果如下：

| 衍射级数 $k$ | $\varphi_{+k}$ / ° | $\varphi_{-k}$ / ° | $\varphi_k$ / ° | $\sin\varphi_k$ |
|:---:|:---:|:---:|:---:|:---:|
| $1$ | 10.158 | 10.167 | 10.163 | 0.17644 |
| $2$ | 20.658 | 20.808 | 20.733 | 0.35402 |
| $3$ | 32.792 | 32.183 | 32.488 | 0.53712 |

### 6.3 逐级求光栅常数

由 $d_k = k\lambda/\sin\varphi_k$（$\lambda = 589.3\ \text{nm}$）：

$$d_1 = \frac{1\times589.3}{0.17644} = 3339.9\ \text{nm}$$

$$d_2 = \frac{2\times589.3}{0.35402} = 3329.2\ \text{nm}$$

$$d_3 = \frac{3\times589.3}{0.53712} = 3291.5\ \text{nm}$$

### 6.4 光栅常数平均值与刻线密度

$$\bar d = \frac{1}{3}\sum_{k=1}^{3} d_k = \frac{3339.9 + 3329.2 + 3291.5}{3} = 3320.2\ \text{nm} = 3.320\times10^{-3}\ \text{mm}$$

刻线密度（每毫米刻线数）：

$$N = \frac{1}{\bar d} = \frac{1}{3.320\times10^{-3}} = 301.2\ \text{条/mm}$$

### 6.5 A 类不确定度

$$u_A(d) = \sqrt{\frac{\sum_{k=1}^{n}(d_k - \bar d)^2}{n(n-1)}} = \sqrt{\frac{1295.9}{3\times2}} = 14.7\ \text{nm}$$

### 6.6 光栅方程的线性验证（附加）

光栅方程可改写为 $\sin\varphi_k = \dfrac{\lambda}{d}\,k$，即 $\sin\varphi_k$ 与 $k$ 成正比。以 $k$ 为横坐标、$\sin\varphi_k$ 为纵坐标作过原点最小二乘拟合 $y = mk$，得

$$m = 0.17827, \qquad r = 0.99996$$

由斜率可得 $d = \lambda/m = 3305.6\ \text{nm}$，与逐级平均 $\bar d = 3320.2\ \text{nm}$ 基本一致。相关系数 $|r| = 0.99996$ 非常接近 $1$，说明 $\sin\varphi_k$ 与 $k$ 的线性关系极好，光栅方程 $d\sin\varphi = k\lambda$ 得到定量验证。

## 7. 实验结果

| 物理量 | 测量值 | 不确定度 | 标称值 | 相对误差 |
|:---|:---:|:---:|:---:|:---:|
| 光栅常数 $d$ / nm | 3320.2 | 14.7 | 3333.3 | **−0.39%** |
| 刻线密度 $N$ / (条/mm) | 301.2 | — | 300 | −0.39% |

最终结果

$$d = (\bar d \pm u_A) = (3.320 \pm 0.015)\times10^{3}\ \text{nm} = (3.320 \pm 0.015)\ \mu\text{m}$$

## 8. 误差分析

本实验测得光栅常数 $\bar d = 3320.2\ \text{nm}$，与标称值 $3333.3\ \text{nm}$ 相对误差 $-0.39\%$，结果可靠。可能的误差来源分析如下：

1. **衍射角测量的瞄准误差（主要误差来源）**。用分划板十字竖线对准光谱线时，由于高衍射级（$+3$ 级）光谱强度较弱、谱线较暗，瞄准难度增大，导致读数存在主观偏差。从逐级结果看，$d_1 = 3339.9\ \text{nm}$ 与 $d_2 = 3329.2\ \text{nm}$ 仅差 $0.3\%$，而 $d_3 = 3291.5\ \text{nm}$ 相对偏离约 $1.2\%$，使三级结果分散度增大（样本标准差 $s = 25.5\ \text{nm}$），是 A 类不确定度的主要来源。

2. **光栅平面与入射光不严格垂直**。若光栅平面未精确垂直入射平行光，光栅方程 $d\sin\varphi = k\lambda$ 需修正为斜入射形式，会引入系统误差。

3. **狭缝与光栅刻痕不完全平行**。若狭缝方向与刻痕方向存在夹角，各级谱线不在同一水平面内，会带来谱线定位误差。

4. **钠光双黄线未完全分辨**。钠光 589.0 nm 与 589.6 nm 两条谱线波长接近，在低衍射级可能未能完全分开，瞄准的是两线的混合中心，本实验按平均波长 $\lambda = 589.3\ \text{nm}$ 处理，引入微小误差。

5. **仪器读数误差（B 类）**。分光计游标最小分度 $1'$，读数存在 $\pm 0.5'$ 量级的仪器误差，经传递后对 $d$ 的影响远小于 A 类不确定度，故本实验按教材规范仅以 A 类不确定度 $u_A$ 作为结果不确定度。

>[!important] 关键结论
> 本实验误差主要来自**随机性的人为瞄准/读数偏差**（尤其 $+3$ 级谱线较弱），而非仪器系统误差。对称测量法与双游标读数法已有效消除了零位误差和偏心误差，但无法消除高衍射级瞄准困难带来的随机误差。适当增加测量级数并多次重复读数，可有效降低 A 类不确定度。

## 9. 结论

1. 通过测量钠光衍射光谱各级谱线的衍射角，由光栅方程测得光栅常数 $d = (3.320 \pm 0.015)\ \mu\text{m}$（对应刻线密度 $N = 301.2\ \text{条/mm}$），与标称值 $3.333\ \mu\text{m}$（300 条/mm）相对误差 $-0.39\%$，结果在实验误差范围内，验证了光栅方程 $d\sin\varphi = k\lambda$。

2. 以 $\sin\varphi_k$ 对 $k$ 作过原点最小二乘拟合，得相关系数 $r = 0.99996$，线性关系极好，定量验证了衍射角与级数的正比关系。

3. 本实验综合运用了对称测量法（消除零位误差）、双游标读数平均（消除偏心误差）等基本测量方法，这些方法对提高角度测量精度效果显著，是光学角度测量实验中的常用技巧。
