# 光栅衍射实验报告

> 本实验利用衍射光栅的分光特性，通过测量钠光经光栅衍射后各级谱线相对中央明纹（0 级）的衍射角 $\varphi_k$，由光栅方程 $d\sin\varphi_k = k\lambda$ 测定光栅常数 $d$。本实验对 $-3,\,-2,\,-1,\,0,\,+1,\,+2,\,+3$ 七级谱线全部进行测量，以 0 级为基准，六个非零级逐级计算光栅常数，得平均值 $\bar d = 3.320\times10^{3}\ \text{nm}$，A 类不确定度 $u_A = 12\ \text{nm}$，即 $d = (3.320 \pm 0.012)\ \mu\text{m}$，对应刻线密度 $N = 301.2\ \text{条/mm}$，与标称值（300 条/mm）相对误差 $-0.39\%$。

## 1. 实验目的

1. 观察光栅衍射光谱，了解衍射光栅的分光原理与分光计的结构和使用方法。
2. 用分光计测定衍射光栅的光栅常数 $d$，加深对光栅方程的理解。
3. 掌握用分光计测量衍射角、用双游标读数消除偏心误差、以中央明纹为基准测量衍射角等基本方法。

## 2. 实验原理

>[!definition] 光栅方程
> 当一束平行单色光垂直入射到光栅平面上时，光栅各狭缝发出的子波在衍射角 $\varphi_k$ 方向上相干叠加，形成各级衍射主极大，其满足光栅方程
>
> $$d\sin\varphi_k = k\lambda, \qquad k = 0, \pm 1, \pm 2, \cdots$$
>
> 其中 $d$ 为光栅常数（相邻两刻痕间的距离），$\lambda$ 为入射光波长，$\varphi_k$ 为第 $k$ 级衍射角（$k$ 级明纹与中央明纹之间的夹角），$k$ 为衍射级数。

由光栅方程可知，只要测得第 $k$ 级明纹对应的衍射角 $\varphi_k$，在入射光波长 $\lambda$ 已知时，即可求出光栅常数

$$d = \frac{k\lambda}{\sin\varphi_k}$$

本实验采用钠光灯作光源，取其双黄线（589.0 nm 与 589.6 nm）的平均波长 $\lambda = 589.3\ \text{nm} = 5.893\times10^{-4}\ \text{mm}$。

>[!important] 衍射角的测量：以中央明纹为基准 + 双游标读数
> 1. **以 0 级为基准测量衍射角**：衍射角定义为第 $k$ 级明纹与中央明纹（0 级）之间的夹角。设 0 级游标读数为 $\theta_0$、$\theta_0'$，第 $k$ 级游标读数为 $\theta_k$、$\theta_k'$，则该级衍射角为两游标读数差值的平均（取平均可消除刻度盘偏心误差）：
>
> $$\varphi_k = \frac{|\theta_k - \theta_0| + |\theta_k' - \theta_0'|}{2}$$
>
> 2. **分光计最小分度**：游标读数分度值为 $1'$。角度读数以度（$^\circ$）、分（$'$）表示，测量与计算全程保持度分制。

## 3. 实验仪器

- 分光计（附两个游标，最小分度 1′）
- 衍射光栅（300 线/mm，标称光栅常数 $d_0 = 1/300\ \text{mm} = 3333.3\ \text{nm}$）
- 钠光灯（$\lambda = 589.3\ \text{nm}$）
- 平行光管（狭缝）

## 4. 实验步骤

### 4.1 分光计与光路的调节

1. 按分光计使用规范调好分光计：使平行光管发出平行光，望远镜聚焦于无穷远并适合接收平行光，平行光管光轴与望远镜光轴均垂直于分光计中心转轴。
2. 将光栅放在载物台上，使光栅平面与平行光管轴线大致垂直；转动望远镜观察中央明纹，微调光栅，使衍射光谱与中央明纹基本处于同一水平面内（即狭缝与光栅刻痕平行）。

### 4.2 测量各级衍射谱线位置

1. 将望远镜由左向右（$-3, -2, -1, 0, +1, +2, +3$ 级）依次移动，用分划板十字竖线精确对准每条光谱线，并在两个游标上分别读数（记为 $\theta_k$、$\theta_k'$），记录于数据表。
2. 每条谱线均采用双游标读数，以消除刻度盘偏心误差。

### 4.3 数据处理

1. 以中央明纹（0 级）为基准，计算六个非零级各自的衍射角 $\varphi_k$（全程保持度分制）。
2. 由 $d_k = |k|\lambda/\sin\varphi_k$ 逐级求光栅常数，取六值平均得 $\bar d$ 与刻线密度 $N$。
3. 计算 A 类不确定度，给出最终结果。

## 6. 数据处理与计算

### 6.1 衍射角的计算（以中央明纹为基准，度分制）

中央明纹（0 级）读数：游标 1 为 $93^\circ10'$，游标 2 为 $93^\circ14'$。

对每个非零级 $k$，由 $\varphi_k = \dfrac{|\theta_k - \theta_0| + |\theta_k' - \theta_0'|}{2}$ 计算衍射角（两游标平均消除偏心）。以 $-1$ 级为例：

$$|\theta_{-1} - \theta_0| = 103^\circ20' - 93^\circ10' = 10^\circ10'$$

$$|\theta_{-1}' - \theta_0'| = 103^\circ24' - 93^\circ14' = 10^\circ10'$$

$$\varphi_{-1} = \frac{10^\circ10' + 10^\circ10'}{2} = 10^\circ10'$$

六个非零级的衍射角计算结果如下（全程度分制）：

| 衍射级数 $k$ | $\theta_k - \theta_0$ | $\theta_k' - \theta_0'$ |    $\varphi_k$    | $\sin\varphi_k$ |
| :------: | :-------------------: | :---------------------: | :---------------: | :-------------: |
|   $-3$   |     $32^\circ11'$     |      $32^\circ11'$      |   $32^\circ11'$   |     0.53263     |
|   $-2$   |     $20^\circ48'$     |      $20^\circ49'$      | $20^\circ48'30''$ |     0.35524     |
|   $-1$   |     $10^\circ10'$     |      $10^\circ10'$      |   $10^\circ10'$   |     0.17651     |
|   $+1$   |     $10^\circ10'$     |      $10^\circ09'$      | $10^\circ09'30''$ |     0.17637     |
|   $+2$   |     $20^\circ35'$     |      $20^\circ44'$      | $20^\circ39'30''$ |     0.35279     |
|   $+3$   |     $32^\circ43'$     |      $32^\circ52'$      | $32^\circ47'30''$ |     0.54159     |

### 6.2 逐级求光栅常数

由 $d_k = |k|\lambda/\sin\varphi_k$（$\lambda = 589.3\ \text{nm}$），逐级计算：

| 衍射级数 $k$ | $d_k$ / nm |
|:---:|:---:|
| $-3$ | 3319.2 |
| $-2$ | 3317.7 |
| $-1$ | 3338.6 |
| $+1$ | 3341.3 |
| $+2$ | 3340.8 |
| $+3$ | 3264.3 |

以 $-1$ 级为例：

$$d_{-1} = \frac{1\times589.3}{0.17651} = 3338.6\ \text{nm}$$

### 6.3 光栅常数平均值与刻线密度

$$\bar d = \frac{1}{6}\sum d_k = \frac{3319.2 + 3317.7 + 3338.6 + 3341.3 + 3340.8 + 3264.3}{6} = 3320.3\ \text{nm} = 3.320\times10^{-3}\ \text{mm}$$

刻线密度（每毫米刻线数）：

$$N = \frac{1}{\bar d} = \frac{1}{3.320\times10^{-3}} = 301.2\ \text{条/mm}$$

### 6.4 A 类不确定度

$$u_A(d) = \sqrt{\frac{\sum_{k=1}^{n}(d_k - \bar d)^2}{n(n-1)}} = \sqrt{\frac{4336.9}{6\times5}} = 12.0\ \text{nm}$$

### 6.5 光栅方程的线性验证（附加）

光栅方程可改写为 $\sin\varphi_k = \dfrac{\lambda}{d}\,k$，即 $\sin\varphi_k$ 与 $k$ 成正比（注意 $\sin\varphi_{-k} = -\sin\varphi_{+k}$）。以 $k$ 为横坐标、$\sin\varphi_k$（含符号）为纵坐标作过原点最小二乘拟合 $y = mk$，得

$$m = 0.17827, \qquad r = 0.99996$$

由斜率可得 $d = \lambda/m = 3305.6\ \text{nm}$，与逐级平均 $\bar d = 3320.3\ \text{nm}$ 基本一致。相关系数 $|r| = 0.99996$ 非常接近 $1$，且正负级数据对称地分布在过原点直线两侧，说明 $\sin\varphi_k$ 与 $k$ 的线性关系极好，光栅方程 $d\sin\varphi = k\lambda$ 得到定量验证。

## 7. 实验结果

| 物理量 | 测量值 | 不确定度 | 标称值 | 相对误差 |
|:---|:---:|:---:|:---:|:---:|
| 光栅常数 $d$ / nm | 3320.3 | 12.0 | 3333.3 | **−0.39%** |
| 刻线密度 $N$ / (条/mm) | 301.2 | — | 300 | −0.39% |

最终结果

$$d = (\bar d \pm u_A) = (3.320 \pm 0.012)\times10^{3}\ \text{nm} = (3.320 \pm 0.012)\ \mu\text{m}$$

## 8. 误差分析

本实验测得光栅常数 $\bar d = 3320.3\ \text{nm}$，与标称值 $3333.3\ \text{nm}$ 相对误差 $-0.39\%$，结果可靠。可能的误差来源分析如下：

1. **衍射角测量的瞄准误差（主要误差来源）**。用分划板十字竖线对准光谱线时，由于高衍射级（$+3$ 级）光谱强度较弱、谱线较暗，瞄准难度增大，导致读数存在主观偏差。从逐级结果看，五个数据点 $d_k$ 集中在 $3318\sim3341\ \text{nm}$（分散约 $0.7\%$），而 $+3$ 级 $d_{+3} = 3264.3\ \text{nm}$ 明显偏低约 $1.7\%$，是数据分散的主要来源（样本标准差 $s = 29.5\ \text{nm}$）。

2. **光栅平面与入射光不严格垂直**。若光栅平面未精确垂直入射平行光，光栅方程 $d\sin\varphi = k\lambda$ 需修正为斜入射形式，会引入系统误差。

3. **狭缝与光栅刻痕不完全平行**。若狭缝方向与刻痕方向存在夹角，各级谱线不在同一水平面内，会带来谱线定位误差。

4. **钠光双黄线未完全分辨**。钠光 589.0 nm 与 589.6 nm 两条谱线波长接近，在低衍射级可能未能完全分开，瞄准的是两线的混合中心，本实验按平均波长 $\lambda = 589.3\ \text{nm}$ 处理，引入微小误差。

5. **仪器读数误差（B 类）**。分光计游标最小分度 $1'$，读数存在 $\pm 0.5'$ 量级的仪器误差，经传递后对 $d$ 的影响远小于 A 类不确定度，故本实验按教材规范仅以 A 类不确定度 $u_A$ 作为结果不确定度。

>[!important] 关键结论
> 本实验误差主要来自**随机性的人为瞄准/读数偏差**（尤其 $+3$ 级谱线较弱），而非仪器系统误差。以中央明纹为基准的测量法与双游标读数法已有效消除了零位误差和偏心误差，但无法消除高衍射级瞄准困难带来的随机误差。本实验对七级谱线全部测量、六值平均，样本量较充分，$u_A$ 相对较小；适当增加测量级数并多次重复读数，可进一步降低 A 类不确定度。

## 9. 结论

1. 通过对七级（$-3\sim+3$）谱线的全面测量，由光栅方程测得光栅常数 $d = (3.320 \pm 0.012)\ \mu\text{m}$（对应刻线密度 $N = 301.2\ \text{条/mm}$），与标称值 $3.333\ \mu\text{m}$（300 条/mm）相对误差 $-0.39\%$，结果在实验误差范围内，验证了光栅方程 $d\sin\varphi = k\lambda$。

2. 以 $\sin\varphi_k$ 对 $k$ 作过原点最小二乘拟合，得相关系数 $r = 0.99996$，正负级数据对称分布，线性关系极好，定量验证了衍射角与级数的正比关系。

3. 本实验综合运用了以中央明纹为基准的测量法（消除零位误差）、双游标读数平均（消除偏心误差）等基本测量方法，这些方法对提高角度测量精度效果显著，是光学角度测量实验中的常用技巧。
