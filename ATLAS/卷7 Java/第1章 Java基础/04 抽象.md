# 1. 抽象类
并不是所有的类都用于描绘对象，对于用于描述对象的信息不足的类，称之为抽象类。

抽象类因为可能无法使用足够的信息用于描述对象，因此是无法被实例化的，进一步地，抽象类的调用必须通过 [[03 继承]] 来实现。
# 2. 实现
## 2.1 abstract
使用 `abstract class` 来定义一个抽象类。

例如：
```java
abstract class Student{  
    private String name;  
    private int number;  
    public Student(){}  
    public Student(String name, int number){  
        this.name = name;  
        this.number = number;  
    }  
    public String getName(){  
        return this.name;  
    }  
    public int getNumber(){  
        return this.number;  
    }  
}
```

不难发现，对于一个抽象类而言，除了不能被实例化之外，和正常的类基本没有什么大的不同，构造和方法都是可以被正常声明和使用的。

## 2.2 抽象类的继承
如果我们要调用这个抽象类，我们就需要继承这个类。

```java
class Exam extends Student{  
    private double examScore;  
    public Exam(String name,int number,double score){  
        super(name,number);  
        setScore(score);  
    }  
    private void setScore(double score){  
        examScore = score;  
    }  
    public double getScore(){  
        return examScore;  
    }  
    public String getName(){  
        return super.getName();  
    }  
    public int getNumber(){  
        return super.getNumber();  
    }  
}
```

可以发现继承之后，抽象类 Student 里的方法和变量都是可以被正常调用的。

# 3. 抽象方法
对于一个方法，如果其实现由其子类确定，那么称这个方法为抽象方法。
抽象方法在父类中声明，仅声明方法名，而没有方法体。

抽象方法只能在抽象类中声明，因为其声明的时候没有方法体，因此对于子类而言，其必须实现抽象方法的方法体，否则子类也必须是抽象类。
## 3.1 声明
例如在父类中声明一个抽象方法 `printInfo` ，声明方法如下：
```java
public abstract void printInfo();
```
## 3.2 实现
对于一个非抽象子类，其必须实现这个抽象方法的方法体：
```java
public void printInfo(){  
    System.out.println(super.getName() + " " + super.getNumber() + " " + examScore);  
}
```
