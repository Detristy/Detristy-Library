# 1. 继承
对于两个并列的类，需要实现相同的功能，如果分别编写则会出现代码臃肿的情况。
此时我们不妨考虑将这些包含相同功能的代码段落都统一放在一个类里，需要的时候从这个类调用即可。

我们将此称为继承。

继承者称之为子类，被继承者称之为父类，通过继承，能够使子类具有父类的实例和方法，使得子类具有和父类相同的行为。
## 继承规则
1. Java允许单继承、多重继承、不同类继承同一个类，不支持多继承。
2. 子类拥有父类的非 private 的成员和方法。
3. 子类允许对父类进行扩展
# 2. 实现
## 2.1 关键字：extends & super
通过 `extends` 来实现对父类的继承，在子类中使用 `super` 关键字来访问父类成员。

```java
public class Main {  
    public static void main(String[] args){  
        Son s = new Son("NAME",114);  
        s.print();  
    }  
}  
  
class Father{  
    private String name;  
    private int id;  
    public Father(String myName,int myId){  
        name = myName;  
        id = myId;  
    }  
    public void print(){  
        System.out.println(name + " " + id);  
    }  
}  
  
class Son extends Father{  
    public Son(String myName,int myId){  
        super(myName,myId);  
    }  
    public void print(){  
        super.print();  
    }  
}
```

这里 Father 作为父类，Son 类通过 extends 继承 Father 类，在 Son 类的构造函数中，通过 super 关键字调用 Father 类的构造函数和 print() 函数。

## 2.2 关键字：this
`this` 是一个指向自己的引用。在两个变量命名冲突的时候可以通过添加 this 关键字来指示哪一个是属于自己的。

例如在上面的构造函数里，可以写成：
```java
public Father(String mame,int id){  
    this.name = name;  
    this.id = id;  
} 
```
这里的 `this.name` 和 `this.id` 所指向的就是 Father 类内部的变量 name 和 id，可以防止和函数的变量相混淆。

## 2.3 构造器
子类不继承父类的构造器，仅是调用。此时如果父类的构造并不是默认构造，则需要在子类的构造中显示调用父类的构造，例如：
```java
public Son(String myName,int myId){  
    super(myName,myId);  
}  
```
