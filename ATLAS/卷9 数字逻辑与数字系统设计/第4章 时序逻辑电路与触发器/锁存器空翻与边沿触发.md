# 1. 都能记住一个数，区别在哪里？

先想象一个只能显示0或1的小窗口。窗口外的数叫**输入**，窗口里已经记住的数叫**输出状态**。

本节先比较高电平有效的D锁存器与边沿D触发器。它们的区别，在于什么时候允许窗口里的数改变：

- **高电平有效的D锁存器**像一扇可打开的窗口：窗口开着时，外面变，里面就跟着变；关上后，保留最后看到的数。
- **边沿D触发器**像按一下取样按钮：只在指定的一次时钟跳变时取一个数，然后保存到下一次取样。

这是理解这两种D存储元件的**理想时序模型**。先用它分清“持续接收”和“取一次样”，再学习具体电路；RS、JK还要按各自的输入命令判断状态，不能直接套用“输出抄下输入”的说法。

> [!note] 本文的使用条件
> 暂不启动异步置位、清零功能，也就是不使用那些能绕过时钟、直接把状态改成1或0的控制端。若它们被激活，应先按异步控制规则处理。

## 1.1 先认三个字母

| 符号 | 可以怎样理解 |
| --- | --- |
| $D$ | 外面送来的数据，取0或1 |
| $Q$ | 元件现在记住的数，也就是输出 |
| $CP$ | 时钟或门控信号，用来决定什么时候接收数据 |

本节的D锁存器在 $CP=1$ 时开窗，$CP=0$ 时关窗。这个规则称为**高电平有效**：这里的“有效”就是允许接收数据。

# 2. 开窗期间，输入来回变会怎样？

假设一开始 $Q=0$。在同一个 $CP=1$ 区间里，输入按下面的顺序变化：

| 发生的事情 | $D$ | 锁存器的 $Q$ |
| --- | --- | --- |
| 窗口打开 | 0 | 0 |
| 输入变成1 | 1 | 跟着变成1 |
| 输入又变回0 | 0 | 跟着变回0 |
| 窗口关闭 | 0 | 保存0，之后不再跟随 |

输出在这一次开窗期间发生了两次变化：$0\rightarrow1\rightarrow0$。课件把这样的现象叫**空翻**：门控有效期间，$Q$ 发生两次或两次以上变化。

“开窗就跟随”在教材里也叫**透明**或**电平敏感**。它强调的是一整段有效时间，不是只在开窗的那一瞬间取一次样。

## 2.1 多次变化一定是坏事吗？

要看输入为什么改变。

| 输入变化的来源 | 怎样理解输出的多次变化 |
| --- | --- |
| 正常数据变化 | 锁存器按设计跟随输入，课件认为电路允许 |
| 异常干扰 | 干扰也可能被传到输出，造成不希望的状态变化 |

所以，**“出现空翻”不等于“器件坏了”**。问题是：如果我们只想一次取样，却用了会持续跟随的元件，就可能得到不想要的结果。

## 2.2 现在再看公式

把“当前记住的数”写成 $Q^n$，把“更新后记住的数”写成 $Q^{n+1}$。上标不是乘方，只是区分更新前后。

$$
Q^{n+1}=D\qquad(CP=1).
$$

读作：**门打开时，更新后的状态等于输入D**。这条式子在整个 $CP=1$ 区间内都起作用；$CP=0$ 时保持原状态。

# 3. 如果只想取一次样，就限定在时钟跳变时

时钟从0变成1，叫**上升沿**；从1变成0，叫**下降沿**。“沿”可以先理解为波形上的一次台阶跳变。

| 名称 | 时钟变化 | 记号 |
| --- | --- | --- |
| 上升沿，也叫正边沿 | $0\rightarrow1$ | $\uparrow$ |
| 下降沿，也叫负边沿 | $1\rightarrow0$ | $\downarrow$ |

如果一个D触发器规定在上升沿取样，那么上升沿时 $D=0$，它就记住0。之后即使 $D$ 在高电平期间先变1再变0，也不会像锁存器那样逐次跟随。

这就叫**边沿触发**：在指定边沿，根据输入和当前状态决定下一状态；其余时间保持。

> [!important] 取样一次，不一定翻转一次
> 如果原来是0，这次又取到0，输出仍然是0。课件的“每个脉冲变化一次”应理解为每个有效边沿至多更新一次状态，而不是每个边沿都必须从0变1或从1变0。

# 5. 接下来学什么？

课件接着介绍两条实现思路：

- [[主从触发器]]：用两个存储位轮流接收，让最终输出在交接时更新。
- [[边沿触发器]]：用维持阻塞型D、延迟型JK电路实现指定边沿更新。

主从结构需要额外留意：**最终输出在边沿更新，不代表内部也只在边沿接收输入**。特别是主从JK，可能记住整个高电平期间发生过的输入变化；这条限制会在下一篇用一个短例子解释。

# 6. 进阶补充与关联

> [!note]- 进阶：课件“空翻”一词的范围
> 本文按课件把有效电平期间的多次输出变化称为空翻。不能据此认定所有多次变化都是故障，也不应直接把它等同于其他教材中特指反馈回路反复翻转的概念。
