# 1. 数字系统

>[!definition] 定义
> **数字系统**：能对数字信号进行加工、传递和存储的实体，由实现各种功能的数字逻辑电路相互连接而成。数字计算机是最具代表性的数字系统。

数字逻辑是数字电路的理论基础，数字系统设计则是利用数字逻辑设计数字系统的过程。数字逻辑分为两大类：

- **组合逻辑电路**：由与门、或门、非门等门电路组合而成，**没有存储元件**；
- **时序逻辑电路**：由存储电路和门电路组成，**具有记忆能力**，至少包含一个存储元件。

> 表决器（少数服从多数）是组合逻辑的典型例子；电话拨号、号码锁的开启是时序逻辑的典型例子。

# 2. 模拟信号与数字信号

- **模拟信号**：连续变化的信号。自然界中可测的物理量（温度、压力、距离、时间、水位等）一般都是模拟量。
- **数字信号**：在时间上和数值上都是离散的信号，一般由模拟量经过**抽样、量化、编码**后得到。

>[!important]
> 模拟量 → 数字量的三步：**抽样**（时间离散）→ **量化**（数值离散）→ **编码**（用二进制表示）。

# 3. 模拟电路与数字电路

- **模拟电路**：处理模拟信号的电路，如音频有线扩音系统（麦克风 → 线性放大器 → 扬声器）。
- **数字电路**：处理数字信号的电路，能完成数字信号的算术运算和逻辑运算，故又称**数字逻辑电路**，如带数字显示的数字钟。

# 4. 数字电路的发展

| 阶段 | 器件 | 特点 |
|---|---|---|
| 1906 | 电子管（福雷斯特等） | 体积大、重、耗电大、寿命短；世界第一台计算机用 1.8 万只电子管、占地 170 m²、耗电 150 kW |
| 1948 | 晶体管（肖克利等） | 体积、重量明显优于电子管 |
| 1960 | 集成电路（IC） | 成千上万器件集成在一块芯片上，目前可达上亿等效门 |

按集成规模由小到大划分：**SSI**（小规模，100 元件以下）→ **MSI**（中规模，$<10^3$）→ **LSI**（大规模，$<10^5$）→ **VLSI**（超大规模，$10^5$ 以上）。

# 5. 数字电路的特点

1. **结构简单**：最基本只有「与」「或」「非」三种门电路，容易实现；
2. **稳定性好、可靠性高**：二值信号（只有 0 和 1 两种取值）允许较大的变化范围，抗干扰性强；
3. **可长期存储**：利用磁带、磁盘、光盘等媒介；
4. **集成度高、成本低**：众多基本单元做在同一块硅片上，便于大批量生产。

# 6. 研究方法：分析与设计

- **逻辑分析**：已知逻辑电路 → 求逻辑功能；
- **逻辑设计（逻辑综合）**：已知逻辑功能 → 求逻辑电路。

>[!important]
> 可编程逻辑器件（PLD）出现后，逻辑设计可用 EDA 软件编程烧录实现，不必再手工连线。但**布尔代数作为基本理论，仍是逻辑电路分析和设计的基本方法**。
