# 1. 基本公式

## 1.1 公理与基本公式

**交换律**

$$
A + B = B + A \qquad AB = BA
$$

**结合律**

$$
(A + B) + C = A + (B + C) \qquad (AB)C = A(BC)
$$

**分配律**（注意第二条是普通代数没有的）

$$
A(B + C) = AB + AC
$$

$$
A + BC = (A + B)(A + C)
$$

**0-1 律**

$$
A + 0 = A,\quad A + 1 = 1,\quad A \cdot 0 = 0,\quad A \cdot 1 = A
$$

**互补律**

$$
A + \bar{A} = 1 \qquad A \cdot \bar{A} = 0
$$

**对合律（还原律）**

$$
\bar{\bar{A}} = A
$$

**等幂律**

$$
A + A = A \qquad A \cdot A = A
$$

**吸收律**

$$
A + AB = A \qquad A(A + B) = A
$$

$$
A + \bar{A}B = A + B \qquad A(\bar{A} + B) = AB
$$

**包含律（多余项定律）**

$$
AB + \bar{A}C + BC = AB + \bar{A}C
$$

$$
(A + B)(\bar{A} + C)(B + C) = (A + B)(\bar{A} + C)
$$

即含 $BC$ 因子的项（或含 $(B+C)$ 因子的项）是**多余项**，可消去。

与-或形式的证明：

$$
\begin{aligned}
AB + \bar{A}C + BC &= AB + \bar{A}C + (A + \bar{A})BC \\
&= AB + \bar{A}C + ABC + \bar{A}BC \\
&= AB(1 + C) + \bar{A}C(1 + B) \\
&= AB + \bar{A}C
\end{aligned}
$$

推广：$AB + \bar{A}C + BCD(G+E) = AB + \bar{A}C$。

其中交换律、结合律、分配律、0-1 律、互补律是布尔代数的**公理**。

## 1.2 异或的常用公式

- 交换律：$A \oplus B = B \oplus A$
- 结合律：$(A \oplus B) \oplus C = A \oplus (B \oplus C)$
- 分配律：$A(B \oplus C) = AB \oplus AC$
- 0-1 律：$A \oplus 0 = A,\quad A \oplus 1 = \bar{A},\quad A \oplus A = 0,\quad A \oplus \bar{A} = 1$
- 反演律：$\overline{A \oplus B} = \bar{A} \oplus B = A \oplus \bar{B} = A \odot B$

## 1.3 与普通代数的区别

>[!warning] 与普通代数的区别
> - 布尔代数**没有减法和除法**（没有逆元），因此**消去律不成立**：由 $AB = AC$ 不能推出 $B = C$，由 $A + B = A + C$ 也不能推出 $B = C$；
> - $A + A = A$（**不是** $2A$），$A \cdot A = A$；
> - 分配律有两条，其中 $A + BC = (A + B)(A + C)$ 是普通代数所没有的。

# 2. 主要定理

## 2.1 德·摩根定理（反演律）

>[!definition] 定理 1　德·摩根（De Morgan）定理
> $$
> \overline{A \cdot B} = \bar{A} + \bar{B}
> $$
> $$
> \overline{A + B} = \bar{A} \cdot \bar{B}
> $$

口诀：**与的非 = 非的或；或的非 = 非的与**。

推广到多变量：

$$
\overline{x_1 x_2 \cdots x_n} = \bar{x}_1 + \bar{x}_2 + \cdots + \bar{x}_n
$$

$$
\overline{x_1 + x_2 + \cdots + x_n} = \bar{x}_1 \bar{x}_2 \cdots \bar{x}_n
$$

证明方法：

- **真值表法**：检查等式两边函数的真值表是否相等；
- **代数法**：应用已证明的公式、定理来推导；
- **数学归纳法**：$N = 2$ 时成立，设 $N = n$ 成立推 $N = n+1$。

## 2.2 香农定理

>[!definition] 定理 2　香农（Shannon）定理
> 任何函数的反函数（补函数），可以通过对该函数的所有变量取反，并将常量 1 换为 0、0 换为 1，运算符「+」换为「·」、「·」换为「+」而得到。

>[!warning] 注意
> 运用摩根和香农定理时，**与项变或项需要加括号**。

>[!example] 例 1
> 求 $F = AB + \bar{A}B(C + D)$ 的反函数。
>
> $$
> \begin{aligned}
> \bar{F} &= \overline{AB + \bar{A}B(C + D)} \\
> &= \overline{AB} \cdot \overline{\bar{A}B(C + D)} \\
> &= (\bar{A} + \bar{B})\left(\overline{\bar{A}B} + \overline{C + D}\right) \\
> &= (\bar{A} + \bar{B})(A + \bar{B} + \bar{C}\bar{D})
> \end{aligned}
> $$

## 2.3 香农展开定理（香农分解）

>[!definition] 定理 3　香农展开定理
> $$
> F(x_1, \dots, x_i, \dots, x_n) = \bar{x}_i\,F(x_1, \dots, 0, \dots, x_n) + x_i\,F(x_1, \dots, 1, \dots, x_n)
> $$
> $$
> = \left[x_i + F(x_1, \dots, 0, \dots, x_n)\right]\left[\bar{x}_i + F(x_1, \dots, 1, \dots, x_n)\right]
> $$

其中 $F(x_1, \dots, 0, \dots, x_n)$ 表示把 $x_i$ 置 0（其余变量不变）后所得的函数。即把函数按某个变量 $x_i$ 分解为 $\bar{x}_i$ 与 $x_i$ 两部分。

>[!example] 例 2
> $F = \bar{A}B + A\bar{B}\bar{C}$
>
> **以 A 为分解对象**：$F = \bar{A}F_1 + A F_2$，其中
> $$F_1 = F(A=0) = B,\qquad F_2 = F(A=1) = \bar{B}\bar{C}$$
>
> **以 C 为分解对象**：$F = \bar{C}F_1 + C F_2$，其中
> $$F_1 = F(C=0) = \bar{A}B + A\bar{B},\qquad F_2 = F(C=1) = \bar{A}B$$

# 3. 重要规则

## 3.1 代入规则

任何一个含有变量 $X$ 的逻辑等式，如果将所有出现 $X$ 的位置都代之以同一个逻辑函数 $F$，则等式仍然成立。

>[!example] 例 3
> 给定 $A(B + C) = AB + AC$，若用 $A + BC$ 代替 $A$，等式仍成立：
> $$
> (A + BC)(B + C) = (A + BC)B + (A + BC)C
> $$

## 3.2 对偶规则

>[!definition] 定义
> 将逻辑函数 $F$ 中所有的「×」变成「+」、「+」变成「×」、「0」变成「1」、「1」变成「0」，**变量保持不变**，所得的新函数 $F^d$ 称为 $F$ 的**对偶函数**。

即：「×、+、0、1、变量」→「+、×、1、0、不变」。

>[!warning] 注意
> 使用对偶规则时应保持原表达式中运算符的优先顺序不变；与项变或项时要加括号。

**对偶函数性质**：

- $F$ 与 $F^d$ 互为对偶函数，即 $(F^d)^d = F$；
- 若 $F = G$，则 $F^d = G^d$。

## 3.3 反演规则（香农定理）

>[!definition] 定义
> 将逻辑函数 $F$ 中所有的「×」变成「+」、「+」变成「×」、「0」变成「1」、「1」变成「0」，**原变量变成反变量、反变量变成原变量**，所得的新函数是原函数的反函数 $\bar{F}$。

即：「×、+、0、1、原变量、反变量」→「+、×、1、0、反变量、原变量」。

>[!warning] 注意
> 使用反演规则时应保持运算符优先顺序不变，与变或时要加括号。

>[!important] 对偶函数与反函数的关系
> 补函数和对偶函数在形式上只差变量的非：已知函数的对偶函数，只要将各变量取反即可得补函数；反之亦然。
>
> 例如对 $F = AB + \bar{A}B(C + D)$：
> $$
> F^d = (A + B)(\bar{A} + B + CD), \qquad \bar{F} = (\bar{A} + \bar{B})(A + \bar{B} + \bar{C}\bar{D})
> $$
> 可见 $\bar{F}$ 正是把 $F^d$ 中所有变量取反得到的。
