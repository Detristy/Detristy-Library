# 1. CMOS 的基本组成

CMOS 门电路采用 **NMOS 管与 PMOS 管**作为基本开关元件。课件概括其特点为：整体功耗较低，随着系列发展，工作速度不断提高。

# 2. 常见系列

| 系列 | 课件名称 | 理解要点 |
|---|---|---|
| 4000 | 基本 CMOS | 课件用来介绍宽电源电压范围 |
| HC | 高速 CMOS | 速度提高 |
| HCT | 与 TTL 兼容的高速 CMOS | “T”强调 TTL 输入电平兼容 |
| AC / ACT | 先进 CMOS | 更先进的系列；ACT对应 TTL 输入兼容版本 |

课件指出，同功能型号的 AC（ACT）与 HC（HCT）可具有相同的逻辑功能和引脚排列。**功能、引脚对应**与**所有电气条件均兼容**应分别理解。

# 3. 电源与逻辑电平

供电常记为 $V_{DD}$，地参考端也常见 $V_{SS}$。课件第37页给出标准 CMOS 的概述：

- 供电范围约 $3\sim18\text{ V}$；
- 逻辑0：电压不高于 $0.45V_{DD}$；
- 逻辑1：电压不低于 $0.55V_{DD}$。

>[!warning] 这些数值不适用于所有 CMOS 系列
> 以上是课件原述。宽电源范围不能直接套用于 HC、HCT、AC、ACT 等全部系列；45%/55%也不能作为所有 CMOS 器件的保证输入门限。实际门限应区分 $V_{IL}$ 与 $V_{IH}$，按器件和供电条件查表，例如 [TI CD4001B 数据手册](https://www.ti.com/lit/ds/symlink/cd4001b.pdf)。

本节要掌握的概念是：**逻辑0、1由电压范围承载；CMOS电平要求与系列和供电有关**，不能简单认为所有器件的逻辑1都等于固定的5 V。

# 4. 封装

CMOS 与 TTL 都可以采用 DIP 等封装。课件给出的实例是 **DIP-14 封装的六非门 CD4069**。

封装引脚的识别方法见 [[TTL集成逻辑门电路]]。外形相同只说明封装形式一致，内部逻辑功能仍由具体型号决定。

# 6. 与 TTL 的对照

| 项目 | TTL | CMOS |
|---|---|---|
| 课件举例的系列 | 74、74L、74S、74LS、74AS、74ALS等 | 4000、HC、HCT、AC、ACT等 |
| 常用电源符号 | $V_{CC}$ | $V_{DD}$ |
| 本课件关注的供电特点 | 标准 TTL 标称5 V | 不同系列的范围有差异 |
| 选用时要检查 | 功能、电平、负载、速度、功耗 | 功能、电平、负载、速度、功耗 |

>[!tip] 把逻辑层与器件层分开理解
> 同一个与非逻辑关系既能由 TTL 实现，也能由 CMOS 实现；逻辑表达式相同，并不意味着电源、电平与驱动参数相同。
