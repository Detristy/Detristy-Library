# 1. 竞争为什么可能造成毛刺

**竞争**：同一输入变化沿不同路径传播，到达汇合处的时间不同。**险象**：由路径延迟差引起不符合预期逻辑变化的短暂错误输出。

有竞争不一定有险象。课件将不产生错误输出的竞争称为非临界竞争，将产生错误输出的竞争称为临界竞争。瞬态结束后，组合电路仍恢复正确的稳定输出。

例：$F=AB+\bar AC$。当 $B=C=1$ 时，理想逻辑是 $F=A+\bar A=1$；若两条路径交接时都暂时为0，输出就产生负脉冲。

# 2. 险象分类与命名

| 分类依据 | 类型 | 输出表现 |
|---|---|---|
| 课件按错误脉冲极性命名 | “0”型险象 | 出现不应有的负脉冲 |
| 同上 | “1”型险象 | 出现不应有的正脉冲 |
| 输入变化前后的预期输出 | 静态险象 | 本应不变，却短暂跳变 |
| 同上 | 动态险象 | 本应改变一次，却在过渡中多次跳变 |

> [!warning] 两套“0/1”命名不要混用
> 常见“静态1险象”指本应保持1却掉到0，即本课件的静态“0”型；“静态0险象”指本应保持0却跳到1，即课件的静态“1”型。笔记优先用“负毛刺/正毛刺”说明现象。

# 3. 代数法：发现危险交接并补冗余项

对于常见两级实现，先找同时以原变量和反变量出现的变量；固定其他输入，检查能否形成 $X+\bar X$ 或 $X\bar X$。这表明具体实现**可能**因延迟差产生静态险象，不能仅凭代数恒等式认定任何实现都必有毛刺。

## 3.1 与或式增加冗余积项

$$XY+\bar XZ=XY+\bar XZ+YZ$$

增加 $YZ$ 不改变真值表，却使 $Y=Z=1$、$X$ 变化时有一个独立于 $X$ 的项保持输出1。

课件第87页：

$$F=\bar A\bar C+\bar AB+AC$$

当 $B=C=1$ 时，$F=\bar A+A$，可能有负毛刺。增加 $BC$：

$$\boxed{F_h=\bar A\bar C+\bar AB+AC+BC}$$

检查 $C$ 的变化时，其他输入固定后得到常量或单个文字，不存在同类静态危险交接。

## 3.2 或与式增加冗余和项

$$ (X+Y)(\bar X+Z)=(X+Y)(\bar X+Z)(Y+Z) $$

课件第88页：

$$F=(A+B)(\bar A+C)(\bar B+C)$$

- $B=C=0$，$A$ 改变：可能有正毛刺，增加和项 $(B+C)$。
- $A=C=0$，$B$ 改变：可能有正毛刺，增加和项 $(A+C)$。

$$F_h=(A+B)(\bar A+C)(\bar B+C)(B+C)(A+C)$$

这里增加的是**和项**；课件第88页文字写“冗余积项”与所列括号形式不符。

# 4. 卡诺图法

对与或式，每个积项对应一个1格圈。检查每一对逻辑相邻的1格是否被至少一个共同圈覆盖；若只分属不同圈而没有共同覆盖，单变量变化时可能发生负毛刺。

消除方法：增加冗余圈覆盖危险的相邻1格。边界与四角环绕相邻也要检查。对或与式，可直接检查相邻0格，或对补函数做同样的1格分析。

> [!note] 判断对象是实现，不只是函数值
> 同一张卡诺图可采用不同覆盖，因而得到不同的电路。必须结合题目已有卡诺圈或表达式判断。以下方法主要保证两级实现、一次一个输入变化时的静态险象处理，不能据此保证任意多输入同时变化或任意多级电路都无险象。

## 4.1 第90页例题

$$F=\bar AD+\bar AC+AB\bar C$$

当 $B=1,C=0,D=1$ 时改变 $A$，从最小项5切换到13（或反向），两格没有共同圈。增加 $B\bar CD$：

$$F_h=\bar AD+\bar AC+AB\bar C+B\bar CD$$

## 4.2 第91页例题与勘误

$$F=(A+B)(\bar B+C),\qquad \bar F=\bar A\bar B+B\bar C$$

补函数的两个圈之间可增加 $\bar A\bar C$，再取反得到：

$$\boxed{F_h=(A+B)(\bar B+C)(A+C)}$$

课件最后一行把新增因子写为 $(\bar A+C)$，与前一行德·摩根变换不符。正确新增和项为 **$(A+C)$**。例如 $A=1,B=0,C=0$ 时原函数为1，误写形式变为0，可直接发现它改变了功能。

# 5. 惯性延时与采样时机

课件第93页提出在输出端加RC低通环节抑制窄脉冲，时间常数 $\tau=RC$ 要足以衰减毛刺，又不能大到使正常信号畸变。

这是一种滤波思路，实际效果受脉冲宽度、负载及后级输入阈值影响；它不改变产生毛刺的逻辑结构。系统也可在信号充分稳定后采样，但采样时机需满足时序要求。

# 6. 复习要点

**稳态逻辑最简不等于瞬态最可靠。** 冗余项对真值表多余，对防止交接空隙却可能必要。第92页与第94页练习解析见 [[组合逻辑电路综合练习]]。
