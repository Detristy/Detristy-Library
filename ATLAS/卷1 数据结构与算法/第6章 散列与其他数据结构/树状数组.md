树状数组也称二元索引树，也以其发明者命名为芬威克树.
使用树状数组能够更好地解决包括但不限于：单点查询，单点修改，区间查询，区间修改的问题，也可以将其视作是一种前缀和和差分。
在介绍树状数组之前，先介绍刚刚提到的几种问题：

# 单点问题 区间问题

四个问题大致的形式如下：

给定一个数列 $a$ ，对数列进行如下操作：

1. 单点修改：给定 $x,y$ ，将 $a[x]$ 自增 $y$ ；
2. 区间修改：给定 $l,r,x$ ，将 $a[l,\cdots,r]$ 区间内所有元素自增 $x$ ；
3. 单点查询：给定 $x$ ，求 $a[x]$ 的值；
4. 区间查询：给定 $l,r$ ，求 $\sum^r_{i=l}a[i]$ 。

其实可以将单点问题视作区间为 1 的区间类型问题，不过接下来我们也会对单点问题单独讨论。

# 树状数组

对于一般的查询和修改，我们以 $O(n)$ 的复杂度遍历数组求解，但是这样太慢了，我们思考有没有一种方式可以压缩这个时间，那么我们不难想到尝试 $O(logn)$ 的复杂度，通过对数复杂度我们不难想到使用树这个结构，很明显， $logn$ 对应的就是树的层数。

在刚刚的思索中我们其实并不知道这个树需要怎么构造，所以我们接下来讨论这个问题。

不难发现， $c[i]$ 对应的是一些树状的前缀和。

如果我们将这些下标都转换成二进制：

即 $a[0001_2],a[0010_2],a[0011_2],a[0100_2]\cdots$

我们暂时不使用数学证明，直接用眼睛看，我们能够发现，二进制尾数是 1 的下标 $k$，对应的 $c[k]$ 在这颗树的底层，其实是 10 ，接着是 100，发现尾数的 0 越多对应的层数越高，最高层的 $c[8_{10}] = c[1000_2]$ ，而 $c[7_{10}] = c[0111_2]$ 能够印证我们的猜想，那么这是为什么呢？

## lowbit 函数

我们引入一个**管辖范围**的概念，很明显 $c[i]$ 是一段连续区间的和，图中 $c[4]$ 连接（包括间接连接）着 $c[1],c[2],c[3],c[4]$ ，也就是说 $c[4]$ 的管辖范围是 $c[1,2,3,4]$ ，那么对于 $c[i]$ ，我们需要求出其对应的管辖范围，考虑其可能与二进制有关。

于是我们引入一个数值 $lowbit(x)$ ，其代表数 $x$ 最低为的 1 及其后面所有的 0 构成的数值。

设整数 $x$ 可以用二进制表示为 $x_{10} = \dots 100\dots0$ ，其中最后一个 1 后跟着连续的 0 直到结尾，我们记这个连续的 0 的数量为 $k$ ，于是根据我们刚刚对 $lowbit(x)$ 的定义，我们可以写出：

$$  
lowbit(x) = 2^k  
$$

接着不难推出 $c[i]$ 的管辖范围为：

$$  
(x-lowbit(x),x]  
$$

我们怎么快速求出 lowbit 的值呢？不难想到，我们只需要数有多少个末尾 0 就可以了，于是我们可以将 $x$ 的二进制取反并且实施按位与运算，举个例子：

$$  
x = 1011011000_2  
$$

我们取 $x$ 的反码：

$$  
-x = 0100101000_2  
$$

接着我们按位与运算：

$$  
x \&(-x) = 0000001000_2  
$$

就能得出这个值对应的就是将 1000 转为十进制，结果为 8，计算机运行这个是特别快了，所以就不需要进行额外的数学运算，于是有：

$$  
lowbit(x) = x \& (-x)  
$$

## 父子关系

回到那张图，我们可以看出 $c[2]$ 是 $c[1]$ 的父亲， $c[4]$ 是 $c[2]$ 的父亲，不难发现两者间的距离跟 2 的幂次有关。

记 $x$ 的父亲为 $father(x)$ ，于是我们可以推出：

$$  
father(x) = x + lowbit(x)  
$$

因此我们接下来的查询和修改操作均可以在这个树中进行，对应的复杂度为 $O(logn)$ 。

## 板子

```cpp
struct BIT {  
    int t[500010];  
    int lowbit(int x) {  
        return x & -x;  
    }  
    void add(int x,int y) {  
        for (; x <= n ; x += lowbit(x)) t[x] += y;  
    }  
    int query(int x) {  
        int ans = 0;  
        for (; x ; x -= lowbit(x)) ans += t[x];  
        return ans;  
    }  
}t;
```
