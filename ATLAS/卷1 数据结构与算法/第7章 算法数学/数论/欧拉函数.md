# 定义

定义 $\phi(n)$ 为表示的是小于等于 $n$  且与 $n$ 互质的数的个数。

# 性质

1. $\phi(n)=n-1,n \text{ is prime}$ , $\phi(1)=1$ 。
2. $\phi(p^{k})=p^k-p^{k-1}=p^k\left( 1-\frac{1}{p} \right),p \text{ is prime}$
	证明：$p^k$ 的因子仅有 $p,2p,3p, \dots ,p^k$ ，共 $p^{k-1}$ 个。
3. $\phi(n)$ 是积性函数，$\phi(nm)=\phi(n)\phi(m)$ 。
4. 若 $n=\prod_{i=1}^s p_{i}^{k_{i}}$ ，则 $\phi(n)=n\prod_{i=1}^s\left( 1-\frac{1}{p_{i}} \right)$ 。
5. $n=\sum_{d|n}\phi(d)$ 。

# 筛法求欧拉函数

考虑通过筛法求质数，对于质数 $p$ ，有 $\phi(p)=p-1$ 。而对于合数，其会被最小的质因子筛掉。

考虑合数 $n$ 的欧拉函数值，设其最小的质因子为 $p_{1}$ ，那么有 $n'=\frac{n}{p}$ ，即 $n$ 会被 $n'p$ 筛掉。

考虑 $n'$ 和 $p$ 的关系：

1. 若 $n',p$ 互质，则：
	$$
	\phi(n)=\phi(n'p)=\phi(n')\phi(p)
	$$
	而 $\phi(n)$ 和 $\phi(p)$ 在前面被处理过了因此可以直接转移过来。
2. 若 $n',p$ 不互质（$n' \bmod p_{1} =0$），则：
	$$
	\phi(n)=n\prod_{i=1}^s\left( 1-\frac{1}{p_{i}} \right)
	$$
	其中 $n$ 用 $n'p_{1}$ 代替可以得到：
	$$
	\phi(n)=p_{1}\phi(n')
	$$

## 筛法求欧拉函数模板

```cpp
vector<int> pri;  
bool notPrime[N];  
int phi[N];   
  
void pre(int x) {  
    phi[1] = 1;  
    for (int i = 2 ; i <= x ; i++) {  
        if (!notPrime[i]) {  
            pri.push_back(i);  
            phi[i] = i-1;  
        }  
        for (int p : pri) {  
            if (i*p > x) break;  
            notPrime[i*p] = true;  
            if (!(i%p)) {  
            // 不互质的情形
                phi[i*p] = phi[i] * p;  
                break;  
            }  
            //互质情形
            phi[i*p] = phi[i] * phi[p];  
        }  
    }  
}
```

线性筛预处理欧拉函数的复杂度为 $O(n)$ 。
