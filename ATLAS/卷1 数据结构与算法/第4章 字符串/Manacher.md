Manacher 算法可以用于在 $O(n)$ 的时间内求字符串的最大回文子串。

我们考虑暴力，即对于每一个字符向两侧进行扩展，复杂度是 $O(n^{2})$ 的。但对于暴力算法而言仍然存在一个问题：对于奇数长度串而言，的确可以选择一个字符进行扩展，但对于偶数长度的回文串而言，其对称轴在中心两个字符之间，为了方便表示这个间隙，我们在每两个字符之间和串两端引入一个扩展字符，用于表示间隙。

例如字符串 `abcba` ，设定 `#` 作为扩展字符，那么我们就能得到 `#a#b$c#b#a#` ，我们称这个字符串为原串的扩展串，扩展字符可以任意选取不影响计算。

对于扩展串和原串，我们需要建立一个对应的双射。

可以证明，扩展串中回文串的回文半径可以与原串对应的回文串长度的关系是：
$$
	原串回文串长度=扩展串回文半径-1
$$
同时，扩展回文串结尾下标也和原回文串的终止位置存在对应关系：
$$
	原回文串终止位置=\frac{扩展回文串结尾下标}{2}
$$
我们建立一个回文数组 $p$ ，用于存储以对应下标处字符为中心的回文半径。
建立一个回文覆盖右边界 $r$ ，用于表示回文串无法覆盖的右侧第一个位置，随着回文串的扩展，当边界 $>r$ 时，$r$ 更新。$r$ 对应的回文串的回文中心为 $c$ 。

Manacher 对于遍历到的“当前字符” $i$ ，利用 $p,r,c$ 对暴力枚举进行加速，需要考虑下列四种情况：

#### $i= r$ ，以 $i$ 为中心直接扩展

例如 `#a#b#c...` ，初始时 $r=0,c=0$ ，此时下标为 $i=0$ ，$i=r$，因此以 $i$ 为中心扩展，此时 $r=1,c=0$ 。

#### $i<r$ ，$i$ 关于 $c$ 对称的下标 $2c-i$ 在大回文区域内

此时因为 $2c-i$ 处已经被访问过了，同时在 $c$ 的大回文区域内，由于回文对称性，$p_{i}=p_{2c-i}$ 。

```
(   [ . ]   c   [ . ]   ) r
      ↑2c-i       ↑i
```

#### $i<r$，$2c-i$ 在大回文区域外

```
     a  b        c  d
  [(  .  ] c       .  ) r
      ↑2c-i        ↑i
```

因为 ab 对称，bc 对称，所以 a=c 。又因为 ad 对称，所以 cd 对称。
因此 $i$ 为中心的回文半径为 $r-i$ 。

这个回文半径不能更大，例如

```
[#x#...#p(#b#c#b#d#p#...#x#]y#C#y#x#...#p#d#b#c'#b#)z#...
```

其中 c=c' 。如果回文半径更大，此时 p=z，但是 C 的回文半径在前面已经求出来不会更大是因为 p!=z ，此时就发生冲突了，因此 p 和 z 可以证明是一定不相等的，因此 c' 的回文半径不会更大。

#### $i<r$，$2c-i$ 在大回文区域的边界

此时 $i$ 的回文半径至少是 $r-i$ ，但是因为缺少了 $2c-i$ 在大回文区域外的限制，因此这个时候可以继续扩展，回文半径是有可能变得更大的。

# 模板

```cpp
int manacher(string s) {
    int mx = 0;
    n = s.length()*2+1;
    string t = "";
    for (char c : s) {
        t += '#';
        t += c;
    }
    t += "#";
    for (int i = 0,c = 0,r = 0 ; i < n ; i++) {
        int len = r > i ? min(p[2*c-i] , r-i) : 1;
        while (i+len < n && i-len >= 0 && t[i+len] == t[i-len]) len++;
        if (i + len > r) r = i + len, c = i;
        p[i] = len;
        mx = max(len,mx);

    }
    return mx-1;
}
```

len 是当前字符的回文半径。
