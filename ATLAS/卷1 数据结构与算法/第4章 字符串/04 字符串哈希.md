# 1. 字符串哈希
为了快速分辨两个字符串是否相同，我们不妨考虑通过一个哈希函数 $f$ 将字符串映射到一个整数上，这样就能通过两个字符串的哈希值进行比较。

最基础的哈希函数是进制哈希，即选取一个基础值 base，将字符串上的每一个数字都作为每一个进制位上的数字，哈希函数的形式大致如下。

```
hash(s) = s₀ × baseⁿ⁻¹ + s₁ × baseⁿ⁻² + ... + sₙ₋₁  (mod M)
```

其中为了减少哈希碰撞的概率， base 值的选择应尽量是质数。

另一个需要考虑的点是这个哈希值可能会非常大，此时可以考虑使用 unsigned long long 来自动在溢出时对哈希值取模，在C++中是对 $2^{64}$ 取模。

有的时候单哈希会被卡，此时我们可以考虑使用双哈希来解决。

# 2. 子串匹配
我们考虑一个模式串和一个主串的匹配：
```
S: a b d c f
T: d c
```
我们不妨使用字符串哈希算法来解决这个问题，假设我们选取基准值 $k$ ，则主串的哈希值为：
$$
	Hash(S)=[a]k^{4}+[b]k^{3}+[d]k^{2}+[c]k^{1}+[f]k^{0}
$$
模式串的哈希值为：
$$
	Hash(T)=[d]k^{1}+[c]k^{0}
$$
不难发现，$Hash(S)$ 减去前面 a 和 b 的部分和后面 f 的部分再除以 $k^{L}$ 就是 $Hash(T)$ ，其中 $L$ 是模式串的长度。
这和前缀和很相似，于是我们不妨考虑就当作前缀和来处理。

要使用前缀和，我们要预处理主串的各前缀的哈希值，用一个数组 $Ha$ 来维护，为了更方便地计算基准值的幂，我们也可以对之提前处理，用另一个数组 $Ba$ 来维护，于是就有：
$$
	Ha[i]=Ha[i-1]*b+S[i]-a+1
$$
其中 $a$ 是字符 a 的ASCII值。

而想要获取某一个区间内子串的哈希值，就可以快速通过下面这个式子获取，复杂度是 $O(1)$ 的：
$$
	Hash([l,r])=Ha[r]-Ha[l-1]*base^{r-l+1}
$$

因为获取子串的哈希值是 $O(1)$ 的，此时要想进行比对，我们只需要遍历一次主串即可，复杂度是 $O(N)$ 。
