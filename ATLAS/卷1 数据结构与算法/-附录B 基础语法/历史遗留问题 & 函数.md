# 1. 历史遗留问题

## 1.1 全局变量和局部变量的初始化问题

C++的变量大致可以根据声明位置分为两类：全局变量和局部变量。

全局变量在没有手动初始化的情况下默认初始化为 $0$ ；
局部变量在没有手动初始化的情况下是随机值，不排除可能为 $0$ 的情况。

例如：

```cpp
#include <iostream>  
using namespace std;  
  
void test() {  
    int a;  
    cout << a << '\n';  
}  
  
int main() {  
    for (int i = 0; i < 10; i++) {  
        test();  
    }  
}
```

## 1.2 数组大小与数据范围问题

1. 为了防止越界，通常需要将数组大小开到比题目所给的数据范围多 $10$  ~ $100$ 。

2. 不建议在局部变量区域开数组，原因：
	1. 因为是局部变量，在不初始化的情况下数组内部存储的容易是随机值
	2. 局部变量区域内存空间有限，数组开太大容易内存溢出 Overflow

3. 即便是在全局变量开内存，也不应开过大。对于某些题目看似可能对内存空间有特别大的要求，实际上可以通过某些方式优化，这里不展开。

## 1.3 变量类型和数据范围问题

对于某些题目，其数据量过大会导致答案超过 int 所能表示的数据范围，所以会出现 WA 的情况。
建议对于大部分题目，能开long long就开。

OI一场十年空，不开long long见祖宗。

## 1.4 局部变量的生命周期问题

局部变量也由不同的分支或者循环分成很多层，因为局部变量是代码块结束就删除的，因此代码块外部是无法访问代码块内部所声明的变量的。

## 1.5 bool 类型的相关使用问题

bool 类型虽然通常使用 true 或 false，但实际上 bool 类型的判定及其的松。
对于所有的非 0 值不论正负都属于 true ，只有 0 属于 false。

对于 if 语句中的条件判断，多数情况下可以进行优化。

例如可以把
```cpp
if(flag == true)
```
优化为
```cpp
if(flag)
```

虽然这种简化方式不是特别严谨，但是确实合法。

对应地也有
```cpp
if(flag == false) -> if(!flag)
```

# 2. 函数

## 2.1 函数的定义与函数的声明

```cpp
return_type FunctionName( parameter list ){
	body;
}
```

可以通过以上的语句定义一个函数，其中parameter list（参数表）是参与函数的参数，body是函数本体，return_type是函数的返回值，当不返回值的时候，函数的return_type为void

函数签名=函数名+参数表

可以直接通过

```cpp
return_type FunctionName( parameter list ) 
```

对所需要调用的函数进行声明，例如：

```cpp
int max( int a , int b )
```

就对返回值为整数的函数max进行了声明，其中int a和int b是参与max()运算的两个参数
## 2.2 函数的传值调用与返回值

## 2.3 函数的默认参数

函数的参数可以有默认值:

```cpp
返回值类型 函数名(形参 = 默认值){};
```

如果我们自己向函数传入了数据，就用自己的数据，如果没有，就用默认值

```cpp
#include <iostream>
using namespace std;

int func(int a, int b=10, int c=20); //声明一个函数

int main() {
    cout << func(10) << endl;
    cout << func(20,30) << endl;
    return 0;
}

int func(int a, int b, int c) {
    return a + b + c;
}
```

在这个例子中，两个cout分别输出：

```cpp
40
70
```

需要注意两个点：

- 如果某个位置有了默认值，那么从这个位置开始往右都必须要有默认值
- 如果函数声明中有了默认值，函数实现的时候就不能有默认参数

```cpp
#include <iostream>
using namespace std;

int func(int a, int b=10, int c=20); //声明一个函数

int main() {
    cout << func(10) << endl;
    cout << func(20,30) << endl;
    return 0;
}

int func(int a, int b=10, int c=20) { //函数的实现部分
    return a + b + c;
}
```

在上面的程序中函数的声明和函数的实现部分都有了默认值，两者会冲突导致程序报错

## 2.5 函数重载

允许函数名相同，可以提高函数的复用性

使用函数重载的时候需要满足函数在同一个作用域下，函数名称相同，参数类型/个数/顺序不同

例如：

```cpp
#include <iostream>
using namespace std;

int cal(int x,int y) {
    return x+y;
};
double cal(double x, double y) {
    return x+y;
}

int main () {
    int a1=1 , a2=2;
    double b1=3.1 , b2=4.5;
    int z = cal(a1,a2);
    cout << z << endl;
    double z2 = cal(b1,b2);
    cout << z2 << endl;

    return 0;
} 
```

上面的程序输出的结果为：

```cpp
3
7.6
```

可以看到因为a1，a2是int型，因此使用了int类型的cal()函数；而b1，b2是double型，因此使用了double类型的cal()函数
