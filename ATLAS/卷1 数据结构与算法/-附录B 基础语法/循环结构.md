# for 循环

for循环的语法：

```
for (起始 ; 条件 ; 迭代){ 
	执行语句; 
}
```

例如：

```cpp
for (int i = 1; i <= 5; i++) { // ① 起点 i=1 ② 条件 i<=5 ③ 每次 i+1 
	cout << i << " "; // 循环体：重复做的事 
}
```

# do-while 循环

do-while 循环的语法：

```
do{ 
	执行语句; 
}while(条件);
```

需要注意的是，while跟在do后面，因此在判断循环条件真假前，循环内的语句一定会先被执行一次。

# continue 语句
