https://www.luogu.com.cn/problem/P1896

对于这个棋盘，国王的位置会影响周围八格，我们把这个影响范围分为两部分：对国王所在行上的影响以及对国王所在相邻行上的影响。

考虑使用状压DP，对于一行上的整体状态，我们可以用一个参数的二进制位来存储放国王或不放的情况，例如：放 不放 放，就可以用 1 0 1 来表示。

每一个状态参数中 1 的个数就是当前状态放的国王个数。

1. 对于国王所在当前行的状态
    
    我们知道国王和国王不能在相邻的格子上放置，也就是说，对于当前行对应的字符串，不能出现相邻的两个 1，用位运算判断的方法如下。
    
    将当前的字符串往前移动一位与自己进行与运算，如果值不为 0 说明存在相邻的情况，我们排除掉。
    
    ```cpp
    s1    =   1 0 1 1 0 1 0
    s1<<1 = 1 0 1 1 0 1 0 0
                  ↑ 出现重复的 1，不合法
    ```
    
2. 对于相邻行的状态
    
    明显地，要判断这一行的状态，我们要从上一行的状态转移过来，对于上一行放置的国王，它的影响范围是这一行对应位置的左侧一格，当前格和右侧一格。
    
    ```cpp
    o o o x o o o //-> x 的位置放置了国王
    o o ! ! ! o o //-> ! 的位置不能放置国王
    ```
    
    我们可以将上一行的状态 s1 和当前行的状态 s2 进行比对，合法的状态要满足： `s1&s2 s1&s2>>1 s1&s2<<1` 都为 0 。
    

对于第一个状态，我们可以预处理到底有多少种状态是合法的，对于第二个状态，我们可以在 dp 的时候枚举判断。

定义 $dp[i][j][k]$ 为第 $i$ 行放置 $j$ 个国王，且第 $i$ 行的状态参数为 $k$ 的总方案数。

设第 $i-1$ 行一共放了 $m$ 个国王，上一行的状态为 $p$ ，若 $k$ 是合法的状态，则状态转移方程为：

$$
	dp[i][j][k]=dp[i][j][k]+dp[i-1][j-m][p]
$$
