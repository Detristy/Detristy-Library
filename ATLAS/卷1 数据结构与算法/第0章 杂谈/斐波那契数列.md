
状态转移：
$$
	f(x)=f(x-1)+f(x-2)
$$
考虑递归搜索：

```cpp
int dfs(int x) {  
	if (x < 0) return 0;
    if (x == 0 || x == 1) return x;  
    return dfs(x - 1) + dfs(x - 2);  
}
```

递归搜索会搜索很多重复的部分，因此对于重复的部分可以利用一个辅助数组打标记，即记忆化搜索：

```cpp
int a[100010];  
  
int dfs(int x) {  
    if (x < 0) return 0;  
    if (x == 0 || x == 1) return x;  
    if (a[x]) return a[x];  
    return a[x] = dfs(x - 1) + dfs(x - 2);  
}
```

改成不需要递归的方式（迭代）：

```cpp
constexpr int N = 1e5+10;  
int a[N];  
  
void solve() {  
    int n;  
    cin >> n;  
    a[0] = 0;  
    a[1] = 1;  
    for (int i = 3 ; i <= n ; i++) {  
        a[i] = a[i-1] + a[i-2];  
    }  
    cout << a[n] << endl;  
}
```
