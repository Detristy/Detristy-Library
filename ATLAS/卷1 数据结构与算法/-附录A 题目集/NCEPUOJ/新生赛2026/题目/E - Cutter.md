## 题目描述
给定一个长度为 $n$ 的字符串 $A$。选择整数 $k$（$0 \le k < n$），从第 $k+1$ 个字符前将 $A$ 切开，把后一段移到前一段前面，得到一个新字符串。特别地，$k=0$ 时得到的就是 $A$ 本身。这样得到的字符串称为 $A$ 的第 $k$ 个循环移位，记作 $A_k$。
给定一个长度为 $m$ 的字符串 $B$（保证 $m \le n$）。请统计有多少个整数 $k$（$0 \le k < n$），使得 $A_k$ 的前 $m$ 个字符构成的字符串恰好等于 $B$。
若不同的 $k$ 得到相同的字符串，仍分别计数。
## 输入格式
第一行输入两个整数 $n,m$，分别表示字符串 $A$ 与 $B$ 的长度。
第二行输入一个长度为 $n$ 的字符串 $A$。
第三行输入一个长度为 $m$ 的字符串 $B$。
## 输出格式
输出一行一个整数，表示满足条件的 $k$ 的个数。
## 样例
### 样例输入 #1
```text
4 2
abab
ab
```
### 样例输出 #1
```text
2
```
### 样例输入 #2
```text
5 3
abcde
ace
```
### 样例输出 #2
```text
0
```
## 说明/提示
### 样例解释
样例 1 中，从各个位置开始按循环顺序取 $2$ 个字符：
- $k=0$：`ab`；
- $k=1$：`ba`；
- $k=2$：`ab`；
- $k=3$：`ba`。
其中 $k=0$ 与 $k=2$ 得到的字符串都是 `ab`，所以答案为 $2$。虽然这两个 $k$ 得到的字符串相同，但仍分别计数。
样例 2 中，从各个位置开始按循环顺序取 $3$ 个字符，得到的字符串依次为 `abc`、`bcd`、`cde`、`dea`、`eab`，它们都不等于 `ace`，所以答案为 $0$。
### 数据范围
对于 $30\%$ 的数据，$1 \le m \le n \le 5 \times 10^3$。
对于 $100\%$ 的数据，$1 \le m \le 2 \times 10^4$，$m \le n \le 10^5$，且 $A,B$ 均只含小写英文字母。
### 提示
`substr()` 用于从字符串中截取一段，返回一个新的字符串，不会修改原字符串。
基本用法：
```cpp
s.substr(pos, len)  // 从下标 pos 开始，截取 len 个字符
s.substr(pos)       // 从下标 pos 开始，一直截取到字符串末尾
```
例如：
```cpp
string s = "abcde";
s.substr(2, 3);  // "cde"
s.substr(2);     // "cde"
s.substr(0, 2);  // "ab"
s.substr(5);     // ""
```
