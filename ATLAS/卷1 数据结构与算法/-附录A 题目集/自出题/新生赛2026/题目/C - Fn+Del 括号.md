## 题目描述
定义：
- 空串是“合法”的；
- 若字符串 $A$ “合法”，则 $\texttt{(}A\texttt{)}$ 是“合法”的；
- 若字符串 $A$ 与 $B$ 均“合法”，则字符串 $A+B$ 是“合法”的，其中 $+$ 表示两个字符串的拼接。
给定一个只由 `(` 和 `)` 组成的字符串 $s$。你可以进行任意次插入操作，也可以不进行操作。每次操作可以在字符串的任意位置（包括开头和末尾）插入一个 `(` 或 `)`。
求使字符串变为“合法”字符串所需插入的最少括号数。

## 输入格式
输入共两行。
第一行输入一个整数 $n$，表示字符串 $s$ 的长度。
第二行输入一个长度为 $n$、仅含 `(` 和 `)` 的字符串 $s$。
## 输出格式
输出一行一个整数，表示最少需要插入的括号数。
## 样例
### 样例输入 1
```text
3
())
```
### 样例输出 1
```text
1
```
### 样例输入 2
```text
3
)((
```
### 样例输出 2
```text
3
```
## 说明/提示
### 样例解释
样例 $1$ 中，在 `())` 的开头插入一个左括号，得到合法字符串 `(())`，因此最少插入 $1$ 个括号。
样例 $2$ 中，对 `)((` 的开头插入一个 `(`，并在末尾插入两个 `)`，得到合法字符串 `()(())`。可以证明不存在插入少于 $3$ 个括号的方案，因此答案为 $3$。
### 数据范围
对于 $20\%$ 的数据，$1 \le n \le 10^2$。
对于 $100\%$ 的数据，$1 \le n \le 10^5$。
其中 $n=|s|$，且 $s$ 仅由 `(` 和 `)` 组成。
