## 题目背景
哥德巴赫猜想认为任一大于 $2$ 的偶数都可写成两个素数之和，目前还没有被证明，请你写一个程序验证小范围内哥德巴赫猜想的正确性。
## 题目描述
本题有多组数据。
对于每组数据，给定一个偶数 $n$，将它分解为两个素数 $a$ 和 $b$ 之和。由于解可能不唯一，假定 $a \le b$，请输出 $a$ 最小的那一组解。
## 输入格式
第一行输入一个整数 $T$，表示数据组数。
接下来 $T$ 行，每行输入一个偶数 $n$。
## 输出格式
输出 $T$ 行。
每行依次输出两个整数 $a$ 和 $b$ 表示答案。 
## 样例
### 样例输入 #1
```text
3
4
6
10
```
### 样例输出 #1
```text
2 2
3 3
3 7
```
### 样例输入 #2
```text
3
20
30
100
```
### 样例输出 #2
```text
3 17
7 23
3 97
```
## 说明/提示
### 数据范围
对于 $50\%$ 的数据，$4 \le n \le 5 \times 10^4$。
对于 $100\%$ 的数据，$1 \le T \le 2 \times 10^5$，$4 \le n \le 10^6$，$n$ 为偶数。
### 样例解释
- **样例 #1**：$4 = 2 + 2$；$6 = 3 + 3$；$10 = 3 + 7$（$5 + 5$ 也合法，但 $3 < 5$，所以取 $3 + 7$）。
- **样例 #2**：$20 = 3 + 17$，虽然 $7 + 13$ 也合法，但 $3$ 更小；$30 = 7 + 23$，因为 $3 + 27$、$5 + 25$ 中的 $27$、$25$ 都不是素数；$100 = 3 + 97$。
