# 贪心做法

可以模拟，注意到每一次交换，相当于对上下异或和同时异或上 $a_{i} \oplus b_{i}$ 。每一个人采取贪心策略即可。

# 注意力做法

设数组的异或和分别为 $S_{a},S_{b}$ ，可以知道 $S_{a}\oplus S_{b}$ 的值无论如何交换都不会改变。

如果结果为 $0$ ，那么如何交换都是平局。

那么最后一个改变双方结果的机会在谁手中，谁就能将 $0$ 改成 $1$ ，如果是 $1$ 也可以选择不换，那么此时胜利情况与前面的选择无关。
