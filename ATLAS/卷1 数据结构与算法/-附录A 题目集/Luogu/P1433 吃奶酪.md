这是一个TSP问题，考虑状压DP解决。
对于全体奶酪，我们用一个参数 $A$ 的二进制位状态表示，1 表示吃过了，0 表示没吃过。

接着在奶酪之间转移即可，转移方式如下：

1. 让当前参数第 $i$ 个奶酪的状态由 0 变 1：
	```cpp
	int nxt = i | (1<<(k-1));
	```
2. 转移更新最短路
	```cpp
	 dp[nxt][k] = min(dp[nxt][k], dp[i][j] + dis[j][k]);
	```

实现细节部分：

1. 需要在转移之前考虑当前的奶酪是否被吃过，吃过则不能转移。同时需要考虑当前位置是否能到达。

2. 我们需要初始化从 $(0,0)$ 到每个奶酪初始位置（对应参数信息为 `dp[1 << (i-1)][i] = dis[0][i];`）

3. 最终答案要从遍历了所有奶酪的状态中枚举每个奶酪作为终点的可能性取最值。
