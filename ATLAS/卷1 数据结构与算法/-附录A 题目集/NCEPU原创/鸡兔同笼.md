# 题目背景

第九空忆喜欢看《孙子算经》，书中记载了一道非常著名的数学趣题：“今有雉兔同笼，上有三十五头，下有九十四足，问雉兔各几何？”  

第九空忆轻松把这个问题解了出来，不过他反问你能否写一个程序，快速计算出鸡和兔子各有多少只。

# 题目描述

已知笼中鸡和兔子的总数为 $n$ ，它们脚的只数一共为 $m$ ，且：

* 每只正常的鸡有 $1$ 个头、$2$ 只脚；
* 每只正常的兔子有 $1$ 个头、$4$ 只脚；
* 不存在变异的动物（没有三条腿或三个头的动物）。

请你根据输入的头数 $n$ 和脚数 $m$，计算笼中分别有多少只鸡和兔子。如果给出的数据无解，请输出 `No Solution`。

# 样例

#### 样例 1

输入：

```
35 94
```

输出：

```
23 12
```

#### 样例 2

输入：

```
10 25
```

输出：

```
No Solution
```

# 说明/提示

Subtask 划分如下：

对于 100% 的数据，$0 \le n, m \le 10^5$。

| 子任务 | 分值 | 数据范围 | 特殊性质 |
|:------:|:----:|:--------:|:--------:|
| Subtask 1 | 20 | $0 \le n \le 10$，$0 \le m \le 40$ | 保证有解 |
| Subtask 2 | 30 | $0 \le n, m \le 10^5$ | 保证有解 |
| Subtask 3 | 50 | $0 \le n, m \le 10^5$ | 无特殊限制 |

其中「保证有解」指输入数据满足 $2n \le m \le 4n$ 且 $m$ 为偶数。
