## 题目背景

光 (Hikari)。
对立 (Tairitsu)。

假设她们知晓对方的名字，甚至仅仅是清楚自己本人的姓名——若真如此，
二人自始至今的感受也会发生改变吗？
"光"与"对立"……存在于这片光怪陆离的世界之中，此般崇高的称呼……
若真如此，她们是否又会静下心来思考蕴藏于自己姓名的深层含义——也会走上截然不同的道路吗？

抑或者无论发生何种分歧、矛盾，无论曾经做出哪些抉择，在何时得到幸运的眷顾——
随之产生偏移的世界线，却终将收束至二人此刻的水火不容？

光并不会知晓确切的答案。她直至如今都不知道自己的名字。
而在这相同的前提下，对立却命中注定被自己的知识所诅咒。
她心中早已清楚，二人间的这场针锋相对，无论如何都会来临。

不可能会产生任何改变。原本一切就不会发生改变。
白衣少女与黑衣少女，绝不可能和睦相处……

## 题目描述

光和对立开启了一场只属于她们的战争，两位少女将装有“记忆”的“碎片”化作武器相互攻击。

战场上一共存在 $n$ 个“碎片”，每 $2$ 或 $3$ 个“碎片”可以组成一件武器，每件武器只能属于光或属于对立，她们都非常希望取得胜利，因此所有的“碎片”都会被用于组成武器。

光没有作战经验，因此求助于你。她想知道她和对立双方所拥有的“碎片”数量的最小差值。

## 输入格式

每个测试由多个测试数据组成。第一行包含一个整数 $t$，表示测试数据数。下面 $t$ 行描述测试用例。

对于每组测试数据，输入一行一个整数 $n$，表示战场上“碎片”的数量，每组测试数据相互独立。

## 输出格式

对于每组测试样例，输出光和对立所拥有的“碎片”数量差的可能最小值。

每组样例之间用换行分隔。

## 输入输出样例 #1

### 输入 #1

```
3
2
5
12
```

### 输出 #1

```
2
1
0
```

## 说明/提示

【样例说明】

在第一个测试案例中，两位少女只能组成一件武器，只有一位少女能拥有武器，而另一位少女没没有武器，所以答案是 $2$ 。

【数据范围】

对于所有的测试用例，保证：

$1≤t≤10^4$ , $2\leq n \leq 10^4$ .
