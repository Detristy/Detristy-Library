# 1. 棋盘上的状压DP

对于棋盘上某组物品选或不选的状态依赖于前一组物品的总体状态的时候，我们可以通过设计一个参数 $A$ ，利用 $A$ 的二进制位信息来进行表达物品的选择状态，其中通常用 0 表示不选择，1 表示选择。

对于 $k$ 个样本而言，其具有 $2^{k}$ 个状态，因此参数 $A$ 的取值范围是 $[0,2^{k}-1]$ 。因为状态数量是指数级增长的，所以通常样本量都不大（通常在20个以内）。

# 2. 旅行商问题

引入一个问题：假设一个快递员要给 $N$ 个站点送货，每个站点去且仅去一次，最后要求回到出发点，求最短总路程。

因为对于每一个站点而言，其只有两种状态：去了/没去，并且我们实际上并不关心站点之间的到达顺序，因此我们可以尝试用一个参数 $A$ 的二进制位状态来表示，0 表示没去过，1 表示去过了。

以这个问题为例，定义 $dp_{i,j}$ 为在访问了参数 $i$ 中的城市的访问状态下处于站点 $j$ 走过的最短距离。

接下来我们考虑转移，从当前城市 $j$ 走到另一个没有访问过的城市 $p$ 。转移分为两步：

1. 将 $j$ 标记为访问过，具体做法是将参数 $i$ 中二进制位中第 $j$ 位标记为 $1$ ：
	```cpp
	ii = i | (1 << j);
	```
2. 更新城市 $p$ 的状态取最值，状态转移方程为：
	$$
	dp_{ii,p}=\min(dp_{ii,p},dp_{i,j}+dis_{j,p})
	$$
	
	其中 $dis_{j,p}$ 表示从城市 $j$ 到达城市 $p$ 的距离。
