# 1. 极值的直观来源

一元函数求极值：求导 → 找驻点 → 判单调性/二阶导。多元函数的思路完全一致，只是"求导"变成"求梯度"，"二阶导"变成"Hessian 矩阵"。

极值问题的两个层次：
- **无条件极值**：在整个定义域上找极值（自由极值）
- **条件极值**：在某个约束条件 $g(x,y)=0$ 下找极值（[[方向导数 梯度|拉格朗日乘数法]]）

而**最值**则是在一个**闭区域**上，比较所有极值点和边界点，挑出最大最小。

# 2. 无条件极值

## 2.1 极值的定义

>[!definition] 定义 1（极值）
> 设 $z = f(x,y)$ 在点 $P_0(x_0, y_0)$ 的某邻域内有定义。若对该邻域内所有异于 $P_0$ 的点 $(x,y)$，恒有：
>
> $$
> f(x,y) < f(x_0, y_0) \quad\text{（严格小于）}
> $$
>
> 则称 $f(x_0, y_0)$ 为**极大值**，$P_0$ 为**极大值点**。
>
> 类似地，若 $f(x,y) > f(x_0, y_0)$，则称为**极小值**和**极小值点**。
>
> 极大值和极小值统称**极值**；极大值点和极小值点统称**极值点**。

>[!warning] 注意
> 极值是**局部**概念——只要求在某个小邻域内最大/最小，不是全局的。一个函数可以有多个极大值，它们之间的大小没有必然关系。

## 2.2 极值的必要条件

>[!corollary] 定理 1（极值的必要条件）
> 若 $z = f(x,y)$ 在点 $(x_0, y_0)$ 处取得极值，且两个偏导数都存在，则必有：
>
> $$
> f_x(x_0, y_0) = 0,\qquad f_y(x_0, y_0) = 0
> $$
>
> 即 $\nabla f(x_0, y_0) = \boldsymbol{0}$。
>
> 满足 $f_x = 0$ 且 $f_y = 0$ 的点称为**驻点**（或**稳定点**）。

这与一元函数"极值点必为驻点"一致。但注意：

>[!warning] 驻点不一定是极值点
> 经典反例：$z = xy$ 在 $(0,0)$ 处 $f_x = y|_{(0,0)} = 0$，$f_y = x|_{(0,0)} = 0$，是驻点。但在 $(0,0)$ 附近，第一、三象限 $xy > 0$，第二、四象限 $xy < 0$，函数值可正可负——$(0,0)$ 不是极值点，而是**鞍点**。

## 2.3 极值的充分条件（Hessian 判别法）

有了驻点，如何判断它是不是极值点？看二阶偏导数。

>[!corollary] 定理 2（极值的充分条件）
> 设 $z = f(x,y)$ 在点 $P_0(x_0, y_0)$ 的某邻域内具有**连续的二阶偏导数**，且 $P_0$ 是驻点（$f_x = f_y = 0$）。记：
>
> $$
> A = f_{xx}(x_0, y_0),\quad
> B = f_{xy}(x_0, y_0),\quad
> C = f_{yy}(x_0, y_0)
> $$
>
> 并定义判别式 $\Delta = AC - B^2$（即 Hessian 矩阵的行列式），则：
>
> 1. 若 $\Delta > 0$ 且 $A > 0$，则 $f(x_0, y_0)$ 是**极小值**；
> 2. 若 $\Delta > 0$ 且 $A < 0$，则 $f(x_0, y_0)$ 是**极大值**；
> 3. 若 $\Delta < 0$，则 $f(x_0, y_0)$ **不是极值**（$(x_0, y_0)$ 为鞍点）；
> 4. 若 $\Delta = 0$，**判别法失效**，需用定义或更高阶方法判断。

>[!tip] 记忆技巧
> $\Delta = AC - B^2$ 就是 Hessian 矩阵 $H = \begin{pmatrix}A & B \\ B & C\end{pmatrix}$ 的行列式。
> - $\Delta > 0$：Hessian **正定**（$A > 0$）→ 极小值；**负定**（$A < 0$）→ 极大值
> - $\Delta < 0$：Hessian **不定** → 鞍点
> - $\Delta = 0$：Hessian **半定** → 不能确定

## 2.4 无条件极值的求解步骤

>[!info] 无条件极值四步法
> 1. **求驻点**：解方程组 $\begin{cases} f_x = 0 \\ f_y = 0 \end{cases}$，得到所有驻点。
> 2. **求二阶偏导**：计算 $A = f_{xx},\; B = f_{xy},\; C = f_{yy}$（作为 $x,y$ 的函数）。
> 3. **逐点判别**：对每个驻点，代入 $A, B, C$ 计算 $\Delta = AC - B^2$，用定理 2 判定。
> 4. **写出结论**：给出极值点和极值。

>[!example] 例 1
> 求 $f(x,y) = x^3 - y^3 + 3x^2 + 3y^2 - 9x$ 的极值。
>
> 解：
>
> **(1) 求驻点**
>
> $$
> \begin{cases}
> f_x = 3x^2 + 6x - 9 = 3(x^2 + 2x - 3) = 3(x+3)(x-1) = 0 \\[4pt]
> f_y = -3y^2 + 6y = -3y(y - 2) = 0
> \end{cases}
> $$
>
> 解得 $x = -3$ 或 $1$；$y = 0$ 或 $2$。共 4 个驻点：$(-3,0),\; (-3,2),\; (1,0),\; (1,2)$。
>
> **(2) 二阶偏导**
>
> $$
> A = f_{xx} = 6x + 6,\qquad B = f_{xy} = 0,\qquad C = f_{yy} = -6y + 6
> $$
>
> **(3) 逐点判别**
>
> | 驻点 | $A$ | $B$ | $C$ | $\Delta$ | 结论 |
> |------|-----|-----|-----|----------|------|
> | $(-3,0)$ | $-12$ | $0$ | $6$ | $<0$ | 鞍点 |
> | $(-3,2)$ | $-12$ | $0$ | $-6$ | $>0$，$A<0$ | **极大值** |
> | $(1,0)$ | $12$ | $0$ | $6$ | $>0$，$A>0$ | **极小值** |
> | $(1,2)$ | $12$ | $0$ | $-6$ | $<0$ | 鞍点 |
>
> **(4) 结论**
>
> - 极大值：$f(-3, 2) = (-27) - 8 + 27 + 12 + 27 = 31$
> - 极小值：$f(1, 0) = 1 - 0 + 3 + 0 - 9 = -5$

>[!example] 例 2（典型题：$f(x,y) = xy$ 在约束下的极值见 [[#3. 条件极值与拉格朗日乘数法|§3]]）
> 验证 $z = x^2 + y^2$ 在 $(0,0)$ 处取得极小值。
>
> 解：$f_x = 2x = 0$，$f_y = 2y = 0$，得驻点 $(0,0)$。
>
> $A = f_{xx} = 2,\; B = f_{xy} = 0,\; C = f_{yy} = 2$。
>
> $\Delta = 2 \times 2 - 0^2 = 4 > 0$，且 $A = 2 > 0$，故 $(0,0)$ 为极小值点，极小值 $f(0,0) = 0$。几何上这就是一个开口向上的旋转抛物面，$(0,0)$ 是最低点。

# 3. 条件极值与拉格朗日乘数法

## 3.1 问题引入

无条件极值是在整个定义域上找极值。但实际中经常遇到附加条件——比如"在圆周 $x^2 + y^2 = 1$ 上，$f(x,y) = x + y$ 的最大值是多少？"

>[!definition] 定义 2（条件极值）
> 求函数 $z = f(x,y)$ 在附加条件 $\varphi(x,y) = 0$ 下的极值，称为**条件极值问题**。$\varphi(x,y) = 0$ 称为**约束条件**（或约束方程）。

## 3.2 拉格朗日乘数法

>[!corollary] 定理 3（拉格朗日乘数法）
> 求 $z = f(x,y)$ 在约束 $\varphi(x,y) = 0$ 下的可能极值点，步骤如下：
>
> 1. 构造**拉格朗日函数**：
>
>    $$
>    L(x, y, \lambda) = f(x, y) + \lambda\,\varphi(x, y)
>    $$
>
>    其中 $\lambda$ 称为**拉格朗日乘数**。
>
> 2. 求 $L$ 的**无条件驻点**——解方程组：
>
>    $$
>    \begin{cases}
>    L_x = f_x + \lambda\varphi_x = 0 \\[4pt]
>    L_y = f_y + \lambda\varphi_y = 0 \\[4pt]
>    L_\lambda = \varphi(x,y) = 0
>    \end{cases}
>    $$
>
> 3. 解出的 $(x, y)$ 即为**可能条件极值点**。再根据问题背景判断是极大还是极小。
>
> ^lagrange-multiplier

>[!tip] 几何直觉
> 从 [[方向导数 梯度|梯度与等值线]] 的讨论中：在约束曲线 $\varphi(x,y)=0$ 上，极值点处 $f$ 的等值线与约束曲线**相切**，即二者的法向量平行：
>
> $$
> \nabla f \parallel \nabla\varphi \;\Longrightarrow\; \nabla f + \lambda\nabla\varphi = \boldsymbol{0}
> $$
>
> 这就是拉格朗日乘数法的几何本质！$\lambda$ 就是两个梯度之间的比例系数。

>[!example] 例 3
> 求 $f(x,y) = x + y$ 在约束 $x^2 + y^2 = 1$ 下的最值。
>
> 解：
>
> 构造 $L(x,y,\lambda) = x + y + \lambda(x^2 + y^2 - 1)$
>
> $$
> \begin{cases}
> L_x = 1 + 2\lambda x = 0 \\[4pt]
> L_y = 1 + 2\lambda y = 0 \\[4pt]
> L_\lambda = x^2 + y^2 - 1 = 0
> \end{cases}
> $$
>
> 由前两式得 $x = y = -\dfrac{1}{2\lambda}$，代入第三式：
>
> $$
> 2 \cdot \frac{1}{4\lambda^2} = 1 \;\Longrightarrow\; \lambda^2 = \frac{1}{2} \;\Longrightarrow\; \lambda = \pm\frac{1}{\sqrt{2}}
> $$
>
> - $\lambda = \frac{1}{\sqrt{2}}$：$x = y = -\frac{1}{\sqrt{2}}$，$f = -\sqrt{2}$（**极小值**）
> - $\lambda = -\frac{1}{\sqrt{2}}$：$x = y = \frac{1}{\sqrt{2}}$，$f = \sqrt{2}$（**极大值**）

>[!example] 例 4（两个约束条件 — 三元函数）
> 求 $f(x,y,z) = xyz$ 在约束 $\begin{cases} x + y + z = 3 \\ x^2 + y^2 + z^2 = 9 \end{cases}$ 下的最大值。
>
> 解：构造 $L(x,y,z,\lambda,\mu) = xyz + \lambda(x + y + z - 3) + \mu(x^2 + y^2 + z^2 - 9)$
>
> $$
> \begin{cases}
> L_x = yz + \lambda + 2\mu x = 0 \\[2pt]
> L_y = xz + \lambda + 2\mu y = 0 \\[2pt]
> L_z = xy + \lambda + 2\mu z = 0 \\[2pt]
> L_\lambda = x + y + z - 3 = 0 \\[2pt]
> L_\mu = x^2 + y^2 + z^2 - 9 = 0
> \end{cases}
> $$
>
> 由对称性及约束推断 $x = y = z = 1$ 是一个解（验证：$1+1+1=3$，$1^2+1^2+1^2 = 3$……等等，$3 \neq 9$！说明不是这个）。
>
> 通过求解（将前三个方程作差消去 $\lambda$），可得 $x, y, z$ 中恰有两个相等。结合约束条件解得可能极值点为 $(3,0,0),\ (0,3,0),\ (0,0,3)$ 以及它们的排列，此时 $f = 0$。
>
> 另一个解：$x=y=z=1$ 不满足第二个约束。重新求解……由前三个方程可得 $x,y,z$ 两两相等或 $\mu$ 取特定值。详细代数过程略，最终最大值出现在 $x = y = z = \sqrt{3}$ 时？不对。实际上 $x,y,z$ 满足 $x+y+z=3,\ x^2+y^2+z^2=9$ 时，利用 $xy+yz+zx = \frac{(x+y+z)^2 - (x^2+y^2+z^2)}{2} = \frac{9-9}{2} = 0$，由对称性可推出最优解。结论：当 $x,y,z$ 为方程 $t^3 - 3t^2 + 0t - k = 0$ 的三根时，$xyz = k$ 的最大值为 $0$（因为 $xy+yz+zx=0$ 意味着至少有一根为零的排列，此时 $f=0$；而由不等式约束，$f$ 可以取正或负值，实际最大值为 $0$）。

# 4. 有界闭区域上的最值

>[!important] 区别：极值 vs 最值
> - **极值**：局部概念，只在一个小邻域内最大/最小。
> - **最值**：全局概念，在整个区域上的最大值和最小值。

>[!corollary] 定理 4（有界闭区域上连续函数的最值）
> 由 [[多元函数的基本概念#^extreme-value|最值定理]]，在有界闭区域 $D$ 上连续的函数必能取得最大值和最小值。

>[!info] 求有界闭区域上最值的步骤
> 1. **求内部驻点**：在 $D$ 的内部，令 $f_x = f_y = 0$，求出所有驻点并计算函数值。
> 2. **求边界上的条件极值**：在 $D$ 的边界上（通常是一段或多段曲线），将边界条件代入 $f$ 化为一元函数求最值，或用拉格朗日乘数法。
> 3. **比较**：比较所有内部驻点、边界驻点和角点（如果边界有端点）的函数值，挑出最大和最小。

>[!example] 例 5
> 求 $f(x,y) = x^2 + y^2 - xy - x - y$ 在闭区域 $D: x \ge 0,\ y \ge 0,\ x + y \le 3$ 上的最值。
>
> 解：
>
> **(1) 内部驻点**：$f_x = 2x - y - 1 = 0$，$f_y = 2y - x - 1 = 0$，解得 $x = y = 1$。$(1,1)$ 在 $D$ 内部，$f(1,1) = -1$。
>
> **(2) 边界上**（三条边）：
> - 边 $OA$（$y = 0,\ 0 \le x \le 3$）：$f = x^2 - x$，$f' = 2x - 1 = 0$，$x = \frac{1}{2}$。端点 $f(0,0)=0$，$f(3,0)=6$，驻点 $f(\frac{1}{2}, 0) = -\frac{1}{4}$。
> - 边 $OB$（$x = 0,\ 0 \le y \le 3$）：对称地，$f = y^2 - y$，结果同上。
> - 边 $AB$（$x + y = 3$）：代入 $y = 3 - x$，$f = x^2 + (3-x)^2 - x(3-x) - x - (3-x) = 3x^2 - 9x + 6$。$f' = 6x - 9 = 0$，$x = \frac{3}{2}$，$y = \frac{3}{2}$。$f(\frac{3}{2}, \frac{3}{2}) = \frac{3}{4}$。端点 $f(3,0) = f(0,3) = 6$（已计入）。
>
> **(3) 比较**：内部 $-1$，边界最小 $-\frac{1}{4}$，边界最大 $6$。
>
> - 最小值：$f(1,1) = -1$
> - 最大值：$f(3,0) = f(0,3) = 6$

# 5. 概念总图与关系

```
           多元函数的极值与最值
                  │
        ┌─────────┴─────────┐
        │                   │
   无条件极值           条件极值
        │              （拉格朗日乘数法）
        │                   │
   驻点 f_x=f_y=0     构造 L = f + λφ
        │              ∇L = 0 → 可能极值点
   Hessian 判别           │
   Δ = AC - B²            │
        │                   │
   ┌────┼────┐              │
   │    │    │              │
  极小  极大  鞍点          │
        │                   │
        └─────────┬─────────┘
                  │
           有界闭区域上最值
        = 内部极值 ∪ 边界最值
```

# 6. 速查表

| 情况 | 方法 | 关键步骤 |
|------|------|---------|
| **无条件极值** | Hessian 判别法 | ① 求驻点 ② 算 $A,B,C$ ③ $\Delta = AC-B^2$ 判定 |
| **条件极值（一个约束）** | 拉格朗日乘数法 | $L = f + \lambda\varphi$，解 $\nabla L = \boldsymbol{0}$ |
| **条件极值（多个约束）** | 多个乘数 | $L = f + \lambda\varphi + \mu\psi$ |
| **有界闭区域最值** | 内部 + 边界比较 | 内部驻点、边界化为一元函数、角点——全比一遍 |

| $\Delta = AC - B^2$ | $A$ 的符号 | 结论 |
|:---:|:---:|------|
| $>0$ | $>0$ | 极小值 |
| $>0$ | $<0$ | 极大值 |
| $<0$ | — | 鞍点（非极值） |
| $=0$ | — | 判别法失效 |

>[!warning] 易错点
> 1. **$\Delta > 0$ 且 $A > 0$ 是极小值，不是极大值**——很多人记反。想象 $z = x^2 + y^2$：$A = 2 > 0$，$\Delta = 4 > 0$，开口向上，极小值。
> 2. **驻点不一定是极值点**——$z = xy$ 在 $(0,0)$ 是驻点却是鞍点。
> 3. **条件极值的 $\lambda$ 不需要求出来**——很多时候 $\lambda$ 只是中间变量，解出 $x,y$ 就够了（除非题目要求求 $\lambda$）。
> 4. **有界闭区域的最值 ≠ 极值**——最值可能在边界上，边界上的点不一定是极值点（定义要求邻域，边界点只有半个邻域）。
> 5. **实际应用题的结论要回答原问题**——求出了极值点后记得代回原函数算出极值，应用题还要写一句"最大值为 xxx，此时 xxx"。
