# 1. 一个 C++ 程序长什么样

```cpp
#include <iostream>               // ① 头文件：把"输入输出工具箱"搬进来
using namespace std;              // ② 声明：以后用 cin/cout 不用写 std:: 前缀

int main() {                      // ③ 主函数：程序从这里开始执行
    cout << "Hello, C++!" << endl; // ④ 输出一句话
    return 0;                      // ⑤ 告诉系统：程序正常结束
}
```

运行结果：

```
Hello, C++!
```

> [!tip] 现在不用全懂
> ①②③ 先当「固定开场白」背下来，每一行是什么，我们一点点拆。

# 2. 输出：cout

`cout` 就是程序的「嘴」。想让它说什么，用 `<<`（读作「流向」）把内容塞给它：

```cpp
cout << "你好";              // 输出文字，注意要加双引号
cout << 42;                  // 输出数字，数字不用加引号
cout << 3 + 4;              // 先算 3+4，再输出 7
cout << endl;                // endl = 换行（end line）
```

运行结果：`你好427`

> [!warning] 文字必须加双引号
> 数字直接写。四行连续输出会「粘」在一起，所以需要 `endl` 换行。

> [!tip] 记忆口诀
> `<<` 是「插」进 cout 的嘴，方向永远朝外 → 屏幕。

# 3. 输入：cin

`cin` 是程序的「耳朵」。用 `>>`（方向是「从 cin 里拿出来」）把键盘输入读进变量：

```cpp
int age;                 // 先声明一个整数变量 age（下一步就学）
cin >> age;              // 等用户敲键盘，把数存进 age
cout << "你" << age << "岁" << endl;   // 再把它说出来
```

运行过程（用户输入 18 回车）：

```
18
你18岁
```

> [!tip] 对比记忆
> **cout 的箭头 << 向外「推」**，**cin 的箭头 >> 向内「收」**。一个说，一个听。

# 4. 变量

变量就是一个**有名字的盒子**，里面可以存数字、文字……而且**里面的东西可以随时换**，所以叫「变」量。

**三步走：声明 → 赋值 → 使用**

```cpp
int score;            // ① 声明：盖一个叫 score 的盒子，只能装整数
score = 95;           // ② 赋值：往盒子里放 95（= 是"放进去"，不是数学等号！）
score = 100;          // ③ 随时能换：现在盒子里的值是 100
cout << score;        // ④ 使用：把盒子里的值拿出来输出

int a = 3;            // 声明 + 赋值一步搞定（叫"初始化"）
int b, c;             // 一次声明好几个盒子，中间用逗号
```

> [!warning] = 不是数学等号
> 在 C++ 里，**= 是「把右边的值放左边盒子」**，不是数学里的「等于」！`a = 10` 是「把 10 放进 a」。

## 4.1 常见类型表

选对盒子，才能装对东西：

| 类型 | 装什么 | 例子 |
|---|---|---|
| `int` | 整数 | `int n = 18;` |
| `double` | 小数 | `double pi = 3.14;` |
| `char` | 单个字符（单引号） | `char ch = 'A';` |
| `string` | 一串文字（双引号） | `string s = "hi";` |
| `bool` | 真 / 假 | `bool ok = true;` |

> [!tip] string 头文件
> 用 **string** 需要在开头加 **#include <string>**，养成习惯总没错。

## 4.2 命名规则

起名要合法，最好也好懂：

```cpp
score, age2, my_name   // ✓ 合法：字母 / 数字 / 下划线，不能以数字开头
2score, my-name, int   // ✗ 不合法：数字开头 / 带横杠 / 撞了关键字
```

> [!tip] 起名建议
> **见名知意**。别人（和一周后的你）看 `studentScore` 就懂，看 `a1b2` 会哭。

# 5. 常量

有些值**永远不该变**，比如圆周率 π。C++ 用 `const` 把它锁死：

```cpp
const double PI = 3.14159;   // 声明时就要给值，之后永远改不了

PI = 3;                      // ✗ 编译报错！常量不能重新赋值
```

> [!tip] 命名约定
> 常量名**全大写**（PI、MAX_SIZE），一眼就能和变量区分开。

还有个亲戚叫**字面量**（直接写在代码里的值）：`42`、`3.14`、`'A'`、`"hello"` —— 它们天生就是常量，没名字，不能改。

# 6. 完整示例：两数加法器

```cpp
#include <iostream>
using namespace std;

int main() {
    int a, b;
    cout << "请输入两个整数：" << endl;
    cin >> a >> b;                     // 一次读两个，中间用空格/回车隔开

    int sum = a + b;
    cout << a << " + " << b << " = " << sum << endl;
    return 0;
}
```

运行过程：

```
请输入两个整数：
10 20        ← 用户输入
10 + 20 = 30
```

# 7. 新手三连坑

1. **分号丢了**：C++ 每条语句结束都要 `;`，丢了编译直接报错。
2. **引号打错**：字符串必须**双引号**，字符必须**单引号**，别用中文引号。
3. **cin >> 和 cout << 方向写反**：`cout` 箭头朝右（朝外），`cin` 箭头朝左（朝里）。
