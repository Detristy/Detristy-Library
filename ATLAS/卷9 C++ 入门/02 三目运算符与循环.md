# 1. 三目运算符

三目运算符是 if-else 的简写形式，语法：

```cpp
条件 ? 值1 : 值2
```

条件成立 → 整个表达式的值是 **值1**；不成立 → 是 **值2**。

```cpp
int a = 10, b = 20;
int max = (a > b) ? a : b;   // 最大数：a>b 就取 a，否则取 b
cout << max;                  // 输出 20
```

等价于：

```cpp
int max2;
if (a > b) max2 = a;
else      max2 = b;
```

> [!tip] 什么时候用？
> 当「选哪个值」是一句话能说清的事 → 用三目；逻辑复杂、要干多件事 → 用 if-else。
> 嵌套三目 `a ? b ? c : d : e` 可读性极差，拆成 if-else。

# 2. 循环总览

循环 = 重复执行同一段代码。三个要素：**起点**、**条件**、**每次怎么变**。

| 循环 | 记法 | 适合场景 |
|---|---|---|
| `for` | 「数数」：我知道要跑几遍 | 1 到 100 求和、遍历数组 |
| `while` | 「只要…就一直…」 | 不知道几遍，看条件 |
| `do-while` | 「先干一次再说」 | 至少执行 1 次 |

> [!warning] 死循环
> 循环最怕死循环——条件永远为真，程序卡死。每次循环都要让条件**往「假」的方向走**。

# 3. for 循环

`for` 的三个格子是固定套路：

```cpp
for (int i = 1; i <= 5; i++) {   // ① 起点 i=1  ② 条件 i<=5  ③ 每次 i+1
    cout << i << " ";            // 循环体：重复做的事
}
// 输出：1 2 3 4 5
```

执行顺序：**①→②→③→④→②→③→④→…**：先初始化，再查条件，条件成立就干活、然后 i++，再查条件……直到条件不成立。

```cpp
// 从 1 加到 100 的经典求和：
int sum = 0;
for (int i = 1; i <= 100; i++) {
    sum += i;
}
cout << "1+2+...+100 = " << sum << endl;   // 5050
```

> [!tip] 口诀
> for 适合「知道跑几遍」。变量名惯用 **i**（index），要几遍就写 `i <= 几`。

# 4. while 循环

进门先检查条件，**条件为真就执行循环体**，执行完回来再检查。条件一开始就是假 → 一次都不执行。

```cpp
int n = 1;
while (n <= 5) {          // 条件：n 还小于等于 5 吗？
    cout << n << " ";
    n++;                  // 🌟 别忘了让 n 变大！否则死循环
}
// 输出：1 2 3 4 5
```

> [!warning] while 的死循环陷阱
> 循环体里忘了 **n++**，条件永远成立 → 程序永远跑不停。

典型场景：**不知道读几个数**，读到结束标记才停：

```cpp
int score;
while (cin >> score) {        // cin >> 读到东西返回真，读不到（Ctrl+Z/结束）返回假
    if (score == -1) break;   // 遇到 -1 提前退出（下一节学 break）
    cout << score * 2 << " ";
}
// 输入 60 80 -1 → 输出 120 160
```

# 5. do-while 循环

`do { … } while (条件);`——**先执行一次循环体，再检查条件**。所以它**至少执行一次**，这就是和 while 的全部区别。

```cpp
int n = 100;
do {
    cout << n << " ";
    n++;
} while (n <= 5);            // 条件一开始就假，但 do-while 已经跑了一次
// 输出：100
```

换成 while：条件 `n<=5` 一开始就是假 → 一次都不输出。一个输出 100，一个啥都不输出 —— 这就是区别。

> [!tip] 常见用法
> **菜单程序**——至少显示一次菜单，选「退出」才结束。

# 6. break 和 continue

两个语句都能用在**循环内部**，但作用完全不同：

| 语句 | 作用 | 类比 |
|---|---|---|
| `break` | **立即结束整个循环**，跑到循环外面 | 🚪 直接推门出去，不回头 |
| `continue` | **跳过本次循环剩余代码**，直接开始下一轮 | ⏭️ 这一轮不玩了，重新来 |

```cpp
// break：找到 5 就停，后面的不管了
for (int i = 1; i <= 10; i++) {
    if (i == 5) break;      // 到 5 直接结束整个循环
    cout << i << " ";
}
// 输出：1 2 3 4

// continue：跳过 5，其他的照常
for (int i = 1; i <= 10; i++) {
    if (i == 5) continue;   // 遇到 5，跳过这次，继续下一轮
    cout << i << " ";
}
// 输出：1 2 3 4 6 7 8 9 10
```

> [!warning] continue 在 while 里要小心
> 如果 continue 跳过了「让条件变化的语句」（比如 `n++`），就会死循环！

```cpp
// ✗ 危险！
while (n <= 10) {
    if (n % 2 == 0) continue;   // 偶数直接跳到下一轮
    n++;                        // n 是偶数时永远执行不到 n++ → 死循环！
}

// ✓ 正确姿势：把 n++ 放前面，或者用 for
for (int i = 1; i <= 10; i++) {
    if (i % 2 == 0) continue;   // for 的变化在括号里，continue 不会卡死
    cout << i << " ";
}
// 输出奇数：1 3 5 7 9
```

# 7. 完整示例：猜数字小游戏

```cpp
#include <iostream>
using namespace std;

int main() {
    int secret = 42;            // 假装是随机数
    int guess;
    while (true) {               // 死循环，靠 break 退出
        cin >> guess;
        if (guess > secret) {
            cout << "大了！" << endl;
        } else if (guess < secret) {
            cout << "小了！" << endl;
        } else {
            cout << "猜对了！" << endl;
            break;              // 猜中 → 退出循环
        }
    }
    return 0;
}
```

# 8. 新手四连坑

1. **死循环**：循环体里忘了让条件变化，程序卡死。按 Ctrl+C 能救。
2. **for 的分号位置**：`for ( ; ; )` 三个格子用**分号**分隔，不是逗号。
3. **三目优先级**：嵌套三目可读性极差，别写 `a ? b ? c : d : e`，拆成 if-else。
4. **break 在 if 里**：break 只能用在**循环 / switch** 里，不能用在普通 if 里。
