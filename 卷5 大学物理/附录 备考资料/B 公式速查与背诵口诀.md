## 1. 质点运动学与动力学

### 核心公式表

| 物理量 | 基本公式 | 变力/变方向情况（核心） |
| :--- | :--- | :--- |
| **位置矢量** | $\vec{r}(t) = x(t)\vec{i} + y(t)\vec{j}$ | 轨迹方程：消去参数 $t$ 得到的 $y = f(x)$ |
| **速度** | $\vec{v} = \frac{d\vec{r}}{dt} = v_x\vec{i} + v_y\vec{j}$ | 速率（大小）：$v = |\vec{v}| = \frac{dS}{dt} = \sqrt{v_x^2 + v_y^2}$ |
| **加速度** | $\vec{a} = \frac{d\vec{v}}{dt} = \frac{d^2\vec{r}}{dt^2}$ | 切向加速度 $a_t$ 与法向加速度 $a_n$（圆周运动必考） |
| **牛顿第二定律** | $\vec{F} = m\vec{a}$ | 变力积分：$\vec{F}(t) = m\frac{d\vec{v}}{dt} \implies \int \vec{F} dt = m\Delta\vec{v}$ |
| **功（Work）** | 恒力：$W = \vec{F} \cdot \Delta\vec{r}$ | 变力做功：$W = \int_{x_1}^{x_2} F_x dx + \int_{y_1}^{y_2} F_y dy$ |
| **动能定理** | $W_{\text{合}} = \Delta E_k = \frac{1}{2}mv_2^2 - \frac{1}{2}mv_1^2$ | 适用于一切质点力学过程 |
| **动量定理** | $\vec{I} = \int_{t_1}^{t_2} \vec{F} dt = \Delta\vec{p} = m\vec{v}_2 - m\vec{v}_1$ | 冲量等于动量的变化量 |

### 🛠️ 关键细节与解题口诀

#### ① 圆周运动加速度双脚定律
*   **公式**：
    *   **切向加速度**（改快慢）：$a_t = \frac{dv}{dt} = R\alpha$（$\alpha$ 为角加速度）
    *   **法向加速度**（改方向）：$a_n = \frac{v^2}{R} = R\omega^2$（$\omega$ 为角速度）
    *   **总加速度大小**：$a = \sqrt{a_t^2 + a_n^2}$
*   口诀：**切向改快慢，法向改方向。两脚呈直角，勾股求总强。**

#### ② 变加速度的空间积分法（必考！）
*   **公式**：若加速度是关于位置的函数 $a = a(x)$，利用恒等式：
    $$a = \frac{dv}{dt} = \frac{dv}{dx} \cdot \frac{dx}{dt} = v\frac{dv}{dx} \implies a(x)dx = v dv$$
*   **积分**：$\int_{x_0}^x a(x') dx' = \int_{v_0}^v v' dv' = \frac{1}{2}v^2 - \frac{1}{2}v_0^2$
*   口诀：**加速度随 $x$ 变，千万别对 $t$ 积。$v dv$ 等于 $a dx$，两边一积速度出。**

#### ③ 非惯性系与等效重力法
*   **公式**：在有加速度 $\vec{a}_0$ 的非惯性系中，物体受虚拟惯性力 $\vec{F}_i = -m\vec{a}_0$。
*   **电梯加速上升**：有效重力加速度 $g' = g + a_0$（超重）。
*   **电梯加速下降**：有效重力加速度 $g' = g - a_0$（失重）。
*   口诀：**系统加速往哪跑，惯性力就往反向倒。向上加速等效重力大，向下加速重力减。**

## 2. 刚体定轴转动

### 核心公式表

| 物理量 | 符号与公式 | 物理意义/对应质点物理量 |
| :--- | :--- | :--- |
| **角位移/角速度/角加速度** | $\theta$ / $\omega = \frac{d\theta}{dt}$ / $\alpha = \frac{d\omega}{dt}$ | 对应直线运动的 $x, v, a$。线角转换：$v = R\omega, a_t = R\alpha$ |
| **转动惯量** | $J = \sum m_i r_i^2 = \int r^2 dm$ | 物体转动惯性的量度。对应质量 $m$ |
| **平行轴定理** | $J = J_c + md^2$ | $J_c$ 为过质心轴的转动惯量，$d$ 为两平行轴间距 |
| **力矩** | $M = F \cdot d$ | 力与力臂的乘积（$d$ 是转轴到力作用线的垂直距离） |
| **转动定律** | $M = J\alpha$ | 刚体定轴转动的核心，对应 $F = ma$ |
| **角动量（定轴）** | 质点绕轴：$L = mvr$（$v \perp r$） <br> 刚体绕轴：$L = J\omega$ | 转动惯性与角速度的乘积。对应动量 $p = mv$ |
| **角动量守恒** | 若合外力矩 $M_{\text{外}} = 0 \implies J_1\omega_1 = J_2\omega_2$ | 碰撞、收缩手臂、质点打棒等系统必备 |
| **转动动能** | $E_k = \frac{1}{2}J\omega^2$ | 刚体绕固定轴转动的动能。对应 $E_k = \frac{1}{2}mv^2$ |

### 常见刚体转动惯量 $J_c$（必须死记硬背！）
1.  **均匀细直杆**（长 $L$、质量 $m$）：
    *   绕过**中心**垂直于杆的轴：$J_c = \frac{1}{12}mL^2$
    *   绕过**一端**垂直于杆的轴：$J = \frac{1}{3}mL^2$ （由平行轴定理：$\frac{1}{12}mL^2 + m(\frac{L}{2})^2 = \frac{1}{3}mL^2$）
2.  **均匀圆盘/实心圆柱**（半径 $R$、质量 $m$）：
    *   绕中心对称轴：$J_c = \frac{1}{2}mR^2$
3.  **均匀圆环/薄圆筒**（半径 $R$、质量 $m$）：
    *   绕中心对称轴：$J_c = mR^2$

### 🛠️ 关键细节与解题口诀

#### ① 刚体碰撞问题（最爱考大题！）
*   **套路**：子弹（小球）以 $v_0$ 垂直撞击挂在转轴上的细杆并粘在一起（非弹性碰撞）。
*   **第一步：角动量守恒求碰撞后的瞬间 $\omega$**：
    $$m v_0 d + 0 = J_{\text{总}}\omega \implies m v_0 d = (J_{\text{杆}} + m d^2)\omega$$ （$d$ 为撞击点到转轴距离）
*   **第二步：机械能守恒求杆摆起的最大角度 $\theta$**：
    $$\frac{1}{2}J_{\text{总}}\omega^2 = \Delta E_p = m_{\text{杆}} g \Delta h_{\text{杆质心}} + m g \Delta h_{\text{子弹}}$$
    （如果是均匀细杆，质心在中点，上升高度 $\Delta h_c = d_c(1 - \cos\theta) = \frac{L}{2}(1-\cos\theta)$）
*   口诀：**碰撞瞬间时间短，外力矩为零角动量管。撞完摆动求高度，能量守恒势能补。**

## 3. 机械振动与机械波

### 核心公式表

| 物理量 | 标准表达式 | 关键系数与物理意义 |
| :--- | :--- | :--- |
| **简谐振动方程** | $x(t) = A\cos(\omega t + \phi)$ | $A$ 为振幅；$\omega = \frac{2\pi}{T} = 2\pi\nu$ 为角频率；$\phi$ 为初相 |
| **弹簧振子参数** | $\omega = \sqrt{\frac{k}{m}}$， $T = 2\pi\sqrt{\frac{m}{k}}$ | 仅由系统自身性质（$m, k$）决定 |
| **单摆参数** | $\omega = \sqrt{\frac{g}{L}}$， $T = 2\pi\sqrt{\frac{L}{g}}$ | 小角度单摆（$\theta < 5^\circ$）适用 |
| **简谐运动速度与加速度** | $v(t) = -A\omega\sin(\omega t + \phi)$ <br> $a(t) = -A\omega^2\cos(\omega t + \phi) = -\omega^2 x$ | 速度最大值 $v_{\max} = A\omega$；加速度最大值 $a_{\max} = A\omega^2$ |
| **振幅与初相确定** | $A = \sqrt{x_0^2 + \left(\frac{v_0}{\omega}\right)^2}$， $\tan\phi = -\frac{v_0}{\omega x_0}$ | 需根据 $x_0$ 和 $v_0$ 的正负号判断 $\phi$ 所在象限 |
| **同向同频合成** | $x = A\cos(\omega t + \phi)$ | $A = \sqrt{A_1^2 + A_2^2 + 2A_1A_2\cos(\phi_2 - \phi_1)}$ <br> $\tan\phi = \frac{A_1\sin\phi_1 + A_2\sin\phi_2}{A_1\cos\phi_1 + A_2\cos\phi_2}$ |
| **平面简谐波方程** | 沿 $+x$ 传播：$y(x,t) = A\cos\left[\omega(t - \frac{x}{u}) + \phi_0\right]$ <br> 沿 $-x$ 传播：$y(x,t) = A\cos\left[\omega(t + \frac{x}{u}) + \phi_0\right]$ | $u$ 为波速；波长 $\lambda = u T = \frac{2\pi u}{\omega}$ <br> 常用形式：$y(x,t) = A\cos\left[2\pi(\frac{t}{T} \mp \frac{x}{\lambda}) + \phi_0\right]$ |
| **波的相位差** | $\Delta \phi = \phi_2 - \phi_1 = \frac{2\pi}{\lambda}(x_2 - x_1) = \frac{2\pi}{\lambda}\Delta x$ | 空间两点在同一时刻的相位差 |

### 🛠️ 关键细节与解题口诀

#### ① 旋转矢量法判象限（必考！）
*   把简谐振动写为标准的余弦形式 $x = A\cos(\omega t + \phi)$。
*   根据初始条件 $t=0$ 时的 $x_0$ 与 $v_0$ 定初相 $\phi$：
    *   **$x_0 > 0, v_0 < 0$**：质点往平衡位置运动（上半圆），初相 $\phi \in (0, \pi/2)$。
    *   **$x_0 < 0, v_0 < 0$**：质点往负最大运动（上半圆），初相 $\phi \in (\pi/2, \pi)$。
    *   **$x_0 < 0, v_0 > 0$**：质点往平衡位置运动（下半圆），初相 $\phi \in (-\pi, -\pi/2)$。
    *   **$x_0 > 0, v_0 > 0$**：质点往正最大运动（下半圆），初相 $\phi \in (-\pi/2, 0)$。
*   口诀：**速度为负在上半圆，速度为正在下半圆。位移决定左右跨，象限一定错不了。**

#### ② 波动方程相位超前/滞后
*   波沿 $+x$（正方向）传播：**右侧的点振动比左侧晚（滞后）**，减去相位差，用 $(t - x/u)$。
*   波沿 $-x$（负方向）传播：**左侧的点振动比右侧晚（滞后）**，加相位差，用 $(t + x/u)$。
*   口诀：**左前右后波右行，左后右前波左行。超前用加滞后减，波速除以距离填。**

## 4. 波动光学

### 核心公式表

| 考点模块 | 核心公式 | 符号意义与重要条件 |
| :--- | :--- | :--- |
| **光程与相位差** | 光程 $L = n \cdot d$ <br> 相位差 $\Delta \phi = \frac{2\pi}{\lambda_0}\Delta L$ | $n$ 为折射率，$d$ 为几何路程，$\lambda_0$ 为**真空中**的波长 |
| **双缝干涉** | 条纹位置：$x_k = \pm k \frac{D\lambda}{d}$（明纹）<br> $x_k = \pm (2k+1)\frac{D\lambda}{2d}$（暗纹）<br> 条纹间距：$\Delta x = \frac{D\lambda}{d}$ | $d$ 为双缝间距；$D$ 为双缝到观察屏距离 <br> 明纹级次 $k=0, 1, 2, \dots$，暗纹级次 $k=0, 1, 2, \dots$ |
| **劈尖干涉** | 明纹：$2nd + \frac{\lambda}{2} = k\lambda \implies 2nd = (k - \frac{1}{2})\lambda$ <br> 暗纹：$2nd + \frac{\lambda}{2} = (2k+1)\frac{\lambda}{2} \implies 2nd = k\lambda$ <br> 条纹间距：$\Delta x = \frac{\lambda}{2n\theta}$ | $d$ 为薄膜厚度；$n$ 为夹层介质折射率；$\theta$ 为劈尖角 <br> $\frac{\lambda}{2}$ 是空气-玻璃界面产生的**半波损失** |
| **单缝夫琅禾费衍射** | 暗纹：$a\sin\theta = \pm k\lambda$ <br> 明纹：$a\sin\theta = \pm (2k+1)\frac{\lambda}{2}$ <br> 中央明纹角宽度：$\Delta \theta_0 = \frac{2\lambda}{a}$ <br> 中央明纹线宽度：$\Delta x_0 = \frac{2f\lambda}{a}$ | $a$ 为缝宽；$f$ 为透镜焦距 <br> **注意**：单缝衍射的暗纹公式与双缝干涉的明纹形式类似，千万不要记反！ |
| **光栅衍射** | 主极大方程：$(a+b)\sin\theta = d\sin\theta = \pm k\lambda$ <br> 缺级条件：$k = \frac{d}{a} k'$ （$k'$ 为非零整数） | $d = a+b$ 为光栅常数；$a$ 为单缝宽度 <br> 发生缺级时，对应的主极大级次 $k$ 不会出现 |
| **光的偏振** | 偏振片透射：$I_{\text{出}} = \frac{1}{2}I_{\text{自}}$（自然光） <br> 马吕斯定律：$I_{\text{出}} = I_{\text{入}}\cos^2\theta$（线偏振光） | $\theta$ 为入射线偏振光的振动方向与偏振片偏振化方向的夹角 |

### 🛠️ 关键细节与解题口诀

#### ① 半波损失判断（大物第一杀手！）
*   光从**折射率小（光疏）**的介质，射向**折射率大（光密）**的介质表面，**反射光**有半波损失，相位突变 $\pi$，相当于光程差突增 $\frac{\lambda}{2}$。
*   光从**光密**射向**光疏**介质表面反射，或者任何情况下的**折射光**，均**无半波损失**。
*   口诀：**疏入密，反射丢半波；密入疏，反射不丢失。折射过去保平安，光程计算别忘加。**

#### ② 劈尖干涉的动态变化
*   **条纹间距**：$\Delta x = \frac{\lambda}{2n\theta}$。
    *   夹角 $\theta$ 增大，条纹变密（$\Delta x$ 变小）。
    *   折射率 $n$ 变大（例如把空气劈尖放入水中），条纹变密（$\Delta x$ 变小）。
*   **条纹移动**：
    *   把劈尖上玻璃片往上抬（厚度 $d$ 变大），条纹向**棱角处（左侧）**移动。
    *   把玻璃片往下压（厚度 $d$ 变小），条纹向**开口处（右侧）**移动。
*   口诀：**膜变厚，条纹往棱跑；膜变薄，条纹往外飘。夹角越大越拥挤，折射率大条纹密。**

## 5. 狭义相对论

### 核心公式表

| 物理量 | 相对论公式 | 经典力学公式（对比） | 核心参数与物理意义 |
| :--- | :--- | :--- | :--- |
| **洛伦兹因子** | $\gamma = \frac{1}{\sqrt{1 - (v/c)^2}} \ge 1$ | - | 决定相对论效应显著程度的因子。$v \to c \implies \gamma \to \infty$ |
| **时间膨胀** | $\Delta t = \gamma \Delta \tau_0$ | $\Delta t = \Delta t'$ | $\Delta \tau_0$ 是**固有时间**（在相对静止系测得的时间）最浅/最短 |
| **长度收缩** | $L = \frac{L_0}{\gamma} = L_0\sqrt{1 - (v/c)^2}$ | $L = L_0$ | $L_0$ 是**固有长度**（相对静止时测得的长度）最长。**仅在运动方向收缩** |
| **洛伦兹坐标变换** | $x' = \gamma(x - vt)$， $y'=y$， $z'=z$ <br> $t' = \gamma(t - \frac{v}{c^2}x)$ | $x' = x - vt$（伽利略变换） | 从 S 系（静止）到 S' 系（以 $v$ 沿 $+x$ 运动）的坐标与时间变换 |
| **相对论质量** | $m = \gamma m_0 = \frac{m_0}{\sqrt{1 - (v/c)^2}}$ | $m = m_0$ | $m_0$ 为静止质量。速度越快，质量越大 |
| **相对论动能** | $E_k = (m - m_0)c^2 = (\gamma - 1)m_0c^2$ | $E_k = \frac{1}{2}m_0v^2$ | **切记**：大物考试中算动能千万不要用经典力学公式！ |
| **相对论总能量** | $E = mc^2 = E_k + m_0c^2$ | - | 静止能量 $E_0 = m_0c^2$。总能等于动能加静能 |
| **动量-能量关系** | $E^2 = (pc)^2 + (m_0c^2)^2$ | $E_k = \frac{p^2}{2m}$ | 高速粒子计算动量 $p$ 最常用的捷径公式 |

### 🛠️ 关键细节与解题口诀

#### ① 固有量最特别
*   **固有时间 $\tau_0$**：两事件发生在**同空间位置**测得的时间间隔。**固有时间最短**。
*   **固有长度 $L_0$**：测量者与被测物体**相对静止**时测得的长度。**固有长度最长**。
*   口诀：**静测时间短（钟慢），静测尺子长（尺缩）。找准静止参考系，固有参数最靠底。**

#### ② 能量-动量速算套路
*   若题目说：“动能是静止能量的 $k$ 倍”（即 $E_k = k m_0 c^2$）：
    *   第一步：求总能量 $E = E_k + E_0 = (k+1)m_0 c^2$。
    *   第二步：求 $\gamma$。因为 $E = \gamma m_0 c^2$，所以 $\gamma = k+1$。
    *   第三步：求动量 $p$。套用关系式：
        $$(pc)^2 = E^2 - (m_0c^2)^2 = [ (k+1)^2 - 1 ] (m_0c^2)^2 \implies p = \sqrt{k^2 + 2k} \cdot m_0 c$$
*   口诀：**动能是静能的几倍，洛伦兹因子就加个一。平方减一开根号，乘上 $m_0 c$ 动量立提。**
