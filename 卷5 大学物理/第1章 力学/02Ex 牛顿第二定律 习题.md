## 核心公式速查表

> 💡 **小贴士**：牛二的核心不是记公式，是**画受力图**和**选参考系**两个基本功。

### 1. 牛顿第二定律
- 基本形式：$\vec{F}_{\text{合}} = m\vec{a}$
- 分量形式（直角坐标）：$\sum F_x = ma_x,\ \sum F_y = ma_y$
- 分量形式（自然坐标）：$\sum F_t = ma_t,\ \sum F_n = ma_n = m\dfrac{v^2}{\rho}$
- 动量形式（变质量时用）：$\vec{F} = \dfrac{\mathrm{d}\vec{p}}{\mathrm{d}t}$

### 2. 摩擦力
- 静摩擦力：$0 \le f_s \le \mu_s N$（被动，方向与相对运动趋势相反）
- 滑动摩擦力：$f_k = \mu_k N$（方向与相对运动方向相反）
- 判断是否滑动：比较外力切向分量与 $\mu_s N$

### 3. 斜面分解套路
- 沿斜面方向：$\sum F_{\parallel} = ma$
- 垂直斜面方向：$\sum F_{\perp} = 0$（不脱离斜面时）
- 重力分解：$G_{\parallel} = mg\sin\theta$，$G_{\perp} = mg\cos\theta$

### 4. 滑轮问题关键点
- 绳不可伸长 → 各物体的加速度大小之间有约束关系
- 轻绳 → 绳中张力处处相等
- 轻滑轮 → 两侧绳张力相等；有质量滑轮 → 需用转动定律

### 5. 非惯性系惯性力
- 平动加速参考系（加速度 $\vec{a}_0$）：$\vec{F}_{\text{惯}} = -m\vec{a}_0$
- 等效重力法：$g_{\text{eff}} = g \pm a_0$（加速方向与重力平行时）

### 6. 相对运动
- 速度变换：$\vec{v}_{\text{A对C}} = \vec{v}_{\text{A对B}} + \vec{v}_{\text{B对C}}$
- 加速度变换（无转动）：$\vec{a}_{\text{A对C}} = \vec{a}_{\text{A对B}} + \vec{a}_{\text{B对C}}$
- **注意**：当 B 是非惯性系（有加速度）时，在 B 系中分析 A 的运动必须加上惯性力！

## 📝 模块一：F=ma 基础

### 📌 考点 1：斜面与摩擦

#### 题1【单选】
**题目**：一质量为 $m$ 的物体放在倾角为 $\theta$ 的粗糙斜面上，物体与斜面间的静摩擦系数为 $\mu_s$。要使物体恰好不下滑，$\theta$ 需满足什么条件？
*   (A) $\tan\theta = \mu_s$
*   (B) $\tan\theta < \mu_s$
*   (C) $\sin\theta = \mu_s$
*   (D) $\cos\theta = \mu_s$

**解析**：
1. 受力分析：沿斜面方向，重力分量 $mg\sin\theta$ 向下，静摩擦力 $f_s$ 沿斜面向上。
2. 恰好不下滑时静摩擦力达到最大：$f_s = \mu_s N = \mu_s mg\cos\theta$
3. 平衡条件：$mg\sin\theta = \mu_s mg\cos\theta \implies \tan\theta = \mu_s$
4. 所以 $\tan\theta \le \mu_s$ 时不下滑，恰好不滑时取等号。
故选 **(A)**。

> [!corollary] 自锁条件
> 当 $\tan\theta \le \mu_s$ 时，物体放在斜面上不会自动下滑，这叫**自锁**。这是斜面静摩擦的经典结论。

---

#### 题2【单选】
**题目**：一质量为 $m = 2\ \text{kg}$ 的物体静止在水平地面上，物体与地面间的静摩擦系数 $\mu_s = 0.3$，滑动摩擦系数 $\mu_k = 0.2$。现施加一水平拉力 $F = 5\ \text{N}$，则物体受到的摩擦力大小为____ N。（$g = 10\ \text{m/s}^2$）
*   (A) 4
*   (B) 5
*   (C) 6
*   (D) 0

**解析**：
1. 最大静摩擦力：$f_{s,\max} = \mu_s mg = 0.3 \times 20 = 6\ \text{N}$
2. $F = 5\ \text{N} < 6\ \text{N}$ → 物体不动，摩擦力是**静摩擦力**，大小等于外力：$f = 5\ \text{N}$
3. 只有外力超过 $6\ \text{N}$ 才会滑起来，此时才用 $\mu_k$。
故选 **(B)**。

> [!warning] 易错
> 看到摩擦系数就乘上去？先判断物体动不动！$F < \mu_s N$ → 静摩擦 = $F$；$F > \mu_s N$ → 滑动摩擦 = $\mu_k N$。

---

#### 题3【填空】
**题目**：一质量为 $m$ 的物体沿倾角 $\theta = 30^\circ$ 的粗糙斜面以**匀速**下滑。则物体与斜面间的滑动摩擦系数 $\mu_k =$ ____。

**解析**：
匀速 → 加速度为零 → 合力为零。
沿斜面方向：$mg\sin\theta - \mu_k mg\cos\theta = 0$
$$\mu_k = \tan\theta = \tan30^\circ = \frac{\sqrt{3}}{3} \approx 0.577$$
**答案**：$\dfrac{\sqrt{3}}{3}$（或 0.577）

*   **🔑 老师划重点**：
    *   匀速下滑 → $\mu_k = \tan\theta$。和自锁条件 $\mu_s = \tan\theta$ 恰好形式一样，但物理意义不同。

## 📝 模块二：连接体问题

### 📌 考点 2：叠块与绳连接体

#### 题4【单选】
**题目**：如图所示，质量 $m_A = 2\ \text{kg}$ 的物体 A 叠放在质量 $m_B = 3\ \text{kg}$ 的物体 B 上，B 放在光滑水平面上。A 与 B 之间的静摩擦系数 $\mu_s = 0.4$，滑动摩擦系数 $\mu_k = 0.3$。用水平力 $F$ 拉 B。要使 A 和 B 不发生相对滑动，$F$ 的最大值为____ N。（$g = 10\ \text{m/s}^2$）
*   (A) 8
*   (B) 12
*   (C) 20
*   (D) 28

**解析**：
1. **两物体无相对滑动 → 加速度相同**，设为 $a$。A 的加速度只能来自 B 对 A 的静摩擦力。
2. A 的最大静摩擦力：$f_{\max} = \mu_s m_A g = 0.4 \times 20 = 8\ \text{N}$
3. A 的最大加速度：$a_{\max} = \dfrac{f_{\max}}{m_A} = \dfrac{8}{2} = 4\ \text{m/s}^2$
4. 整体最大加速度也是 $4\ \text{m/s}^2$，用整体法：
   $$F_{\max} = (m_A + m_B)a_{\max} = 5 \times 4 = 20\ \text{N}$$
故选 **(C)**。

*   **🔑 老师划重点**：
    *   叠块问题两步走：① 隔离上面物体，最大静摩擦 → 最大加速度；② 整体法求最大外力。
    *   直接拿 $\mu_s(m_A+m_B)g$ 算就掉坑里了——擦的是 A 和 B 之间的界面，不是 B 和地面！

---

#### 题5【填空】
**题目**：如图，两个质量均为 $m$ 的物体用轻绳跨过光滑定滑轮连接，其中一个放在倾角 $\theta = 37^\circ$ 的**光滑**斜面上，另一个悬挂在空中。释放系统后，物体的加速度大小为__。（$g = 10\ \text{m/s}^2$，$\sin37^\circ = 0.6$）

**解析**：
设悬挂物体加速度向下为 $a$（绳不可伸长，斜面物体加速度大小也为 $a$，方向沿斜面向上）。
1. 悬挂物体：$mg - T = ma$
2. 斜面物体（沿斜面）：$T - mg\sin\theta = ma$
3. 两式相加消去 $T$：
   $$mg - mg\sin\theta = 2ma$$
   $$mg(1 - 0.6) = 2ma \implies a = \frac{0.4g}{2} = 0.2g = 2\ \text{m/s}^2$$
**答案**：2

---

#### 题6【填空】
**题目**：一轻绳跨过两个轻滑轮，两端各挂质量 $m_1 = 3\ \text{kg}$ 和 $m_2 = 1\ \text{kg}$ 的物体。不计一切摩擦。则绳中张力 $T =$ ____ N。（$g = 10\ \text{m/s}^2$）

**解析**：
经典阿特伍德机——两个物体加速度大小相等，方向相反。设 $m_1$ 向下加速 $a$。
1. $m_1g - T = m_1a$
2. $T - m_2g = m_2a$
3. 相加：$(m_1 - m_2)g = (m_1 + m_2)a$
   $$a = \frac{m_1 - m_2}{m_1 + m_2}g = \frac{2}{4} \times 10 = 5\ \text{m/s}^2$$
4. 代回求张力：
   $$T = m_2(g + a) = 1 \times 15 = 15\ \text{N}$$
   （或用 $T = m_1(g - a) = 3 \times 5 = 15\ \text{N}$）
**答案**：15

*   **🔑 老师划重点**：
    *   阿特伍德机的加速度公式：$a = \dfrac{m_1 - m_2}{m_1 + m_2}g$。质量差越大，加速越快。
    *   张力永远介于两者重力之间，不要直觉地以为等于较重的重力。

## 📝 模块三：弹簧与变力

### 📌 考点 3：F(x) 型与 F(v) 型

#### 题7【填空】
**题目**：一质量为 $m$ 的物块连接在劲度系数为 $k$ 的轻弹簧一端，弹簧另一端固定。初始时弹簧被压缩 $A$ 且物块静止。释放后物块在光滑水平面上运动。当弹簧恢复原长时，物块的速率为____。

**解析**：
1. 弹簧力 $F = -kx$（$x$ 是形变量），是 $F(x)$ 型变力 → 用 $a = v\dfrac{\mathrm{d}v}{\mathrm{d}x}$。
2. 牛顿第二定律：
   $$-k(-x) = m v\frac{\mathrm{d}v}{\mathrm{d}x} \quad (\text{设弹簧原长处为原点，物块在 } x=-A \text{ 处})$$
   或直接：弹力做正功，从 $F=ma$ 出发：
   $$kx = m v\frac{\mathrm{d}v}{\mathrm{d}x} \quad (\text{以压缩量为正方向})$$
3. 分离变量积分（$x=A$ 时 $v=0$，$x=0$ 时求 $v$）：
   $$\int_0^v v\,\mathrm{d}v = \int_A^0 \frac{k}{m}x\,\mathrm{d}x \quad (\text{注意积分方向})$$
   更简单：从 $x=A$ 到 $x=0$：
   $$\int_0^v v\,\mathrm{d}v = \frac{k}{m}\int_0^A x\,\mathrm{d}x$$
   $$\frac{1}{2}v^2 = \frac{k}{m} \cdot \frac{A^2}{2} \implies v = A\sqrt{\frac{k}{m}}$$
**答案**：$A\sqrt{\dfrac{k}{m}}$

> 当然也可以用机械能守恒秒杀：$\frac{1}{2}kA^2 = \frac{1}{2}mv^2$，直接得 $v = A\sqrt{k/m}$。但考试有时要求用牛二积分——两种方法都要会。

#### 题8【填空】
**题目**：一质量为 $m$ 的物体在水平面上运动，所受空气阻力 $f = -kv$（$k$ 为常数）。设初速度为 $v_0$。物体从初速度 $v_0$ 减小到 $v_0/3$ 所经过的位移为___。（结果用 $m, k, v_0$ 表示）

**解析**：
$F(v)$ 型。牛顿第二定律：
$$-kv = m\frac{\mathrm{d}v}{\mathrm{d}t} = m v\frac{\mathrm{d}v}{\mathrm{d}x}$$
消去 $v$（$v \neq 0$）：
$$-k = m\frac{\mathrm{d}v}{\mathrm{d}x}$$
分离变量：
$$\mathrm{d}v = -\frac{k}{m}\mathrm{d}x$$
积分：
$$\int_{v_0}^{v_0/3} \mathrm{d}v = -\frac{k}{m}\int_0^x \mathrm{d}x$$
$$\frac{v_0}{3} - v_0 = -\frac{k}{m}x$$
$$-\frac{2}{3}v_0 = -\frac{k}{m}x \implies x = \frac{2mv_0}{3k}$$
**答案**：$\dfrac{2mv_0}{3k}$

> [!corollary] 小结
> $f = -kv$ 的妙处：$\dfrac{\mathrm{d}v}{\mathrm{d}t} = v\dfrac{\mathrm{d}v}{\mathrm{d}x}$ 变形成 $\dfrac{\mathrm{d}v}{\mathrm{d}x} = -\dfrac{k}{m}$，速度对位移线性递减！$v = v_0 - \dfrac{k}{m}x$。

## 📝 模块四：非惯性系

### 📌 考点 4：惯性力实战

#### 题9【单选】
**题目**：一车厢以加速度 $a$ 向右加速行驶，车厢内一质量为 $m$ 的小球用细线悬挂在天花板上。稳定后细线与竖直方向的夹角为 $\theta$（向后偏）。则 $\theta$ 满足____。
*   (A) $\tan\theta = \dfrac{a}{g}$
*   (B) $\sin\theta = \dfrac{a}{g}$
*   (C) $\cos\theta = \dfrac{a}{g}$
*   (D) $\tan\theta = \dfrac{g}{a}$

**解析**：
**方法一（非惯性系）**：以车厢为参考系，小球受到重力 $mg$（向下）、绳拉力 $T$（沿绳）、惯性力 $ma$（向左）。
- 竖直平衡：$T\cos\theta = mg$
- 水平平衡：$T\sin\theta = ma$
- 两式相除：$\tan\theta = \dfrac{a}{g}$
故选 **(A)**。

**方法二（地面惯性系）**：小球随车厢以 $a$ 向右加速。
- 水平：$T\sin\theta = ma$
- 竖直：$T\cos\theta = mg$
- 同样得 $\tan\theta = a/g$。

*   **🔑 老师划重点**：
    *   在车厢里看，小球受惯性力"向后甩"；在地面看，小球受绳拉力水平分量产生加速度。两种视角结果一样，但非惯性系里小球**平衡**了，方程更好列。

---

#### 题10【填空】
**题目**：一电梯以加速度 $a = \dfrac{g}{3}$ **向上**加速。电梯内有一质量为 $m$ 的物体用弹簧秤悬挂。弹簧秤的读数为___。（结果用 $mg$ 表示）

**解析**：
以电梯为参考系（非惯性系），物体受到向下的惯性力 $ma$，"等效重力加速度"为：
$$g_{\text{eff}} = g + a = g + \frac{g}{3} = \frac{4g}{3}$$
弹簧秤读数 = 视重 = $mg_{\text{eff}} = \dfrac{4}{3}mg$

（地面系视角：$T - mg = ma \implies T = m(g+a) = \dfrac{4}{3}mg$，结果一致）
**答案**：$\dfrac{4}{3}mg$

> [!warning] 超重与失重
> 加速向上 → 超重（弹簧秤读数变大）；加速向下 → 失重（读数变小）；$a=g$ 向下 → 完全失重（读数为 0）。

#### 题11【填空】
**题目**：一倾角 $\theta = 30^\circ$ 的光滑斜面固定在一小车上，小车以加速度 $a = \dfrac{g}{2}$ 向右加速行驶。一质量为 $m$ 的物块静止放置在斜面上（相对斜面静止）。则物块与斜面间的弹力大小为___。（结果用 $mg$ 表示）

**解析**：
以小车（非惯性系）为参考系。物块受重力 $mg$（↓）、斜面支持力 $N$（↖⊥斜面）、惯性力 $ma$（←，大小为 $mg/2$）。

沿垂直斜面方向，物块不脱离斜面，合力为零：
$$N - mg\cos30^\circ - ma\sin30^\circ = 0$$
$$N = mg \cdot \frac{\sqrt{3}}{2} + \frac{mg}{2} \cdot \frac{1}{2} = mg\left(\frac{\sqrt{3}}{2} + \frac{1}{4}\right)$$
$$= mg\left(\frac{2\sqrt{3} + 1}{4}\right) \approx 0.683mg$$
**答案**：$\dfrac{2\sqrt{3}+1}{4}mg$

> [!corollary] 小结
> 在加速参考系中处理斜面→把惯性力当成一个额外的"重力"分量，等效重力方向不再是竖直的！

## 📝 模块五：相对运动

### 📌 考点 5：相对速度与相对加速度

#### 题12【填空】
**题目**：A、B 两车沿同一直线相向而行，A 车速度为 $20\ \text{m/s}$ 向东，B 车速度为 $15\ \text{m/s}$ 向西。则 A 车驾驶员看到 B 车的速度大小为____ m/s。

**解析**：
以向东为正方向。$v_{\text{A对地}} = +20\ \text{m/s}$，$v_{\text{B对地}} = -15\ \text{m/s}$。

A 看到 B 的速度 = B 相对 A 的速度：
$$v_{\text{B对A}} = v_{\text{B对地}} - v_{\text{A对地}} = -15 - 20 = -35\ \text{m/s}$$
大小为 $35\ \text{m/s}$，方向向西。
**答案**：35

*   **🔑 老师划重点**：
    *   $\vec{v}_{\text{B对A}} = \vec{v}_{\text{B对C}} - \vec{v}_{\text{A对C}}$。相向而行 → 相对速度是绝对值之和，比直觉更大！

---

#### 题13【单选】
**题目**：B 车在 A 车正前方以 $v_B = 10\ \text{m/s}$ 匀速行驶，A 车以 $v_A = 20\ \text{m/s}$ 从后方匀速追赶。以 B 车为参考系，A 车的运动情况是____。
*   (A) 以 $10\ \text{m/s}$ 向前运动
*   (B) 以 $10\ \text{m/s}$ 向后运动
*   (C) 以 $30\ \text{m/s}$ 向前运动
*   (D) 以 $30\ \text{m/s}$ 向后运动

**解析**：
A 相对 B 的速度 = $v_A - v_B = 20 - 10 = +10\ \text{m/s}$（向前，即靠拢）。
在 B 看来，A 正以 $10\ \text{m/s}$ 追过来。
故选 **(A)**。

---

#### 题14【填空】
**题目**：一光滑平板车以加速度 $a_0 = 4\ \text{m/s}^2$ 向右加速运动，车上有一质量为 $m$ 的物块相对于车以加速度 $a' = 2\ \text{m/s}^2$ 向左运动。物块与车之间无摩擦。则物块对地的加速度大小为____ m/s²，方向____。

**解析**：
1. **绝对加速度 = 牵连加速度 + 相对加速度**：
   $$\vec{a}_{\text{物对地}} = \vec{a}_{\text{车对地}} + \vec{a}_{\text{物对车}}$$
2. 设定向右为正：$\vec{a}_{\text{车对地}} = +4\ \text{m/s}^2$，$\vec{a}_{\text{物对车}} = -2\ \text{m/s}^2$
3. $a_{\text{物对地}} = 4 + (-2) = +2\ \text{m/s}^2$，方向向右。
**答案**：2，向右

> [!warning] 坑
> 别以为物块相对车向左运动就对地也向左！车的加速度更大，"拖着"物块整体还是向右加速。

### 📌 考点 6：相对运动综合作图法

#### 题15【填空】
**题目**：一人在雨中向东以 $6\ \text{m/s}$ 的速度奔跑，感觉雨点从正北方向以 $10\ \text{m/s}$ 的速度打来。则雨点对地的速度大小为____ m/s。

**解析**：
伽利略速度变换：$\vec{v}_{\text{雨对地}} = \vec{v}_{\text{雨对人}} + \vec{v}_{\text{人对地}}$
- $\vec{v}_{\text{人对地}} = 6\ \text{m/s}$ 向东（→）
- $\vec{v}_{\text{雨对人}} = 10\ \text{m/s}$ 从正北来（即向南，↓）
- 矢量合成：$\vec{v}_{\text{雨对地}} = \vec{v}_{\text{雨对人}} + \vec{v}_{\text{人对地}} =$ ↓$10$ + →$6$
- 大小：$v = \sqrt{10^2 + 6^2} = \sqrt{136} = 2\sqrt{34} \approx 11.66\ \text{m/s}$
- 方向：$\tan\theta = \dfrac{10}{6}$，偏东偏南。

**答案**：$2\sqrt{34}$（约 11.66）

> 这题和 306A 的雨滴问题互为"逆问题"——那边是已知雨对地+人对地求雨对人，这边是已知雨对人+人对地求雨对地。矢量三角形转个方向而已！
