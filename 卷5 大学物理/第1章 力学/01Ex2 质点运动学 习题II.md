## 核心公式速查表

> 💡 **小贴士**：运动学的根是两条链——求导链和积分链，所有公式都从它们长出来的。

### 1. 微积分关系
- 位移 → 速度 → 加速度（求导）：
  $$v = \frac{\mathrm{d}x}{\mathrm{d}t},\quad a = \frac{\mathrm{d}v}{\mathrm{d}t} = \frac{\mathrm{d}^2x}{\mathrm{d}t^2}$$
- 加速度 → 速度 → 位移（积分）：
  $$v(t) = v_0 + \int_0^t a(t)\mathrm{d}t,\quad x(t) = x_0 + \int_0^t v(t)\mathrm{d}t$$
- 关键变形（a = a(x) 时）：$a = v\dfrac{\mathrm{d}v}{\mathrm{d}x}$

### 2. 抛体运动
- 水平：$x = v_0\cos\theta \cdot t$（匀速）
- 竖直：$y = v_0\sin\theta \cdot t - \frac{1}{2}gt^2$
- 射高：$H = \dfrac{v_0^2\sin^2\theta}{2g}$
- 射程：$R = \dfrac{v_0^2\sin2\theta}{g}$
- 飞行时间：$T = \dfrac{2v_0\sin\theta}{g}$
- 射程最大条件：$\theta = 45^\circ$（落地高度相同）

### 3. 圆周运动
- 角量与线量：$s = R\theta,\ v = R\omega,\ a_t = R\alpha$
- 切向加速度：$a_t = \dfrac{\mathrm{d}v}{\mathrm{d}t} = R\alpha$（改变速度大小）
- 法向（向心）加速度：$a_n = \dfrac{v^2}{R} = R\omega^2$（改变速度方向）
- 总加速度：$a = \sqrt{a_t^2 + a_n^2}$
- 匀变速圆周：$\omega = \omega_0 + \alpha t,\ \theta = \theta_0 + \omega_0 t + \frac{1}{2}\alpha t^2$

### 4. 相对运动（伽利略变换）
- 速度变换：$\vec{v}_{\text{A对C}} = \vec{v}_{\text{A对B}} + \vec{v}_{\text{B对C}}$
- 加速度在两惯性系间不变：$\vec{a} = \vec{a}'$

### 5. 三种变加速积分套路
- **a(t)**：直接对 t 积分 → $v = v_0 + \int a(t)\mathrm{d}t$
- **a(v)**：分离变量 → $\dfrac{\mathrm{d}v}{a(v)} = \mathrm{d}t$
- **a(x)**：用 $a = v\dfrac{\mathrm{d}v}{\mathrm{d}x}$ → $v\mathrm{d}v = a(x)\mathrm{d}x$

## 📝 模块一：一维运动微积分

### 📌 考点 1：求导链与积分链

#### 题1【单选】
**题目**：一质点沿 x 轴做直线运动，运动方程为 $x = 2t^3 - 3t^2 + t + 1$（SI 单位）。当 $t = 1\ \text{s}$ 时，质点的加速度大小为____。
*   (A) $0\ \text{m/s}^2$
*   (B) $3\ \text{m/s}^2$
*   (C) $6\ \text{m/s}^2$
*   (D) $9\ \text{m/s}^2$

**解析**：
1. 求速度：$v = \dfrac{\mathrm{d}x}{\mathrm{d}t} = 6t^2 - 6t + 1$
2. 求加速度：$a = \dfrac{\mathrm{d}v}{\mathrm{d}t} = 12t - 6$
3. $t = 1$ 时：$a = 12 - 6 = 6\ \text{m/s}^2$
故选 **(C)**。

*   **🔑 老师划重点**：
    *   $x(t) \xrightarrow{\text{求导}} v(t) \xrightarrow{\text{求导}} a(t)$ — 两步走，稳准狠。
    *   反向就是积分：$a(t) \xrightarrow{\text{积分}} v(t) \xrightarrow{\text{积分}} x(t)$。

---

#### 题2【填空】
**题目**：一质点沿 x 轴做直线运动，加速度 $a = 4t$（SI 单位）。已知 $t = 0$ 时 $v_0 = 2\ \text{m/s}$，$x_0 = 0$。则 $t = 2\ \text{s}$ 时质点的位置 $x =$ ____ m。

**解析**：
1. 一次积分求速度：
   $$v(t) = v_0 + \int_0^t 4t'\,\mathrm{d}t' = 2 + 2t^2$$
2. 二次积分求位移：
   $$x(t) = \int_0^t (2 + 2t'^2)\,\mathrm{d}t' = 2t + \frac{2}{3}t^3$$
3. $t = 2$ 时：
   $$x = 2 \times 2 + \frac{2}{3} \times 8 = 4 + \frac{16}{3} = \frac{28}{3} \approx 9.33\ \text{m}$$
**答案**：$\dfrac{28}{3}$（或 9.33）

---

#### 题3【单选】
**题目**：一质点沿 x 轴运动，其速度 $v$ 与时间 $t$ 满足 $v = 3t^2 - 2$。则质点在 $t = 0$ 到 $t = 2\ \text{s}$ 内的位移大小为____ m。
*   (A) 0
*   (B) 2
*   (C) 4
*   (D) 8

**解析**：
1. **注意陷阱**：$v$ 在 $t < \sqrt{2/3} \approx 0.82\ \text{s}$ 时为负（往负方向走），之后为正。如果直接积分得到的是**位移**，不是路程！但题目问的是位移，所以直接积分即可。
2. 位移：
   $$\Delta x = \int_0^2 v(t)\,\mathrm{d}t = \int_0^2 (3t^2 - 2)\,\mathrm{d}t = [t^3 - 2t]_0^2 = 8 - 4 = 4\ \text{m}$$
故选 **(C)**。

> [!warning] 注意区分！
> 位移是矢量，直接积分速度即可。**路程**才是速度绝对值的积分，需要找到速度变号的时刻分段计算。题目问"位移"就不要自作多情去分段！

## 📝 模块二：抛体运动

### 📌 考点 2：射程、射高与轨迹

#### 题4【单选】
**题目**：以相同的初速率 $v_0$ 从地面上斜抛物体，下面哪个仰角能使抛体的射程最大？（不计空气阻力）
*   (A) $30^\circ$
*   (B) $45^\circ$
*   (C) $60^\circ$
*   (D) $30^\circ$ 和 $60^\circ$ 射程相同

**解析**：
1. 射程公式 $R = \dfrac{v_0^2\sin2\theta}{g}$，当 $2\theta = 90^\circ$（即 $\theta=45^\circ$）时，$\sin2\theta$ 取最大值 1，射程最大。
2. **注意选项 (D)**：$\theta=30^\circ$ 和 $\theta=60^\circ$ 满足 $\sin2\theta$ 相等（$\sin60^\circ=\sin120^\circ=\sqrt{3}/2$），射程确实相同，但都是 $45^\circ$ 射程的 $\sqrt{3}/2$ 倍，**并非最大**。
   故选 **(B)**。

*   **🔑 老师划重点**：
    *   互余角（$\theta$ 和 $90^\circ-\theta$）射程相同，但都小于 $45^\circ$。
    *   只有落地高度与出发高度相等时 $45^\circ$ 才是最优。

---

#### 题5【填空】
**题目**：一小球以初速率 $v_0 = 20\ \text{m/s}$、仰角 $\theta = 37^\circ$ 从地面斜上抛出。小球到达最高点时的高度为____ m。($g = 10\ \text{m/s}^2$，$\sin37^\circ = 0.6$，$\cos37^\circ = 0.8$)

**解析**：
射高公式：
$$H = \frac{v_0^2\sin^2\theta}{2g} = \frac{20^2 \times 0.6^2}{2 \times 10} = \frac{400 \times 0.36}{20} = \frac{144}{20} = 7.2\ \text{m}$$
**答案**：7.2

---

#### 题6【填空】
**题目**：从高 $h = 45\ \text{m}$ 的塔顶以初速率 $v_0 = 10\ \text{m/s}$ 水平抛出一小球。小球落地时速度方向与水平方向的夹角的正切值 $\tan\alpha =$ ____。（$g = 10\ \text{m/s}^2$）

**解析**：
1. 水平方向：匀速 $v_x = v_0 = 10\ \text{m/s}$
2. 竖直方向：自由落体 $v_y^2 = 2gh = 2 \times 10 \times 45 = 900$ → $v_y = 30\ \text{m/s}$
3. 落地时 $\tan\alpha = \dfrac{v_y}{v_x} = \dfrac{30}{10} = 3$
**答案**：3

## 📝 模块三：圆周运动

### 📌 考点 3：切向与法向加速度

#### 题7【单选】
**题目**：一质点沿半径为 $R$ 的圆周做匀速率运动，速率为 $v$。下列关于加速度的说法正确的是____。
*   (A) 加速度为零
*   (B) 只有切向加速度，大小为零
*   (C) 只有法向加速度，大小为 $v^2/R$
*   (D) 切向和法向加速度均不为零

**解析**：
匀速率圆周运动：速率 $v$ 不变 → 切向加速度 $a_t = \dfrac{\mathrm{d}v}{\mathrm{d}t} = 0$。但速度方向时刻变化 → 法向加速度 $a_n = v^2/R \neq 0$。
故选 **(C)**。

*   **🔑 老师划重点**：
    *   "匀速" ≠ 无加速度！圆周运动中"匀速"只是速率不变，方向一直在变。
    *   $a_t$ 管速度大小变化，$a_n$ 管速度方向变化。

---

#### 题8【填空】
**题目**：一质点沿半径 $R = 2\ \text{m}$ 的圆周运动，路程 $S = t^2 + 2t$（SI 单位）。当 $t = 1\ \text{s}$ 时，(1) 切向加速度 $a_t =$ ____ m/s²；(2) 法向加速度 $a_n =$ ____ m/s²。

**解析**：
1. 速率：$v = \dfrac{\mathrm{d}S}{\mathrm{d}t} = 2t + 2$
   $t = 1$ 时：$v = 4\ \text{m/s}$
2. 切向加速度：$a_t = \dfrac{\mathrm{d}v}{\mathrm{d}t} = 2\ \text{m/s}^2$（恒量）
3. 法向加速度：$a_n = \dfrac{v^2}{R} = \dfrac{4^2}{2} = 8\ \text{m/s}^2$
**答案**：(1) 2；(2) 8

---

#### 题9【填空】
**题目**：一质点沿半径 $R = 0.5\ \text{m}$ 的圆周做匀变速圆周运动，初始角速度 $\omega_0 = 4\ \text{rad/s}$，角加速度 $\alpha = -2\ \text{rad/s}^2$。当角速度减小到 $2\ \text{rad/s}$ 时，质点转过的角度为____ rad。

**解析**：
匀变速圆周运动公式：
$$\omega^2 - \omega_0^2 = 2\alpha(\theta - \theta_0)$$
$$2^2 - 4^2 = 2 \times (-2) \times \Delta\theta$$
$$4 - 16 = -4\Delta\theta \implies -12 = -4\Delta\theta \implies \Delta\theta = 3\ \text{rad}$$
**答案**：3

## 📝 模块四：变加速运动

### 📌 考点 4：三种 a 函数类型的积分

#### 题10【填空 — a(t) 型】
**题目**：一质点由静止出发沿直线运动，加速度 $a = 2 + \sin t$（SI）。则 $t = \pi\ \text{s}$ 时质点的速度为____ m/s。

**解析**：
$a = a(t)$ 型，直接对 t 积分：
$$v = \int_0^\pi (2 + \sin t)\,\mathrm{d}t = [2t - \cos t]_0^\pi = (2\pi - \cos\pi) - (0 - \cos0)$$
$$= 2\pi - (-1) - (-1) = 2\pi + 1 + 1 = 2\pi + 2 \approx 8.28\ \text{m/s}$$
**答案**：$2\pi + 2$

---

#### 题11【填空 — a(v) 型】
**题目**：一质点以初速度 $v_0 = 10\ \text{m/s}$ 沿直线运动，加速度 $a = -kv$，其中 $k = 0.5\ \text{s}^{-1}$。当速度减小为 $v_0/2$ 时，经过的时间为____ s。（结果用 $\ln2$ 表示）

**解析**：
$a = a(v)$ 型，分离变量：
$$a = \frac{\mathrm{d}v}{\mathrm{d}t} = -kv \implies \frac{\mathrm{d}v}{v} = -k\,\mathrm{d}t$$
积分：
$$\int_{v_0}^{v_0/2} \frac{\mathrm{d}v}{v} = \int_0^t (-k)\,\mathrm{d}t$$
$$\ln\frac{v_0/2}{v_0} = -kt \implies \ln\frac{1}{2} = -0.5t$$
$$-\ln2 = -0.5t \implies t = 2\ln2\ \text{s}$$
**答案**：$2\ln2$

> [!corollary] 小结
> a(v) 型的套路：分离变量 → $\mathrm{d}v/a(v) = \mathrm{d}t$ → 两边定积分。常见于阻力与速度成正比的场景。

---

#### 题12【填空 — a(x) 型】
**题目**：一质点由静止从原点出发沿 x 轴运动，加速度 $a = 3x^2$（SI）。质点在 $x = 2\ \text{m}$ 处的速度大小为____ m/s。

**解析**：
$a = a(x)$ 型，用 $a = v\dfrac{\mathrm{d}v}{\mathrm{d}x}$：
$$v\,\mathrm{d}v = a(x)\,\mathrm{d}x = 3x^2\,\mathrm{d}x$$
两边积分（$x=0$ 时 $v=0$）：
$$\int_0^v v'\,\mathrm{d}v' = \int_0^2 3x'^2\,\mathrm{d}x'$$
$$\frac{1}{2}v^2 = [x'^3]_0^2 = 8$$
$$v^2 = 16 \implies v = 4\ \text{m/s}$$
**答案**：4

## 📝 模块五：相对运动

### 📌 考点 5：小船渡河与风中飞机

#### 题13【填空】
**题目**：河宽 $d = 200\ \text{m}$，水流速度 $u = 2\ \text{m/s}$ 方向向东。小船在静水中的航速为 $v = 4\ \text{m/s}$。要使小船以**最短时间**到达对岸，船头应向____ 方向（填"正对岸"或"上游偏某角度"），最短时间为____ s。

**解析**：
1. 最短时间条件：船头指向正对岸（船速垂直河岸方向），此时水流只管横向漂移，不影响渡河时间。
2. 最短时间：
   $$t_{\min} = \frac{d}{v_{\text{船}}} = \frac{200}{4} = 50\ \text{s}$$
**答案**：正对岸，50

> [!corollary] 最短时间 vs 最短路径
> - **最短时间**：船头对准对岸，水流不影响垂直河岸的分速度 → $t_{\min} = d/v_{\text{船}}$
> - **最短路径（正对岸到达）**：船头偏向上游，合速度正对对岸 → 需要 $v_{\text{船}} > u$ 才可行

---

#### 题14【填空】
**题目**：一架飞机从 A 城飞往正北方向的 B 城，两城相距 $300\ \text{km}$。飞机在静止空气中的航速为 $200\ \text{km/h}$。飞行时遇到风速 $50\ \text{km/h}$ 的正西风。若飞机要沿正北方向直线飞行，机头应偏向____ 方向，飞行时间为____ h。

**解析**：
1. 要使合速度指向正北，飞机速度的西向分量必须抵消东风：
   $$v_{\text{飞机}}\sin\theta = u \implies 200\sin\theta = 50 \implies \sin\theta = 0.25 \implies \theta \approx 14.5^\circ$$
   机头应偏向**西偏北**（即西北方向偏北）。

2. 合速度的正北分量：
   $$v_{\text{北}} = v_{\text{飞机}}\cos\theta = 200 \times \sqrt{1 - 0.25^2} = 200 \times \sqrt{0.9375} \approx 193.6\ \text{km/h}$$

3. 飞行时间：
   $$t = \frac{300}{193.6} \approx 1.55\ \text{h}$$
**答案**：西偏北约 $14.5^\circ$（或西北方向），1.55

## 📝 模块六：图像法

### 📌 考点 6：从 v-t 图和 a-t 图提取信息

#### 题15【填空】
**题目**：一质点沿直线运动，其 $v$-$t$ 图如图所示：$0$~$2$ s 内速度从 0 线性增加到 $4\ \text{m/s}$；$2$~$5$ s 内以 $4\ \text{m/s}$ 匀速运动；$5$~$7$ s 内速度从 $4\ \text{m/s}$ 线性减小到 0。则 $0$~$7$ s 内质点的总位移为____ m。

**解析**：
v-t 图下面积 = 位移：
1. 0~2 s：三角形面积 = $\dfrac{1}{2} \times 2 \times 4 = 4\ \text{m}$
2. 2~5 s：矩形面积 = $3 \times 4 = 12\ \text{m}$
3. 5~7 s：三角形面积 = $\dfrac{1}{2} \times 2 \times 4 = 4\ \text{m}$
总位移：$4 + 12 + 4 = 20\ \text{m}$
**答案**：20

---

#### 题16【单选】
**题目**：一质点从静止开始沿直线运动，其 $a$-$t$ 图如图所示：$0$~$2$ s 内 $a = 3\ \text{m/s}^2$；$2$~$5$ s 内 $a = 0$；$5$~$6$ s 内 $a = -2\ \text{m/s}^2$。则 $t = 6\ \text{s}$ 时质点的速度为____ m/s。
*   (A) 0
*   (B) 2
*   (C) 3
*   (D) 4

**解析**：
a-t 图下面积 = 速度变化量：
1. 0~2 s：$\Delta v_1 = 3 \times 2 = 6\ \text{m/s}$
2. 2~5 s：$\Delta v_2 = 0$
3. 5~6 s：$\Delta v_3 = -2 \times 1 = -2\ \text{m/s}$
总速度：$v_6 = 0 + 6 + 0 - 2 = 4\ \text{m/s}$
故选 **(D)**。

*   **🔑 老师划重点**：
    *   $v$-$t$ 图面积 = 位移；$a$-$t$ 图面积 = 速度变化。
    *   这不是什么高级技巧，就是积分的几何意义。一条线画给你，别傻傻列方程。

## 📝 模块七：综合计算

### 📌 考点 7：抛体命中条件

#### 题17【计算】
**题目**：一炮弹以初速率 $v_0 = 50\ \text{m/s}$ 从地面发射，仰角 $\theta = 53^\circ$。在炮弹飞行的同时，正前方水平距离 $d = 120\ \text{m}$ 处有一辆汽车从静止开始以 $a = 2\ \text{m/s}^2$ 沿炮弹飞行方向匀加速行驶。问炮弹是否能命中汽车？若能命中，命中时炮弹已飞行了多少秒？（$g = 10\ \text{m/s}^2$，$\sin53^\circ = 0.8$，$\cos53^\circ = 0.6$）

**解析**：
1. **炮弹的运动方程**：
   $$x_{\text{炮}} = v_0\cos\theta \cdot t = 50 \times 0.6 \times t = 30t$$
   $$y_{\text{炮}} = v_0\sin\theta \cdot t - \frac{1}{2}gt^2 = 40t - 5t^2$$

2. **汽车的运动方程**：
   $$x_{\text{车}} = d + \frac{1}{2}at^2 = 120 + t^2$$

3. **命中条件**：同时满足水平方向相遇和竖直方向落地（$y=0$）。
   先由 $y=0$ 求飞行时间（排除 $t=0$）：
   $$40t - 5t^2 = 0 \implies t(40 - 5t) = 0 \implies t = 8\ \text{s}$$

4. **$t = 8\ \text{s}$ 时**：
   $$x_{\text{炮}} = 30 \times 8 = 240\ \text{m}$$
   $$x_{\text{车}} = 120 + 8^2 = 120 + 64 = 184\ \text{m}$$
   $x_{\text{炮}} \neq x_{\text{车}}$ → **不能命中**。

> **答案**：不能命中（$t=8\ \text{s}$ 时炮弹水平距离 240 m，汽车仅前进到 184 m）

### 📌 考点 8：圆周运动总加速度

#### 题18【填空】
**题目**：一质点沿半径 $R = 1\ \text{m}$ 的圆周运动，其路程 $S$ 随时间变化规律为 $S = \pi t^2$（SI）。当总加速度 $a$ 的方向与半径方向夹角为 $45^\circ$ 时，质点已运动的时间为____ s。

**解析**：
1. 速率：$v = \dfrac{\mathrm{d}S}{\mathrm{d}t} = 2\pi t$
2. 切向加速度：$a_t = \dfrac{\mathrm{d}v}{\mathrm{d}t} = 2\pi$（恒定）
3. 法向加速度：$a_n = \dfrac{v^2}{R} = \dfrac{(2\pi t)^2}{1} = 4\pi^2 t^2$
4. 总加速度方向与半径夹角为 $45^\circ$ → 切向加速度与法向加速度大小相等：
   $$a_t = a_n \implies 2\pi = 4\pi^2 t^2$$
   $$t^2 = \frac{2\pi}{4\pi^2} = \frac{1}{2\pi} \implies t = \frac{1}{\sqrt{2\pi}} \approx 0.399\ \text{s}$$
**答案**：$\dfrac{1}{\sqrt{2\pi}}$（约 0.399）

> [!corollary] 关键理解
> 总加速度与半径夹角 $\varphi$ 满足 $\tan\varphi = \dfrac{a_t}{a_n}$。当 $\varphi=45^\circ$ 时 $a_t = a_n$。
