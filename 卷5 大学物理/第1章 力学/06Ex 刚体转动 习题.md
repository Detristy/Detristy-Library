## 核心公式速查表

> 💡 **小贴士**：刚体转动和质点平动是一一对应的——把 $F \to M$、$m \to J$、$v \to \omega$、$a \to \alpha$ 替换就行！

### 1. 转动惯量
- 定义：$J = \sum m_i r_i^2$，连续体：$J = \int r^2\,\mathrm{d}m$
- 常见形状（均质）：
  - 细杆绕端点：$J = \dfrac{1}{3}mL^2$
  - 细杆绕中点：$J = \dfrac{1}{12}mL^2$
  - 圆盘/圆柱绕中心轴：$J = \dfrac{1}{2}mR^2$
  - 圆环绕中心轴：$J = mR^2$
  - 实心球绕直径：$J = \dfrac{2}{5}mR^2$
- **平行轴定理**：$J = J_C + md^2$
- **补缺法**：$J_{\text{所求}} = J_{\text{完整}} - J_{\text{挖去}}$

### 2. 转动定律
- $M = J\alpha$（$M$ 是**合外力矩**）
- 线量与角量关系：$a_t = R\alpha$，$v = R\omega$
- 力矩：$M = rF\sin\varphi$（$\varphi$ 为 $\vec{r}$ 与 $\vec{F}$ 夹角）

### 3. 刚体的功和能
- 转动动能：$E_k = \dfrac{1}{2}J\omega^2$
- 力矩做功：$W = \int_{\theta_1}^{\theta_2} M\,\mathrm{d}\theta$
- 动能定理：$W = \Delta E_k = \dfrac{1}{2}J\omega_2^2 - \dfrac{1}{2}J\omega_1^2$
- 重力势能（刚体）：$E_p = mgh_c$（$h_c$ 为质心高度）
- 机械能守恒：只有保守力做功时 $E_k + E_p = \text{常数}$

### 4. 质点+刚体连接体
- 绳绕飞轮不打滑 → 挂物线加速度 $a$ 与飞轮角加速度 $\alpha$ 满足 $a = R\alpha$
- 对挂物：$mg - T = ma$
- 对飞轮：$TR = J\alpha$
- 联立消 $T$ 求解

### 5. 非惯性系+滑轮
- 等效重力加速度（竖直加速系）：$g_{\text{eff}} = g \pm a$
- 水平加速系：加惯性力 $\vec{F}_{\text{惯}} = -m\vec{a}_0$，分解到所需方向

## 📝 模块一：转动惯量计算

### 📌 考点 1：积分法与常见形状

#### 题1【单选】
**题目**：一质量为 $m$、半径为 $R$ 的均匀薄圆盘，绕通过其圆心且垂直于盘面的轴转动。其转动惯量为____。
*   (A) $mR^2$
*   (B) $\dfrac{1}{2}mR^2$
*   (C) $\dfrac{1}{4}mR^2$
*   (D) $\dfrac{2}{5}mR^2$

**解析**：
均匀圆盘绕中心垂直轴的转动惯量为 $J = \dfrac{1}{2}mR^2$，这是需要强记的结论。
用积分验证：取半径 $r$ 处宽 $\mathrm{d}r$ 的圆环，$\mathrm{d}m = \dfrac{m}{\pi R^2}\cdot 2\pi r\mathrm{d}r$，$J = \int_0^R r^2\mathrm{d}m = \dfrac{1}{2}mR^2$。
故选 **(B)**。

*   **🔑 老师划重点**：
    *   圆盘 $\to \frac{1}{2}mR^2$，圆环 $\to mR^2$（所有质量在 $r=R$ 处）。千万别搞混！
    *   实心球绕直径是 $\frac{2}{5}mR^2$，但大物一般不考。

---

#### 题2【单选】
**题目**：一质量为 $m$、长度为 $L$ 的均匀细杆。其对通过杆一端且垂直于杆的轴的转动惯量为 $J_A$，对通过杆中心且垂直于杆的轴的转动惯量为 $J_O$。则 $J_A : J_O =$ ____。
*   (A) $1:1$
*   (B) $2:1$
*   (C) $3:1$
*   (D) $4:1$

**解析**：
$J_O = \dfrac{1}{12}mL^2$（绕中心）
$J_A = \dfrac{1}{3}mL^2$（绕端点）
比值：$\dfrac{1/3}{1/12} = 4$。
也可以用平行轴定理验证：$J_A = J_O + m\left(\dfrac{L}{2}\right)^2 = \dfrac{1}{12}mL^2 + \dfrac{1}{4}mL^2 = \dfrac{1}{3}mL^2$ ✓
故选 **(D)**。

---

### 📌 考点 2：平行轴定理

#### 题3【填空】
**题目**：一质量为 $m$、半径为 $R$ 的均匀薄圆盘，绕通过其边缘且垂直于盘面的轴转动。该转动惯量为__。（结果用 $m, R$ 表示）

**解析**：
1. 圆盘绕中心轴的转动惯量：$J_C = \dfrac{1}{2}mR^2$
2. 应用平行轴定理（$d = R$）：
   $$J = J_C + md^2 = \frac{1}{2}mR^2 + mR^2 = \frac{3}{2}mR^2$$
**答案**：$\dfrac{3}{2}mR^2$

> [!corollary] 平行轴定理
> $J = J_C + md^2$，$d$ 是两平行轴之间的距离。$J_C$ 必须是通过**质心**的轴的转动惯量。

### 📌 考点 3：补缺法（挖孔）

#### 题4【填空】
**题目**：一半径为 $R$、质量为 $M$ 的均匀圆盘，在距圆心 $d = R/2$ 处挖去一半径为 $r = R/4$ 的小圆孔。剩余部分对通过大圆盘圆心且垂直于盘面的轴的转动惯量为___。（结果用 $M, R$ 表示）

**解析**：
1. **完整大圆盘**的转动惯量：$J_{\text{完整}} = \dfrac{1}{2}MR^2$
2. **挖去部分**的质量（按面积比例）：$m = M\cdot\dfrac{\pi r^2}{\pi R^2} = M\cdot\dfrac{R^2/16}{R^2} = \dfrac{M}{16}$
3. 挖去部分对**大圆盘圆心轴**的转动惯量（平行轴定理）：
   $$J_{\text{挖}} = \frac{1}{2}mr^2 + md^2 = \frac{1}{2}\cdot\frac{M}{16}\cdot\frac{R^2}{16} + \frac{M}{16}\cdot\frac{R^2}{4}$$
   $$= \frac{MR^2}{512} + \frac{MR^2}{64} = MR^2\left(\frac{1}{512} + \frac{8}{512}\right) = \frac{9MR^2}{512}$$
4. **剩余部分**：
   $$J = J_{\text{完整}} - J_{\text{挖}} = \frac{1}{2}MR^2 - \frac{9MR^2}{512} = MR^2\left(\frac{256}{512} - \frac{9}{512}\right) = \frac{247}{512}MR^2$$
**答案**：$\dfrac{247}{512}MR^2$

*   **🔑 老师划重点**：
    *   补缺法 = "完整 − 挖去"。挖去部分如果轴不通过它自己的质心，必须用平行轴定理平移！
    *   注意挖去后总质量变了，但题目说"对过圆心轴"的转动惯量，直接用补缺法减即可。

## 📝 模块二：转动定律 $M=J\alpha$

### 📌 考点 4：恒力矩与变力矩

#### 题5【单选】
**题目**：一飞轮转动惯量为 $J = 2\ \text{kg·m}^2$，在恒力矩 $M = 4\ \text{N·m}$ 作用下从静止开始转动。$t = 3\ \text{s}$ 时飞轮的角速度为____ rad/s。
*   (A) 2
*   (B) 4
*   (C) 6
*   (D) 8

**解析**：
1. 转动定律：$\alpha = \dfrac{M}{J} = \dfrac{4}{2} = 2\ \text{rad/s}^2$
2. 匀角加速度：$\omega = \omega_0 + \alpha t = 0 + 2 \times 3 = 6\ \text{rad/s}$
故选 **(C)**。

---

#### 题6【填空】
**题目**：一转动惯量为 $J$ 的飞轮以角速度 $\omega_0$ 转动。在制动力矩 $M = -k\omega$（$k$ 为常数）作用下减速。角速度减小到 $\omega_0/2$ 时飞轮转过的角度为____。

**解析**：
1. 转动定律：$-k\omega = J\dfrac{\mathrm{d}\omega}{\mathrm{d}t}$
2. 用链式法则：$\dfrac{\mathrm{d}\omega}{\mathrm{d}t} = \dfrac{\mathrm{d}\omega}{\mathrm{d}\theta}\cdot\omega$
   $$-k\omega = J\omega\frac{\mathrm{d}\omega}{\mathrm{d}\theta} \implies -k = J\frac{\mathrm{d}\omega}{\mathrm{d}\theta}$$
3. 分离变量积分：
   $$\int_{\omega_0}^{\omega_0/2} \mathrm{d}\omega = -\frac{k}{J}\int_0^{\Delta\theta} \mathrm{d}\theta$$
   $$\frac{\omega_0}{2} - \omega_0 = -\frac{k}{J}\Delta\theta$$
   $$-\frac{\omega_0}{2} = -\frac{k}{J}\Delta\theta \implies \Delta\theta = \frac{J\omega_0}{2k}$$
**答案**：$\dfrac{J\omega_0}{2k}$

> [!corollary] 小结
> $M \propto \omega$ 的阻力矩 → 角速度对转角的衰减是**线性**的。和 308A 题7（试卷二）的时间衰减解法是同源的——那里分离变量是对 $t$，这里是对 $\theta$。

---

#### 题7【填空】
**题目**：一均匀细杆质量为 $m$、长为 $L$，可绕通过其一端 $O$ 的水平光滑轴在竖直平面内自由转动。初始时杆静止在水平位置，释放瞬间杆的角加速度大小为____。

**解析**：
1. 杆绕端点的转动惯量：$J = \dfrac{1}{3}mL^2$
2. 释放瞬间杆水平，重力作用在质心（距 $O$ 点 $L/2$），力矩：
   $$M = mg\cdot\frac{L}{2}$$
3. 转动定律：
   $$\alpha = \frac{M}{J} = \frac{mgL/2}{mL^2/3} = \frac{3g}{2L}$$
**答案**：$\dfrac{3g}{2L}$

*   **🔑 老师划重点**：
    *   重力矩 = $mg \times$ 质心到轴的水平距离。杆在不同角度时力矩 = $mg\dfrac{L}{2}\cos\theta$。
    *   释放瞬间是力矩最大的时刻，角加速度也最大。

## 📝 模块三：刚体的功和能

### 📌 考点 5：转动动能与机械能守恒

#### 题8【填空】
**题目**：一飞轮转动惯量为 $J = 0.5\ \text{kg·m}^2$，以 $\omega = 20\ \text{rad/s}$ 转动。其转动动能为____ J。

**解析**：
$$E_k = \frac{1}{2}J\omega^2 = \frac{1}{2} \times 0.5 \times 400 = 100\ \text{J}$$
**答案**：100

---

#### 题9【填空】
**题目**：一均匀细杆质量为 $m$、长为 $L$，可绕通过其一端 $O$ 的水平光滑轴在竖直平面内自由转动。初始时杆静止在**水平**位置，释放后杆绕 $O$ 下摆。当杆摆到**竖直向下**位置时，杆的角速度为___。（结果用 $g, L$ 表示）

**解析**：
机械能守恒。取 $O$ 点所在水平面为重力势能零点。

- 初态（水平）：质心与 $O$ 等高，势能 $E_{p0} = 0$；动能 $E_{k0} = 0$
- 末态（竖直向下）：质心在 $O$ 下方 $L/2$，势能 $E_p = -mg\dfrac{L}{2}$；动能 $E_k = \dfrac{1}{2}J\omega^2 = \dfrac{1}{2}\cdot\dfrac{1}{3}mL^2\cdot\omega^2$

机械能守恒：
$$0 = \frac{1}{6}mL^2\omega^2 - mg\frac{L}{2}$$
$$\frac{1}{6}L\omega^2 = \frac{g}{2} \implies \omega^2 = \frac{3g}{L} \implies \omega = \sqrt{\frac{3g}{L}}$$
**答案**：$\sqrt{\dfrac{3g}{L}}$

> 300A 题25（试卷一）出过类似题，但方向相反（从最低摆到水平）。思路完全一样——机械能守恒 + 取好零势能面。

---

#### 题10【填空】
**题目**：一均匀细杆质量为 $m$、长为 $L$，可绕通过其一端 $O$ 的水平光滑轴转动。先将杆从竖直下垂位置拨动，使其获得初角速度 $\omega_0$。若杆恰好能摆到水平位置（角速度刚好减为零），则 $\omega_0 =$ ____。

**解析**：
机械能守恒，取 $O$ 点为零势能面。

- 初态（竖直下垂）：质心在 $O$ 下方 $L/2$，$E_{p0} = -mgL/2$；$E_{k0} = \dfrac{1}{2}J\omega_0^2 = \dfrac{1}{6}mL^2\omega_0^2$
- 末态（刚好水平）：质心与 $O$ 等高，$E_p = 0$；$E_k = 0$

$$\frac{1}{6}mL^2\omega_0^2 - mg\frac{L}{2} = 0 \implies \omega_0 = \sqrt{\frac{3g}{L}}$$

恰好和题9的末态角速度一样——对称的！
**答案**：$\sqrt{\dfrac{3g}{L}}$

## 📝 模块四：刚体+连接体综合

### 📌 考点 6：绳绕飞轮 + 挂物

#### 题11【填空】
**题目**：一轻绳绕在质量为 $M$、半径为 $R$ 的匀质圆盘形飞轮边缘，飞轮可绕通过盘心且垂直于盘面的水平轴自由转动。绳端悬挂一质量为 $m$ 的物体。释放后物体下落。求物体下落的加速度 $a$。（结果用 $m, M, g$ 表示）

**解析**：
1. **挂物 $m$**（向下为正）：$mg - T = ma$
2. **飞轮**（转动定律，力矩 $TR$）：$TR = J\alpha$，$J = \dfrac{1}{2}MR^2$
3. **线角约束**（绳不打滑）：$a = R\alpha$
4. 联立：
   $$T = \frac{J\alpha}{R} = \frac{\frac{1}{2}MR^2 \cdot a/R}{R} = \frac{1}{2}Ma$$
   代入：$mg - \dfrac{1}{2}Ma = ma \implies mg = \left(m + \dfrac{M}{2}\right)a$
   $$a = \frac{mg}{m + M/2}$$
**答案**：$\dfrac{mg}{m + M/2}$

> 如果没有飞轮（绳直接固定），$a = g$；有飞轮后，飞轮的转动惯量"拖慢"了下落。$M \to 0$ 时 $a \to g$，验证通过 ✓

---

#### 题12【填空】
**题目**：在题11中，若 $M = 4m$，则绳中张力 $T$ 为____。（结果用 $mg$ 表示）

**解析**：
代入 $M = 4m$：
$$a = \frac{mg}{m + 2m} = \frac{g}{3}$$
$$T = m(g - a) = m\left(g - \frac{g}{3}\right) = \frac{2}{3}mg$$
或用飞轮端：$T = \dfrac{1}{2}Ma = \dfrac{1}{2} \cdot 4m \cdot \dfrac{g}{3} = \dfrac{2}{3}mg$ ✓
**答案**：$\dfrac{2}{3}mg$

### 📌 考点 7：滑轮有质量

#### 题13【填空】
**题目**：一轻绳跨过一质量为 $m_0$、半径为 $R$ 的匀质圆盘形定滑轮（可绕中心轴自由转动），绳两端各挂质量为 $m_1$ 和 $m_2$ 的物体（$m_1 > m_2$）。绳与滑轮间不打滑。求系统的加速度 $a$。（结果用 $m_1, m_2, m_0, g$ 表示）

**解析**：
这是有质量滑轮的阿特伍德机。滑轮有转动惯量 → 两侧绳张力不相等！

设 $T_1$ 为 $m_1$ 侧张力，$T_2$ 为 $m_2$ 侧张力。

1. $m_1$（向下为正）：$m_1g - T_1 = m_1a$
2. $m_2$（向上为正）：$T_2 - m_2g = m_2a$
3. 滑轮转动：$(T_1 - T_2)R = J\alpha$，$J = \dfrac{1}{2}m_0R^2$
4. 线角约束：$a = R\alpha$

由 (3)：$(T_1 - T_2)R = \dfrac{1}{2}m_0R^2\cdot\dfrac{a}{R} \implies T_1 - T_2 = \dfrac{1}{2}m_0 a$

(1) − (2)：$(m_1 - m_2)g - (T_1 - T_2) = (m_1 + m_2)a$
代入 $T_1 - T_2$：
$$(m_1 - m_2)g - \frac{1}{2}m_0 a = (m_1 + m_2)a$$
$$(m_1 - m_2)g = \left(m_1 + m_2 + \frac{1}{2}m_0\right)a$$
$$a = \frac{(m_1 - m_2)g}{m_1 + m_2 + m_0/2}$$
**答案**：$\dfrac{(m_1 - m_2)g}{m_1 + m_2 + m_0/2}$

> 当 $m_0 = 0$（轻滑轮），退化回 $a = \dfrac{m_1 - m_2}{m_1 + m_2}g$ ✓ 滑轮有质量 → 等效于增加了系统的"惯性"。

## 📝 模块五：滑轮 + 非惯性系 进阶 ⚡

> ⚠️ **难度警告**：以下题目融合了滑轮连接体与加速参考系，需要同时处理绳约束和惯性力，是考试压轴题级别的难度。建议先吃透前四模块再啃。

### 📌 考点 8：加速参考系中的滑轮系统

#### 题14【填空】
**题目**：一质量为 $M$ 的斜面体放在光滑水平地面上，斜面倾角 $\theta$，斜面光滑。斜面体上放一质量为 $m$ 的物块，物块通过一轻绳跨过固定在斜面顶端的轻滑轮与一质量为 $m_0$ 的悬挂重物相连，绳与斜面平行。初始系统静止，释放后悬挂重物 $m_0$ 竖直向下运动。设 $M = 2m$，$m_0 = m$，$\theta = 30^\circ$。求悬挂重物 $m_0$ 相对地面的加速度大小。（结果用 $g$ 表示）

**解析**：
这道题的难点在于——斜面体也会动！三个物体各列方程，还要处理相对加速度。

设斜面体对地加速度为 $a_M$（向右），物块 $m$ 相对斜面体的加速度为 $a_r$（沿斜面向上），悬挂重物 $m_0$ 对地加速度为 $a_0$（向下）。

**约束关系**：绳不可伸长 →
- $m$ 的对地加速度 $\vec{a}_m = \vec{a}_r + \vec{a}_M$（矢量合成），沿斜面方向分量为 $a_r - a_M\cos\theta$
- $m_0$ 的加速度 $a_0 = a_r$（绳长约束）

以地面为参考系，各列方程：

**$m_0$（竖直向下为正）**：
$$m_0 g - T = m_0 a_r \quad (1)$$

**$m$（以地面为参考系，沿斜面向上为正）**：
$$T - mg\sin\theta = m(a_r - a_M\cos\theta) \quad (2)$$

**$M$（水平向右为正）**：
垂直斜面方向：$N = mg\cos\theta + m a_M\sin\theta$
水平方向：$N\sin\theta - T\cos\theta = M a_M \quad (3)$

代入数值 $M=2m$, $m_0=m$, $\theta=30^\circ$ 联立求解得：
$$a_r = \frac{3\sqrt{3}+2}{8\sqrt{3}+12}\,g \approx 0.433g$$
$a_0 = a_r \approx 0.433g$（向下）。

**答案**：$a_0 = a_r$，由三方程联立求解。

> [!corollary] 三体+滑轮通用套路
> ① 画三个受力图；② 设斜面加速度 $a_M$ 和相对加速度 $a_r$；③ 写绝对加速度的约束关系；④ 各列地面系 F=ma；⑤ 联立消元。

#### 题15【计算】
**题目**：一电梯以加速度 $a = \dfrac{g}{2}$ **向上**加速。电梯天花板上悬挂一轻滑轮，滑轮两侧用轻绳各挂质量 $m_1 = 3m$ 和 $m_2 = m$ 的物体。求：
(1) 两物体相对电梯的加速度；
(2) 绳中张力 $T$。

**解析**：
**方法：以电梯为参考系**（非惯性系，加速度向上 $a = g/2$）。

两物体受到向下的惯性力：$F_{\text{惯}} = m_i a = m_i \cdot \dfrac{g}{2}$

等效重力加速度：$g_{\text{eff}} = g + a = \dfrac{3g}{2}$

在电梯里看，这就变成了一个静止参考系中的普通阿特伍德机，只是重力加速度换成了 $g_{\text{eff}}$。

**(1)** 相对电梯的加速度（$m_1$ 向下，$m_2$ 向上，大小均为 $a'$）：
$$a' = \frac{m_1 - m_2}{m_1 + m_2}g_{\text{eff}} = \frac{3m - m}{3m + m} \cdot \frac{3g}{2} = \frac{2}{4} \cdot \frac{3g}{2} = \frac{3g}{4}$$

**(2)** 张力：
$$T = m_2(g_{\text{eff}} + a') = m\left(\frac{3g}{2} + \frac{3g}{4}\right) = \frac{9}{4}mg$$
**答案**：(1) $\dfrac{3g}{4}$；(2) $\dfrac{9}{4}mg$

> [!corollary] 等效重力法 — 加速参考系中滑轮的万能钥匙
> 当滑轮+绳子整体在竖直方向以加速度 $a$ 运动时，把所有 $g$ 替换成 $g_{\text{eff}} = g \pm a$（加速向上取 +，向下取 −），阿特伍德机那套公式照搬就行！

#### 题16【填空】
**题目**：一车厢以加速度 $a_0 = \dfrac{g}{3}$ 向右水平加速。车厢内一倾角 $\theta = 37^\circ$ 的光滑斜面固定在车厢地板上，斜面上放一质量为 $m$ 的物块通过轻绳跨过斜面顶端的轻滑轮与一质量为 $3m$ 的悬挂重物相连。绳与斜面平行。释放后系统在车厢内运动。求悬挂重物相对车厢的加速度。（$\sin37^\circ=0.6$，$\cos37^\circ=0.8$）

**解析**：
车厢是非惯性系（水平加速 $a_0 = g/3$ 向右 → 车内物体受向左的惯性力 $ma_0$）。

以车厢为参考系，设重物相对车厢向下加速度为 $a_r$。

**重物 $3m$**（竖直向下为正）：
$$3mg - T = 3m a_r \quad (1)$$
（惯性力水平向左，不影响竖直方向运动方程）

**斜面物块 $m$**（沿斜面向上为正）：
惯性力水平向左，沿斜面分量 = $ma_0\cos37^\circ = m\dfrac{g}{3}\cdot0.8$
$$T - mg\sin37^\circ - ma_0\cos37^\circ = m a_r$$
$$T - 0.6mg - \frac{0.8}{3}mg = m a_r \quad (2)$$

(1) + (2) 消 $T$，精确求解：
$$T = 3m(g - a_r)$$
代入 (2)：$3mg - 3ma_r - \dfrac{3}{5}mg - \dfrac{4}{15}mg = ma_r$
$$3g - \frac{3}{5}g - \frac{4}{15}g = 4a_r$$
$$\frac{45 - 9 - 4}{15}g = 4a_r \implies a_r = \frac{8}{15}g$$
**答案**：$\dfrac{8}{15}g$

> [!corollary] 水平加速 + 斜面滑轮
> 惯性力 $ma_0$ 必须分解到**沿斜面方向**（分量 $ma_0\cos\theta$）和垂直斜面方向。沿斜面分量直接影响加速度方程！

#### 题17【填空】
**题目**：一质量为 $M$ 的楔形块放在光滑水平地面上，斜面倾角 $\theta$，斜面光滑。一质量为 $m$ 的物块放在斜面上。初始时系统静止，释放后物块沿斜面下滑，楔形块向右运动。求楔形块的加速度 $a_M$。（结果用 $g, m, M, \theta$ 表示）

**解析**：
经典自由斜面题。设楔形块向右加速度 $a_M$，物块相对楔形块沿斜面向下加速度 $a_r$。

物块对地加速度：$\vec{a}_m = \vec{a}_r + \vec{a}_M$

**楔形块 $M$**（水平方向）：$N\sin\theta = M a_M \quad (1)$

**物块 $m$**（地面系）：
水平：$a_{mx} = a_r\cos\theta - a_M$ → $N\sin\theta = m(a_r\cos\theta - a_M) \quad (2)$
竖直（向下）：$a_{my} = a_r\sin\theta$ → $mg - N\cos\theta = m a_r\sin\theta \quad (3)$

由 (1)(2)：$M a_M = m(a_r\cos\theta - a_M) \implies a_r\cos\theta = \dfrac{M+m}{m}a_M$

(1) 代入 (3) 消 $N$，解得：
$$a_M = \frac{mg\sin\theta\cos\theta}{M + m\sin^2\theta}$$
**答案**：$\dfrac{mg\sin\theta\cos\theta}{M + m\sin^2\theta}$

> 若 $M \to \infty$（斜面固定）：$a_M \to 0$，$a_r \to g\sin\theta$，退化回固定斜面经典结果 ✓

---

**解法二（非惯性系 + 沿斜面分解）**：

既然物块是沿斜面下滑的，我们索性坐到楔形块上看——虽然楔形块本身在加速，但加上惯性力后就能当"静止参考系"用了。

**坐进楔形块参考系**：楔形块以 $a_M$ 向右加速 → 系内所有物体受到向左的惯性力 $-m a_M$。

对物块 $m$，沿斜面方向（向下为正）和垂直斜面方向（离开斜面为正）分解：

- 重力分量：沿斜面向下 $mg\sin\theta$，垂直斜面 $mg\cos\theta$（压向斜面）
- 惯性力分量：惯性力水平向左，大小为 $ma_M$
  - 沿斜面方向：$ma_M\cos\theta$（沿斜面向上！因为惯性力向左，斜面是↘的，向左的分量反而"推"物块上坡）
  - 垂直斜面方向：$ma_M\sin\theta$（离开斜面方向，因为惯性力向左，有"甩离"斜面的趋势）

**沿斜面方向**的运动方程（相对楔形块，加速度 $a_r$ 向下）：
$$mg\sin\theta - ma_M\cos\theta = m a_r \quad (\text{★})$$

> 注意这里的符号！惯性力向左，沿斜面的分量方向是沿斜面**向上**，与重力分量 $mg\sin\theta$ 相反，所以用减号。

**垂直斜面方向**：物块不脱离斜面，垂直斜面方向无加速度（相对楔形块静止在这个方向上）：
$$N - mg\cos\theta - ma_M\sin\theta = 0 \implies N = mg\cos\theta + ma_M\sin\theta \quad (\text{★★})$$

> 惯性力"甩离"斜面，所以支持力比 $mg\cos\theta$ 要大——这合理：楔形块在向右"逃"，物块压向斜面的力更大了。

**楔形块本身**（地面系，水平方向）：
$$N\sin\theta = M a_M \quad (\text{★★★})$$

三个方程 (★)(★★)(★★★) 联立：

由 (★)：$a_r = g\sin\theta - a_M\cos\theta$

由 (★★★) 代入 $N$：
$$(mg\cos\theta + ma_M\sin\theta)\sin\theta = M a_M$$
$$mg\sin\theta\cos\theta + ma_M\sin^2\theta = M a_M$$
$$mg\sin\theta\cos\theta = a_M(M + m\sin^2\theta)$$
$$a_M = \frac{mg\sin\theta\cos\theta}{M + m\sin^2\theta}$$

和地面系结果完全一致 ✓

> 代入 (★) 得：
> $$a_r = g\sin\theta - \frac{mg\sin\theta\cos^2\theta}{M + m\sin^2\theta} = \frac{(M+m)g\sin\theta}{M + m\sin^2\theta}$$

> [!corollary] 两种解法对比
> | | 地面系（解法一） | 楔形块系（解法二） |
> |---|---|---|
> | 物块方程列在 | 地面（水平和竖直分开） | 楔形块上（沿/垂直斜面） |
> | 是否需要加速度合成 | 是：$\vec{a}_m = \vec{a}_r + \vec{a}_M$ | 否：直接写 $a_r$ |
> | 代价 | 两个分量方程 | 需要加惯性力并正确分解 |
> | 适合人群 | 不习惯惯性力 | 习惯"坐到加速物体上看" |
>
> 两个方法各有利弊。解法二的妙处在于——物块的方程直接写在它"自然"的方向（沿斜面）上，不用把 $\vec{a}_r$ 和 $\vec{a}_M$ 合成。但惯性力的分解方向一定要画图确认，小心符号！

#### 题18【计算 — 综合难题】
**题目**：一质量为 $M$ 的小车在光滑水平地面上，车上固定一倾角 $\theta$ 的光滑斜面和一轻滑轮。一质量为 $m$ 的物块放在斜面上，通过轻绳跨过滑轮与一质量为 $m_h$ 的悬挂重物相连。初始系统静止，小车受到水平力 $F$ 作用，三个物体随小车一起运动且相对小车静止。求：
(1) 小车的加速度 $a$（即整体加速度）；
(2) 若 $m_h = 2m$，$\theta = 30^\circ$，$F$ 需满足什么条件才能保证内部平衡？

**解析**：
**(1)** 以小车为参考系（非惯性系，加速度 $a$ 向右 → 惯性力 $m_i a$ 向左）。

物块沿斜面方向平衡（相对小车静止）：
$$T - mg\sin\theta - ma\cos\theta = 0 \quad (1)$$

重物竖直平衡（惯性力水平，不影响竖直方向）：
$$T - m_h g = 0 \quad (2)$$

由 (2)：$T = m_h g$，代入 (1)：
$$m_h g = mg\sin\theta + ma\cos\theta$$
$$a = \frac{m_h g - mg\sin\theta}{m\cos\theta}$$

**(2)** 代入数值：$a = \dfrac{2mg - mg\cdot0.5}{m\cdot\sqrt{3}/2} = \dfrac{1.5mg}{0.866m} = \sqrt{3}g$

$F = (M + m + m_h)a = (M + 3m)\sqrt{3}g$

> **答案**：(1) $a = \dfrac{m_h g - mg\sin\theta}{m\cos\theta}$；(2) $F = (M+3m)\sqrt{3}g$

> [!corollary] 整体加速内部平衡
> 核心思路：① 非惯性系中各物体平衡；② 惯性力 $-ma$ 加到每个物体上；③ 列平衡方程。这是"整体有加速度但内部无相对运动"的经典考法。
