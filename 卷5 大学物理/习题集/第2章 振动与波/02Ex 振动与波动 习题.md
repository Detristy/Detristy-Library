# 振动与波动 习题精讲

> 本笔记补充 300A 中未覆盖的简谐振动与机械波经典题型：振动能量定量、拍现象、振动曲线读图、驻波波节波腹、波的干涉、多普勒效应定量。

---

## 📌 补1：简谐振动能量

### 题1-1
**题目**：一弹簧振子，劲度系数 $k = 200\text{ N/m}$，物体质量 $m = 0.5\text{ kg}$，振幅 $A = 0.05\text{ m}$。求：(1) 总机械能 $E$；(2) 当位移 $x = A/2$ 时的动能 $E_k$ 和势能 $E_p$。

**解析**：
1. **总机械能**：
   $$E = \frac{1}{2}kA^2 = \frac{1}{2} \times 200 \times (0.05)^2 = 0.25\text{ J}$$
2. **位移 $x = A/2$ 时的势能**：
   $$E_p = \frac{1}{2}kx^2 = \frac{1}{2}k\left(\frac{A}{2}\right)^2 = \frac{1}{4} \cdot \frac{1}{2}kA^2 = \frac{1}{4}E = 0.0625\text{ J}$$
3. **动能**：
   $$E_k = E - E_p = 0.25 - 0.0625 = 0.1875\text{ J}$$

**答案**：(1) $0.25\text{ J}$；(2) $E_k = 0.1875\text{ J}$，$E_p = 0.0625\text{ J}$

> 🔑 **老师划重点**：振动总能量守恒 $E = \frac{1}{2}kA^2 = \frac{1}{2}m\omega^2A^2$。位移 $x = A/2$ 时，$E_p = E/4$，$E_k = 3E/4$。一般地，$E_p/E = (x/A)^2$。

### 题1-2
**题目**：一水平弹簧振子，振幅 $A = 0.1\text{ m}$。测得物体从正向最大位移运动到 $\frac{\sqrt{3}}{2}A$ 处的最短时间为 $t = 0.1\text{ s}$。求：(1) 振动周期 $T$；(2) 若物体质量 $m = 0.2\text{ kg}$，求劲度系数 $k$。

**解析**：
1. **相位分析**：
   设 $x = A\cos\omega t$（取初相 0，$t=0$ 在 $x=A$）。
   当 $x = \frac{\sqrt{3}}{2}A$ 时：$\cos\omega t = \frac{\sqrt{3}}{2}$ → $\omega t = \frac{\pi}{6}$
2. **求角频率**：
   $$\omega \times 0.1 = \frac{\pi}{6} \implies \omega = \frac{\pi}{0.6} = \frac{5\pi}{3}\text{ rad/s}$$
3. **周期**：$T = \frac{2\pi}{\omega} = \frac{2\pi}{5\pi/3} = \frac{6}{5} = 1.2\text{ s}$
4. **劲度系数**：$k = m\omega^2 = 0.2 \times \left(\frac{5\pi}{3}\right)^2 \approx 5.48\text{ N/m}$

**答案**：(1) $1.2\text{ s}$；(2) 约 $5.48\text{ N/m}$

> ⚠️ **易错提醒**：「从正向最大位移出发」→ 初相为 0！如果从负最大出发→初相为 $\pi$。到某位置的时间 = 相位差 ÷ 角频率，不一定是 1/4 周期！

## 📌 补2：振动曲线读图

### 题2-1
**题目**：某质点做简谐振动，其 $x$-$t$ 曲线如图所示：$t=0$ 时位移 $x = \frac{A}{2}$ 且向正方向运动；$t=1\text{ s}$ 时第一次经过平衡位置。求振动方程 $x(t)$。

**解析**：
1. **确定初相 $\phi$**：
   $t=0$ 时 $x = \frac{A}{2}$ → $\cos\phi = \frac{1}{2}$
   又向正方向运动（$v>0$）→ $\sin\phi < 0$ → $\phi$ 在第四象限
   $$\phi = -\frac{\pi}{3} \quad \text{（或 } \frac{5\pi}{3}\text{）}$$
2. **确定角频率 $\omega$**：
   $t=1\text{ s}$ 时第一次过平衡位置（$x=0$），相位为 $\frac{\pi}{2}$ 或 $\frac{3\pi}{2}$。
   从 $-\frac{\pi}{3}$ 到 $\frac{\pi}{2}$：$\omega \times 1 = \frac{\pi}{2} - \left(-\frac{\pi}{3}\right) = \frac{5\pi}{6}$
   $$\omega = \frac{5\pi}{6}\text{ rad/s}$$
3. **振动方程**：
   $$x = A\cos\left(\frac{5\pi}{6}t - \frac{\pi}{3}\right)$$

**答案**：$x = A\cos\left(\frac{5\pi}{6}t - \frac{\pi}{3}\right)$

> 🔑 **老师划重点**：读图三步——①看 $t=0$ 位移定 $\cos\phi$；②看 $t=0$ 速度方向定 $\sin\phi$ 符号；③看关键点时间定 $\omega$。

## 📌 补3：拍现象

### 题3-1
**题目**：一质点同时参与两个同方向的简谐振动：$x_1 = 0.05\cos(100\pi t)$，$x_2 = 0.05\cos(102\pi t)$（SI）。求合振动的拍频 $f_{\text{拍}}$ 和拍的周期 $T_{\text{拍}}$。

**解析**：
1. **两振动角频率**：$\omega_1 = 100\pi$，$\omega_2 = 102\pi$
2. **拍频公式**：
   $$f_{\text{拍}} = |f_2 - f_1| = \frac{|\omega_2 - \omega_1|}{2\pi} = \frac{2\pi}{2\pi} = 1\text{ Hz}$$
3. **拍的周期**：
   $$T_{\text{拍}} = \frac{1}{f_{\text{拍}}} = 1\text{ s}$$

**答案**：$f_{\text{拍}} = 1\text{ Hz}$，$T_{\text{拍}} = 1\text{ s}$

> 🔑 **老师划重点**：拍频 = 两分振动频率之差（不仅是角频率之差/2π）。振幅相等时合振动 $x = 2A\cos(\frac{\Delta\omega}{2}t)\cos(\frac{\omega_1+\omega_2}{2}t)$，振幅包络变化频率 = $\frac{\Delta\omega}{2\pi} = |f_1-f_2|$。

## 📌 补4：波动方程参数提取

### 题4-1
**题目**：一平面简谐波的波动方程为 $y = 0.02\cos\left[\pi(5x - 200t)\right]$（SI）。求：振幅 $A$、波长 $\lambda$、频率 $f$、波速 $u$ 及传播方向。

**解析**：
1. **标准形式对比**：
   $$y = A\cos\left[2\pi\left(\frac{x}{\lambda} - \frac{t}{T}\right) + \phi\right]$$
   已知：$y = 0.02\cos\left[\pi(5x - 200t)\right] = 0.02\cos\left(5\pi x - 200\pi t\right)$
2. **提取参数**：
   - $A = 0.02\text{ m}$
   - $\frac{2\pi}{\lambda} = 5\pi \implies \lambda = \frac{2}{5} = 0.4\text{ m}$
   - $\omega = 200\pi \implies f = \frac{\omega}{2\pi} = 100\text{ Hz}$
   - $u = f\lambda = 100 \times 0.4 = 40\text{ m/s}$
   - $x$ 系数为正→波沿 $+x$ 方向传播

**答案**：$A=0.02\text{ m}$，$\lambda=0.4\text{ m}$，$f=100\text{ Hz}$，$u=40\text{ m/s}$，沿 $+x$ 方向

> 🔑 **老师划重点**：波动方程的标准型 $y = A\cos[\omega(t \mp x/u) + \phi]$。括号里 $t$ 和 $x$ **同号**→沿 $-x$；**异号**→沿 $+x$。参数提取：$k = 2\pi/\lambda$（波数），$\omega/k = u$。

## 📌 补5：已知波形图写波动方程

### 题5-1
**题目**：一平面简谐波沿 $+x$ 方向传播，波速 $u = 20\text{ m/s}$。$t=0$ 时刻波形如图：原点 $x=0$ 处位移 $y=0$ 且向 $+y$ 方向运动；振幅 $A=0.1\text{ m}$；波长 $\lambda = 2\text{ m}$。求波动方程 $y(x,t)$。

**解析**：
1. **参数确定**：
   - $A = 0.1\text{ m}$
   - $\lambda = 2\text{ m}$ → $k = \frac{2\pi}{\lambda} = \pi\text{ rad/m}$
   - $\omega = ku = \pi \times 20 = 20\pi\text{ rad/s}$
2. **确定初相**：
   $t=0$ 时，$x=0$ 处 $y=0$ 且向 $+y$ 运动 → $\phi = -\frac{\pi}{2}$
   （验证：$y(0,0) = A\cos(-\pi/2) = 0$，$v \propto -\sin(-\pi/2) = +1 > 0$ ✓）
3. **波动方程**（沿 $+x$）：
   $$y = 0.1\cos\left(20\pi t - \pi x - \frac{\pi}{2}\right)$$

**答案**：$y = 0.1\cos\left(20\pi t - \pi x - \frac{\pi}{2}\right)$

> 🔑 **老师划重点**：波形图→方程，关键是**原点 $t=0$ 时刻的位移和速度方向定初相**。沿 $+x$ 传：$y = A\cos(\omega t - kx + \phi)$。$x=0$ 处还原为振动方程 $y = A\cos(\omega t + \phi)$。

## 📌 补6：驻波——波节波腹

### 题6-1
**题目**：两列振幅相同的相干波沿相反方向传播，叠加形成驻波。已知驻波方程 $y = 0.04\cos(2\pi x)\cos(100\pi t)$（SI）。求：(1) 波节位置；(2) 波腹位置及振幅；(3) 相邻波节间距。

**解析**：
1. **驻波标准形式**：$y = 2A\cos(kx)\cos(\omega t)$
   对比：$k = 2\pi\text{ rad/m}$，$\omega = 100\pi\text{ rad/s}$，$2A = 0.04 \implies A = 0.02\text{ m}$
2. **波节位置**：$\cos(2\pi x) = 0$
   $$2\pi x = (2n+1)\frac{\pi}{2} \implies x = \frac{2n+1}{4}\text{ m} \quad (n = 0, 1, 2, \dots)$$
   即 $x = 0.25, 0.75, 1.25, \dots \text{ m}$
3. **波腹位置**：$|\cos(2\pi x)| = 1$
   $$2\pi x = n\pi \implies x = \frac{n}{2}\text{ m} \quad (n = 0, 1, 2, \dots)$$
   波腹振幅 = $0.04\text{ m}$
4. **相邻波节间距**：
   $$\Delta x_{\text{节}} = \frac{\lambda}{2} = \frac{2\pi/k}{2} = \frac{\pi}{2\pi} = 0.5\text{ m}$$

**答案**：(1) $x = \frac{2n+1}{4}\text{ m}$；(2) $x = \frac{n}{2}\text{ m}$，振幅 $0.04\text{ m}$；(3) $0.5\text{ m}$

> 🔑 **老师划重点**：驻波波节间距 = 波腹间距 = $\lambda/2$。波节处质元始终不动，波腹处质元振幅最大。$y = 2A\cos(kx)\cos(\omega t)$ 形式中 $\cos(kx)=0$ 是波节。

### 题6-2
**题目**：一根长 $L = 1.5\text{ m}$ 的弦两端固定，波在弦上的传播速度 $u = 300\text{ m/s}$。求：(1) 基频 $f_1$；(2) 能产生驻波的各次谐波频率。

**解析**：
1. **两端固定弦的驻波条件**：两端是波节，弦长必须是半波长的整数倍
   $$L = n\frac{\lambda_n}{2} \implies \lambda_n = \frac{2L}{n} \quad (n=1,2,3,\dots)$$
2. **基频**（$n=1$）：
   $$f_1 = \frac{u}{\lambda_1} = \frac{u}{2L} = \frac{300}{3} = 100\text{ Hz}$$
3. **各次谐波**：$f_n = nf_1 = 100n\text{ Hz}$

**答案**：(1) $100\text{ Hz}$；(2) $f_n = 100n\text{ Hz}$（$n=1,2,3,\dots$）

> 🔑 **老师划重点**：两端固定→两端波节→$L = n\lambda/2$。一端固定一端自由→固定端波节、自由端波腹→$L = (2n-1)\lambda/4$。

## 📌 补7：波的干涉

### 题7-1
**题目**：两相干波源 $S_1$ 和 $S_2$ 相距 $d = 3\text{ m}$，发出同频率、同振幅、初相均为 0 的波，波长 $\lambda = 1\text{ m}$。求 $S_1S_2$ 连线上：(1) 干涉加强点的位置；(2) 干涉减弱点的位置。

**解析**：
1. **设坐标**：$S_1$ 在 $x=0$，$S_2$ 在 $x=3$。连线上一点 $P$ 坐标为 $x$（$0 < x < 3$）。
   两波源初相相同，$P$ 点相位差只由波程差决定：
   $$\Delta\phi = \frac{2\pi}{\lambda}(r_2 - r_1) = \frac{2\pi}{\lambda}[(3-x) - x] = \frac{2\pi}{\lambda}(3-2x)$$
2. **干涉加强**：$\Delta\phi = 2k\pi \implies 3-2x = k\lambda = k$
   $$x = \frac{3-k}{2}, \quad k = 0, \pm1, \pm2, \dots$$
   在 $0<x<3$ 内：$k=2 \to x=0.5$；$k=1 \to x=1.0$；$k=0 \to x=1.5$；$k=-1 \to x=2.0$；$k=-2 \to x=2.5$
3. **干涉减弱**：$\Delta\phi = (2k+1)\pi \implies 3-2x = (2k+1)\frac{\lambda}{2} = k + 0.5$
   $$x = \frac{3 - k - 0.5}{2}, \quad k = 0, \pm1, \pm2, \dots$$
   在 $0<x<3$ 内：$k=2 \to x=0.25$；$k=1 \to x=0.75$；$k=0 \to x=1.25$；$k=-1 \to x=1.75$；$k=-2 \to x=2.25$

**答案**：加强点 $x=0.5,1.0,1.5,2.0,2.5\text{ m}$；减弱点 $x=0.25,0.75,1.25,1.75,2.25\text{ m}$

> 🔑 **老师划重点**：波程差 $\delta = r_2-r_1$。加强：$\delta = k\lambda$；减弱：$\delta = (2k+1)\lambda/2$。若波源有初相差 $\Delta\phi_0$，则总相位差 = $\frac{2\pi}{\lambda}\delta + \Delta\phi_0$。

## 📌 补8：多普勒效应定量计算

### 题8-1
**题目**：一列火车以 $v_s = 30\text{ m/s}$ 的速度驶向站台，鸣笛频率 $f_0 = 500\text{ Hz}$。声速 $c = 340\text{ m/s}$。求：(1) 站台上的人听到的频率；(2) 若火车驶离站台，人听到的频率。

**解析**：
1. **多普勒效应公式**（波源运动，观察者静止）：
   $$f' = f_0 \cdot \frac{c}{c \mp v_s}$$
   波源靠近：分母用 $-$（$f'$ 增大）；波源远离：分母用 $+$（$f'$ 减小）
2. **(1) 驶向**：
   $$f' = 500 \times \frac{340}{340 - 30} = 500 \times \frac{340}{310} \approx 548.4\text{ Hz}$$
3. **(2) 驶离**：
   $$f' = 500 \times \frac{340}{340 + 30} = 500 \times \frac{340}{370} \approx 459.5\text{ Hz}$$

**答案**：(1) $\approx 548\text{ Hz}$；(2) $\approx 459\text{ Hz}$

---

### 题8-2
**题目**：一警车鸣笛发出 $f_0 = 800\text{ Hz}$，以 $v_s = 25\text{ m/s}$ 追赶前方一辆以 $v_o = 15\text{ m/s}$ 同向行驶的汽车。声速 $c = 340\text{ m/s}$。求汽车司机听到的频率。

**解析**：
1. **波源和观察者都在运动**：
   $$f' = f_0 \cdot \frac{c - v_o}{c - v_s}$$
   符号规则：波源向观察者→分母 $-v_s$；观察者远离波源→分子 $-v_o$
2. 代入：
   $$f' = 800 \times \frac{340 - 15}{340 - 25} = 800 \times \frac{325}{315} \approx 825.4\text{ Hz}$$

**答案**：$\approx 825\text{ Hz}$

> 🔑 **老师划重点**：多普勒通用公式 $f' = f_0 \cdot \frac{c \pm v_o}{c \mp v_s}$。口诀：**分子（观察者）向波源取 +，分母（波源）向观察者取 −**。两者都使频率增大时，$f'$ 最大。

## 总结：振动与波动公式速查补

| 题型      | 核心公式                                 | 易错点                                 |
| :------ | :----------------------------------- | :---------------------------------- |
| 振动总能量   | $E = \frac{1}{2}kA^2$                | 任何时刻总能量守恒                           |
| 动能/势能分配 | $E_p/E = (x/A)^2$                    | 端点：$E_k=0$；平衡：$E_p=0$               |
| 拍频      | $f_{\text{拍}} = \vert f_1-f_2 \vert$ | 是频率差，不是角频率差                         |
| 波动方程→参数 | $k=2\pi/\lambda$，$\omega=ku$         | 括号内 $t$ 和 $x$ 异号→沿 $+x$             |
| 驻波波节    | $kx = (2n+1)\pi/2$                   | 波节间距 = $\lambda/2$                  |
| 两端固定弦   | $f_n = n\frac{u}{2L}$                | 一端固定一端自由：$f_n = (2n-1)\frac{u}{4L}$ |
| 干涉加强    | $\delta = k\lambda$                  | 别忘了波源初相差                            |
| 多普勒效应   | $f' = f_0\frac{c\pm v_o}{c\mp v_s}$  | 相对运动方向决定 ±                          |
