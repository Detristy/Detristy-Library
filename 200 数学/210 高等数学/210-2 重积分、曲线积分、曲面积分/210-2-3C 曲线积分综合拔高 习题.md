# 曲线积分综合拔高 习题精讲

> 本篇为曲线积分的**综合与拔高专题（C篇）**。这里不再区分第一类还是第二类，而是将两类积分的几何性质、物理背景、对称性、格林公式以及相互转换混在一起。题目具有较强的综合性与隐蔽性，适合冲刺高分使用。

---

## 📌 题型1：对称性对空间曲线的“降维打击”

### 题1-1
**题目**：计算 $\displaystyle\int_\Gamma (x^2+y^2)\,\mathrm{d}s$，其中 $\Gamma$ 为球面 $x^2+y^2+z^2=a^2$ 与平面 $x+y+z=0$ 的交线。

**解析**：
1. **寻找约束关系**：
   积分曲线 $\Gamma$ 既在球面上，也在平面上。因此，在 $\Gamma$ 上天然满足关系式：
   $$x^2+y^2+z^2=a^2$$
2. **分析对称性**：
   观察积分曲线 $\Gamma$ 的方程：
   - 球面 $x^2+y^2+z^2=a^2$ 关于 $x, y, z$ 轮换对称；
   - 平面 $x+y+z=0$ 关于 $x, y, z$ 也轮换对称。
   
   因此，交线 $\Gamma$ 关于 $x, y, z$ 具有**轮换对称性**。
3. **化简积分**：
   利用轮换对称性，有：
   $$\int_\Gamma x^2\,\mathrm{d}s = \int_\Gamma y^2\,\mathrm{d}s = \int_\Gamma z^2\,\mathrm{d}s$$
   由此可得：
   $$\int_\Gamma (x^2+y^2+z^2)\,\mathrm{d}s = 3\int_\Gamma x^2\,\mathrm{d}s$$
   代入球面约束条件：
   $$\int_\Gamma a^2\,\mathrm{d}s = a^2 \int_\Gamma \mathrm{d}s = 3\int_\Gamma x^2\,\mathrm{d}s$$
   因为 $\Gamma$ 是通过球心的平面与球面相交而成的大圆，其半径为 $a$，所以其弧长（周长）为 $S(\Gamma) = 2\pi a$。
   从而：
   $$a^2 \cdot 2\pi a = 3\int_\Gamma x^2\,\mathrm{d}s \implies \int_\Gamma x^2\,\mathrm{d}s = \frac{2\pi a^3}{3}$$
4. **求出目标积分**：
   所求积分为：
   $$\int_\Gamma (x^2+y^2)\,\mathrm{d}s = \int_\Gamma x^2\,\mathrm{d}s + \int_\Gamma y^2\,\mathrm{d}s = 2\int_\Gamma x^2\,\mathrm{d}s = \frac{4\pi a^3}{3}$$

**答案**：$\dfrac{4\pi a^3}{3}$

> 🔑 **老师划重点**：空间交线的第一类积分如果去老老实实写参数方程，会陷入极其复杂的三角化简泥潭。**利用“曲线在面上”的代数特征与“轮换对称性”直接降维**是这类题目的唯一秒杀通道。切记：轮换对称性的前提是**曲线和被积函数都具有对称性**。

## 📌 题型2：空间交线的精细参数化

### 题2-1
**题目**：计算 $\displaystyle\int_\Gamma z\,\mathrm{d}s$，其中 $\Gamma$ 是圆柱面 $x^2+y^2=ax$ 与半球面 $x^2+y^2+z^2=a^2$（$z\geq 0$）的交线（常数 $a > 0$）。

**解析**：
1. **参数化空间交线（维维安尼曲线段）**：
   交线在 $xOy$ 面上的投影为圆 $x^2+y^2=ax$。
   引入极坐标系：$x=\rho\cos\theta$，$y=\rho\sin\theta$，其中 $-\dfrac{\pi}{2} \leq \theta \leq \dfrac{\pi}{2}$。
   投影圆方程化为：$\rho = a\cos\theta$。
   由此可得 $x, y$ 的参数方程：
   $$x = \rho\cos\theta = a\cos^2\theta$$
   $$y = \rho\sin\theta = a\cos\theta\sin\theta = \frac{a}{2}\sin 2\theta$$
   再代入半球面方程 $z = \sqrt{a^2 - (x^2+y^2)}$（因 $z\geq 0$）：
   $$z = \sqrt{a^2 - ax} = \sqrt{a^2 - a^2\cos^2\theta} = a\sqrt{1-\cos^2\theta} = a|\sin\theta|$$
2. **利用对称性简化**：
   由于 $\Gamma$ 关于 $xOz$ 平面对称（$y \to -y$ 即 $\theta \to -\theta$），而被积函数 $z = a|\sin\theta|$ 关于 $\theta$ 是偶函数，因此可以仅在第一象限 $\theta\in\left[0, \dfrac{\pi}{2}\right]$ 计算，最后结果乘以 $2$。
   此时在该区间内，有 $z = a\sin\theta$。
3. **计算弧长微元 $\mathrm{d}s$**：
   对参数求导：
   $$x'(\theta) = -2a\cos\theta\sin\theta = -a\sin 2\theta$$
   $$y'(\theta) = a\cos 2\theta$$
   $$z'(\theta) = a\cos\theta$$
   代入 $\mathrm{d}s$ 公式：
   $$\mathrm{d}s = \sqrt{[x'(\theta)]^2 + [y'(\theta)]^2 + [z'(\theta)]^2}\,\mathrm{d}\theta = \sqrt{a^2\sin^2 2\theta + a^2\cos^2 2\theta + a^2\cos^2\theta}\,\mathrm{d}\theta = a\sqrt{1+\cos^2\theta}\,\mathrm{d}\theta$$
4. **积分计算**：
   $$I = 2\int_0^{\pi/2} (a\sin\theta) \cdot a\sqrt{1+\cos^2\theta}\,\mathrm{d}\theta = 2a^2 \int_0^{\pi/2} \sqrt{1+\cos^2\theta}\,\mathrm{d}(-\cos\theta)$$
   令 $u = \cos\theta$，则当 $\theta: 0 \to \dfrac{\pi}{2}$ 时，$u: 1 \to 0$。
   $$I = 2a^2 \int_0^1 \sqrt{1+u^2}\,\mathrm{d}u$$
   利用积分公式 $\displaystyle\int \sqrt{1+u^2}\,\mathrm{d}u = \frac{u}{2}\sqrt{1+u^2} + \frac{1}{2}\ln(u+\sqrt{1+u^2})$：
   $$I = 2a^2 \left[ \frac{\sqrt{2}}{2} + \frac{1}{2}\ln(1+\sqrt{2}) \right] = a^2\left[\sqrt{2} + \ln(1+\sqrt{2})\right]$$

**答案**：$a^2\left[\sqrt{2} + \ln(1+\sqrt{2})\right]$

> ⚠️ **易错提醒**：把空间交线写成参数方程时，极坐标的 $\theta$ 变化范围是 $\left[-\dfrac{\pi}{2}, \dfrac{\pi}{2}\right]$，消去绝对值号时要特别小心。在计算 $\mathrm{d}s$ 时，一定要把三个分量的导数平方和彻底化简（这里利用了 $\sin^2 2\theta + \cos^2 2\theta = 1$），否则后续积分根本无法进行。

## 📌 题型3：非圆奇点模型的挖洞技巧

### 题3-1
**题目**：计算曲线积分 $\displaystyle\oint_C \frac{x\,\mathrm{d}y - y\,\mathrm{d}x}{x^2+4y^2}$，其中 $C$ 是包围椭圆 $x^2+4y^2=1$ 的任意正向简单闭曲线。

**解析**：
1. **寻找奇点与偏导数关系**：
   被积函数在原点 $(0,0)$ 处无意义，即原点是奇点。设：
   $$P = \frac{-y}{x^2+4y^2},\quad Q = \frac{x}{x^2+4y^2}$$
   在整个平面除去原点的区域内，计算偏导数：
   $$P_y = \frac{-(x^2+4y^2) - (-y)(8y)}{(x^2+4y^2)^2} = \frac{4y^2-x^2}{(x^2+4y^2)^2}$$
   $$Q_x = \frac{(x^2+4y^2) - x(2x)}{(x^2+4y^2)^2} = \frac{4y^2-x^2}{(x^2+4y^2)^2}$$
   可见 $P_y = Q_x$ 在除原点外的区域恒成立。
2. **利用挖洞法转换路径**：
   因为 $C$ 包围原点，我们可以在 $C$ 内部挖去一个以原点为中心的极小正向椭圆 $C_\varepsilon: x^2+4y^2=\varepsilon^2$。
   根据复连通区域的格林公式，有：
   $$\oint_C \frac{x\,\mathrm{d}y - y\,\mathrm{d}x}{x^2+4y^2} = \oint_{C_\varepsilon} \frac{x\,\mathrm{d}y - y\,\mathrm{d}x}{x^2+4y^2}$$
3. **参数化椭圆并计算**：
   设 $C_\varepsilon$ 的参数方程为：
   $$x = \varepsilon\cos t,\quad y = \frac{\varepsilon}{2}\sin t\quad (t: 0 \to 2\pi)$$
   则微分项为：
   $$\mathrm{d}x = -\varepsilon\sin t\,\mathrm{d}t,\quad \mathrm{d}y = \frac{\varepsilon}{2}\cos t\,\mathrm{d}t$$
   代入分子：
   $$x\,\mathrm{d}y - y\,\mathrm{d}x = (\varepsilon\cos t)\left(\frac{\varepsilon}{2}\cos t\right)\,\mathrm{d}t - \left(\frac{\varepsilon}{2}\sin t\right)(-\varepsilon\sin t)\,\mathrm{d}t = \frac{\varepsilon^2}{2}(\cos^2 t + \sin^2 t)\,\mathrm{d}t = \frac{\varepsilon^2}{2}\,\mathrm{d}t$$
   代入分母：
   $$x^2+4y^2 = \varepsilon^2\cos^2 t + 4\left(\frac{\varepsilon^2}{4}\sin^2 t\right) = \varepsilon^2$$
   于是：
   $$I = \oint_{C_\varepsilon} \frac{\frac{\varepsilon^2}{2}\,\mathrm{d}t}{\varepsilon^2} = \int_0^{2\pi} \frac{1}{2}\,\mathrm{d}t = \pi$$

**答案**：$\pi$

> 🔑 **老师划重点**：这道题是经典“原点奇点”模型 $\displaystyle\oint \frac{-y\mathrm{d}x+x\mathrm{d}y}{x^2+y^2}=2\pi$ 的变形。由于分母是 $x^2+4y^2$，我们在挖洞时**不能挖圆，而应该顺应分母的结构挖椭圆 $x^2+4y^2=\varepsilon^2$**，这样才能利用参数化把分母化为常数 $\varepsilon^2$ 从而轻松消去。

## 📌 题型4：两类曲线积分的相互转化

### 题4-1
**题目**：计算 $\displaystyle\oint_L (2x^3 - y)\,\mathrm{d}x + (x + 2y^3)\,\mathrm{d}y$，其中 $L$ 为圆周 $x^2+y^2=a^2$，取逆时针方向。要求不直接使用格林公式。

**解析**：
1. **两类曲线积分的联系**：
   设 $L$ 上的有向切向量方向余弦为 $(\cos\alpha, \cos\beta)$，则有：
   $$\oint_L P\,\mathrm{d}x + Q\,\mathrm{d}y = \oint_L (P\cos\alpha + Q\cos\beta)\,\mathrm{d}s$$
2. **确定方向余弦**：
   对于逆时针方向的圆周 $x^2+y^2=a^2$，任一点 $(x,y)$ 处的切向量方向为 $(-y, x)$。
   对应的单位切向量为 $\vec{\tau} = \left(-\dfrac{y}{a}, \dfrac{x}{a}\right)$。
   所以：$\cos\alpha = -\dfrac{y}{a}$，$\cos\beta = \dfrac{x}{a}$。
3. **转化为第一类曲线积分**：
   $$I = \oint_L \left[ (2x^3 - y)\left(-\frac{y}{a}\right) + (x + 2y^3)\left(\frac{x}{a}\right) \right]\mathrm{d}s = \frac{1}{a} \oint_L \left[ -2x^3y + y^2 + x^2 + 2xy^3 \right]\mathrm{d}s$$
   因为在 $L$ 上 $x^2+y^2=a^2$，代入上式整理得：
   $$I = \frac{1}{a} \oint_L \left[ a^2 + 2xy(y^2-x^2) \right]\mathrm{d}s = a\oint_L \mathrm{d}s + \frac{2}{a}\oint_L xy(y^2-x^2)\,\mathrm{d}s$$
4. **对称性分析**：
   观察被积函数 $f(x,y) = xy(y^2-x^2)$。
   积分路径 $L$ 关于 $x$ 轴对称，而 $f(x,-y) = x(-y)(y^2-x^2) = -xy(y^2-x^2) = -f(x,y)$，是关于 $y$ 的奇函数。
   故根据第一类曲线积分的对称性：
   $$\oint_L xy(y^2-x^2)\,\mathrm{d}s = 0$$
5. **计算结果**：
   $$I = a\oint_L \mathrm{d}s = a \cdot (2\pi a) = 2\pi a^2$$

**答案**：$2\pi a^2$

> 🔑 **老师划重点**：虽然这道题用格林公式可以秒出（$\iint (1 - (-1))\mathrm{d}\sigma = 2\pi a^2$），但是掌握**两类积分的转换公式**是考研/期末考中极具杀伤力的“降维武器”。特别是在圆周上，单位切向量的余弦和点坐标存在极简关系：$\cos\alpha = -\dfrac{y}{r}, \cos\beta = \dfrac{x}{r}$，代入后常常能把第二类积分的 $\mathrm{d}x, \mathrm{d}y$ 直接化简为第一类积分的常数项。

## 总结：曲线积分“大一统”解题策略

| 步骤 | 诊断与决策 | 常用手段 / 避坑要点 |
| :--- | :--- | :--- |
| **第一步** | **观察被积曲线是否封闭** | - 封闭：优先考虑格林公式（第二类）或对称性（第一类）。<br>- 不封闭：考虑**路径无关（全微分）**或**补线法**。 |
| **第二步** | **检验全微分条件 ($P_y = Q_x$)** | 只要是第二类积分，不管封不封闭，**先求偏导数**。若是全微分，直接抄近道（改用折线）或找原函数，免去大量积分计算。 |
| **第三步** | **寻找奇点** | 分母含有 $x^2+y^2$、$\sqrt{x^2+y^2}$ 等项时，警惕原点奇点。若包围奇点，必须用**挖洞法**隔离奇点，不能直接对全区域上用格林。 |
| **第四步** | **对称性最大化利用** | - 第一类：普通对称性（奇零偶倍）、轮换对称性。<br>- 第二类：关于坐标轴对称时，$P\mathrm{d}x$ 看 $y$ 奇偶，$Q\mathrm{d}y$ 看 $x$ 奇偶，规律与第一类相反！ |
| **第五步** | **两类积分的桥梁** | 遇到第二类积分直接代入参数极度恶心（例如分母含根式）时，尝试将其转化为第一类积分，利用 $\mathrm{d}s$ 的几何对称性化简。 |
